# 캐나다 — NRCan 1:500만과 온타리오 OGS 1:25만, 화면은 캐나다 람베르트(3978)

2026-10-04 · `feature/canada` · wetherilli

북미의 첫 나라 탭이다. `docs/다른_대륙_지질도.md` 의 "북미 — 캐나다" 를 따랐다. 미국·멕시코는 gsm-91 이 따로 세운다 — 묶음 "북미"(`north_america`)는
그쪽과 합칠 때 선다. 지금은 `canada` 하나이고, 남미·유럽처럼 묶음이 품기 쉬운 꼴(나라 탭 + 레이어군 + 문)로 지었다.

| 레이어 | 문 | 상류 |
|---|---|---|
| 캐나다 지질도 (1:500만, Wheeler) | `nrcan.py` | NRCan ArcGIS WMS `geological_map_canada_wheeler_en` 레이어 0. 속성 GeoJSON |
| 온타리오 기반암 (1:25만)·제4기·단층·암맥·철층 | `ogs.py` | LIO ArcGIS WMS `GeologyOntario_Map`. 속성은 REST identify |

둘 다 열쇠가 없고 CORS 를 되비추며 열린 정부 라이선스(OGL–Canada·OGL–Ontario)다.

## 1. 투영 — 3857·3413·3978 을 견줬다

상류에 같은 범위를 세 투영으로 물었다(2026-10-04, NRCan 한 장씩). **셋 다 그려 준다** — Capabilities 에는 3978·4326 만 적혀 있지만 ArcGIS WMS 가 다시 그린다.
온타리오도 3857·3978 을 그린다.

- **3857** — 북위 70° 위의 북극 제도가 남쪽의 두세 배로 부푼다. 엘즈미어섬이 온타리오만 해진다. 유럽·남미와 같은 투영이라 묶음 "북미" 와 맞추기는 쉽다
- **3413**(북극 탭들) — 북극 제도는 반듯한데, **중앙 경선이 서경 45°** 라 서경 95° 의 캐나다가 50° 가까이 시계 반대로 눕는다. 남쪽(온타리오·BC)이 비스듬하다
- **3978**(NAD83 / Canada Atlas Lambert, 표준위선 49°·77°, 서경 95°) — 나라가 반듯이 서고 북극 제도도 부풀지 않는다. NRCan 이 스스로 쓰는 투영이다

**3978 로 했다.** 값을 치른 것은 셋이다.

- 화면에 투영을 하나 더 등록한다(`proj4.defs` 한 줄과 범위). **범위는 3857 과 같은 너비(±20 037 508 m)** 로 잡아 줌 번호가 3857 과 같은 해상도를 뜻하게 했다 —
  `minZoom` 같은 줌 문턱을 다른 탭과 같은 수로 읽는다. 캐나다 밖은 투영이 틀어지지만 화면이 가지 않는다
- 배경(EOX 지형·위성, GEBCO)은 3857·4326 타일이라 OpenLayers 가 옮겨 그린다 — 북극 탭들이 이미 그렇게 한다. 3857 배경이라 북위 85° 위가 둥글게 빈다(017 과 같다)
- 미리 데우기(`prewarm`)의 격자가 3978 을 알아야 한다 — `tilegrid.EXTENT` 에 같은 범위, `forward` 는 `crs.latlon_to_lcc`(이미 있던 람베르트 정각원추 식)를 쓴다.
  NAD83 의 GRS80 과 WGS84 는 이 셈에서 같다

묶음 "북미" 가 3857 이 되더라도 캐나다 레이어는 카탈로그 행의 투영(3978)으로 받아 OpenLayers 가 옮겨 그린다 — 북극 묶음 안의 NGU(3575)와 같은 길이다.
3D 는 3857 로 묻는다(`MAP3D_WMS`) — 두 상류 다 그려 준다.

- **버린 것:** 북극 묶음에 캐나다 넣기 — 3413 이 캐나다를 눕혀서다. 북극 제도만 따로 보고 싶어지면 그때 묶음이 캐나다 레이어군을 빌리면(`borrow`) 된다

## 2. 온타리오 — WMS 번호와 REST 번호, 그리고 identify

LIO 서비스는 WMS 레이어 번호(3 기반암·1 제4기·6 단층·4 암맥·5 철층)와 REST 번호(57·52·54·56·55)가 다르다 — 우루과이(196)와 같은 함정이다. 이름은 WMS 번호로
`ogs:<번호>` 이고 `ogs.REST_ID` 가 짝을 든다. WMS GetFeatureInfo 는 GeoJSON 을 XML 오류로 돌려줘서 **속성은 REST identify** 로 묻는다 — 화면이 보낸 WMS 꼴
(범위·크기·누른 화소)을 **그 투영의 좌표 그대로** identify 에 넘긴다(`sr=3978`). 위경도로 바꾸지 않아 셈이 한 줄이다. 제4기의 열(`UNIT_NAME`·`MATERIAL`·`AGE`)은
토론토 북쪽을 한 번 눌러 확인했다. 단층·암맥·철층은 상류가 1:150만보다 가까울 때만 그린다.

NRCan 속성은 영어 열과 프랑스어 짝(`ERE`·`TPRCH`…)이 함께 온다 — 영어 열만 쓴다. 두 문 모두 지질시대(ICS 영어)는 한국어판에서 옮기고(`PALEOPROTEROZOIC (1.6 Ga to 2.5 Ga)` →
"고원생대 (1.6 Ga to 2.5 Ga)"), 암상·층서는 영어 그대로 둔다. "lower Silurian" 처럼 ICS 이름이 아닌 것은 옮기지 않는다.

## 3. 확인

개발 서버로 캐나다 탭을 열었다 — 3978 로 서고, NRCan 을 누르니 처칠 구의 시생대 편마암이, 온타리오 기반암을 켜고 서드베리를 누르니 "Sudbury Igneous Complex
(1850 Ma) · Granophyre · 고원생대" 가 나왔다. 단층 선도 섰다. 휴대폰 시험은 탭 목록을 `REGIONS` 에서 읽어(193) 캐나다도 돈다.
