# 층리·엽리 뺀 5만 지질도 — 그림만 낱레이어를 엮어 GeoServer 에서

2026-09-30 · `feature/kigam-50k-no-attitude` · jikhanjung

## 1. 왜

5만 지질도(`L_50K_Geology_Map`)는 층리·엽리·절리 기호와 경사각 숫자가 빽빽하다. 암상을 읽으려는 사람에게는 소음이고,
jikhanjung P01 대로 층리를 우리가 따로 그리면 두 벌이 겹친다. 사람이 "층리 그려진 거 빼고 받아올 수 있는지" 물었다.

## 2. 무엇을 알았나

- `L_50K_Geology_Map` 은 GeoServer 의 **레이어 묶음**이다. WMS 에는 묶음의 일부만 빼는 요청이 없다
- 묶음을 이루는 낱레이어(`Geology_map:l_50k_geology_*_latest`)를 골라 부르면 된다 — `litho_view`·`alterationzone`·
  `metamorphismzone`·`boundary`·`fold`·`fault`. 청송 천지 도폭에서 견주니 자세 기호만 빠지고 나머지가 같다
- **`/openapi/wms` 는 낱레이어를 모른다** — 키를 붙여도 393 바이트 빈 그림이다. 그래서 GeoServer 로만 된다
- 낱레이어의 `GetFeatureInfo` 는 칸 이름이 영어(`lithoname`·`age` …)다. 묶음은 한국어(`시대`·`도폭`·`지층`)이고 우리 팝업이
  그것에 맞춰져 있다(원도·수치지질도 링크까지)

## 3. 무엇을 정했나

1. **레이어를 하나 더한다, 기본 5만 지질도는 그대로 둔다** — 사람이 "1번" 을 골랐다(docs/KIGAM_5만_구조요소.md §8).
   요청의 대부분인 기본 타일은 여전히 `/openapi/wms` + 인증키다. 예외는 새 레이어 하나에 갇힌다
2. **그림(`GetMap`)만 GeoServer 로, 속성·범례는 바탕 묶음 이름으로 바꿔 지금 길로.** 팝업과 범례가 5만 지질도와 똑같다.
   범례는 키를 붙여 `/openapi/wms` 로, 속성은 전처럼 GeoServer(`DIRECT_REQUESTS`)로 간다
3. 엮는 법은 **`kigam.COMPOSED` 한 표**다. `_get` 이 이름을 보고 가른다 — 문이 하나라는 규칙(CLAUDE.md "구조")을 지킨다.
   엮은 이름은 카탈로그에만 있고 상류에는 없다
4. 씨앗은 따로 `data/kigam_composed_layers.json` 이다. `kigam_layers.json` 은 `GetCapabilities` 에서 뽑는 것이라 손으로
   적은 레이어를 넣으면 다음 뽑기에 사라진다. `확인한날` 을 적어 "아직 대조 안 함" 점이 뜨지 않게 했다 — 씨앗을 만들며
   타일·속성·범례를 받아 봤다
5. 캐시 열쇠에 레이어 이름이 들어가므로 두 판의 타일은 섞이지 않는다. 받은 타일은 다른 KIGAM 타일처럼 캐시에 보탠다
6. 스타일은 비운다(`styles=`) — 낱레이어마다 제 기본 스타일이 묶음 안의 모습과 같았다

## 4. 버린 것

- **묶음 대신 SLD 로 자세 기호를 지우기** — `SLD_BODY` 로 묶음을 다시 그리게 하면 되겠지만, 묶음의 스타일을 우리가
  베껴 들고 있어야 하고 KIGAM 이 스타일을 고치면 어긋난다
- **기본 5만 지질도를 통째로 바꾸기** — 타일 요청 전부가 문서에 없는 주소로 나간다
- 시·군 경계·물길 낱레이어를 같이 엮기 — 배경지도에 있다. 묶음에 든 것의 이름(`admin_boundary_*_NGII`)을 전체
  `GetCapabilities` 에서 찾지 못했다

## 5. 확인

- 시험: 엮은 이름의 `GetMap` 이 GeoServer 로 키 없이 낱레이어 여섯을 부른다, 속성·범례는 바탕 묶음으로 바뀐다, 다른 레이어는
  그대로다 (`test_kigam.Composed`)
- 로컬 서버의 `/GSM/wms/` 로 천지 도폭(3857, 800×600)을 받아 층리 없는 그림을 봤다. `/GSM/featureinfo/` 는 5만 지질도와 같은
  속성(청송화강암, 원도·DOI 링크), `/GSM/legend/` 는 같은 범례
- 남은 것 — KIGAM 에 이 판을 `/openapi/wms` 에 열어 달라고 부탁하기(사람)
