# 일본 — GSJ 1:200만 지질도·중력을 누르면 이름이

2026-10-05 · `feature/gsj-names` · wetherilli

판 세션이 고른 일(TODOs, wetherilli 255 의 남은 것) — 1:200만 일본 지질도·부게 중력을 누르면 기호 번호뿐이라 누르지 않게 두었다. 범례에서 번호 → 이름
표를 떠서 누르게 한다.

## 왜 예전엔 못 눌렀나

255 는 3857 로 물으면 "no results", 4326 으로도 번호뿐이라고 적었다. 다시 보니 MapServer 8 이 **`STYLES` 를 요구**해서(`MissingParameterValue`) 빈 답이
돌아온 것이었다 — `styles=` 를 붙이면 3857·4326 둘 다 `GEO200 = '3'` 을 준다. 그래도 번호뿐인 것은 같다.

## 번호 → 이름은 SLD 에서

범례 그림 대신 **`GetStyles`(SLD)** 를 받으면 규칙마다 `<Name>3 PG2-N1 : 中期始新世より中期中新世前期の堆積岩類</Name>` — 번호·기호·설명이 글로 온다
(규칙 50, 27 KB). 그림을 읽지 않아도 된다. 한 번 받아 캐시에 30 일(1:200만 2012 판은 바뀌지 않는다).

- 설명을 **첫 `の` 에서 시대와 암상으로** 나눈다 — 50 칸 모두 `<시대>の<암상>` 꼴이다. 암상(`堆積岩類`)은 속성 값이라 옮기지 않고, 시대는 옮긴다(CLAUDE.md
  "영어판"의 규칙)
- **시대는 일본어 파서**(`i18n.age_ja`) — 대만(`age_zh`)과 같은 틀이다. `[앞 꾸밈]낱말[뒤 꾸밈]` 을 `より` 로 잇는다. 앞 꾸밈은 ICS 의 세(`前期中新世` =
  마이오세 전기), 뒤 꾸밈은 그 세 안의 앞·가운데·뒤라 한국어로 "전반·중반·후반" 으로 적었다(`中期中新世前期` → 마이오세 중기 전반). 모르는 글자가
  남으면 원문이다. `時代未詳`·`先シルル紀` 는 통째로
- 바다·호수·물·하천·未定義 칸은 비운다
- 누를 때는 CCOP 처럼 **4326 의 작은 네모(0.2°)로 다시** 묻는다 — 화면의 3857 네모는 줌마다 달라 캐시가 맞지 않는다

## 중력은 등치선뿐

`gravdb` 는 칠한 면이 없고 **등치선(2 mGal 간격)만** 누를 수 있다(Capabilities 의 queryable). 누른 자리의 값을 낼 수 없어, 둘레의 등치선 값의 범위를
"부게 이상 (mGal, 둘레 등치선)" 으로 보인다(`10 – 12`). 0.4° 네모(한 픽셀 0.004°)로 묻고 비면 1° 로 한 번 더 — 1° 는 처음부터 쓰면 10 mGal 남짓을
걸쳐 넓었다(`10 – 20`).

## 두지 않은 것

- 지구화학도 — 누르면 함량 구간 번호뿐이고, 범례 그림이 이미 구간을 다 보인다
- 기호(`PG2-N1`)를 시대로 풀기 — GSJ 의 기호 규칙을 따로 옮겨야 하고, 설명의 일본어가 같은 것을 말한다
