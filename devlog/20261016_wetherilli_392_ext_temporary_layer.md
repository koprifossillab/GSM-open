# 392 — 넘겨받은 임시 레이어 (`#ext=`) — 같은 사이트의 형제 앱이 제 점을 GSM 지도에 얹는다

2026-10-16 · `feature/ext-layer` · wetherilli (Cropobite 세션 sclee-fa 가 짜고 gsm-63 이 검토)

Cropobite(노두 사진 뷰어, `/Cropobite/`)의 사용자 요청 — 「장소 페이지는 GSM 화면을 빌려 오든가, GSM 으로 바로 넘어가 점 묶음으로
데이터를 **임시 레이어로** 띄우든가」. GSM 세션(gsm-63)과 나눴다: ext 는 Cropobite 세션이 별도 worktree 에서 PR 로, gsm-63 은 검토.

## 한 것

- 공유 링크 해시에 `ext`·`extname` (`share.js` 의 KEYS).
  `/GSM/#r=korea&c=129.05,37.15&z=10&ext=/Cropobite/places.geojson&extname=Cropobite`
- `map.js` — `extFrom` 이 주소를 고르고, `loadExt` 가 받아 `drawExt` 가 그린다. 투영이 바뀌면 점묶음과 함께 다시 그린다(`setProjection`).
  팝업은 이름·메모(`note`)·「{앱}에서 열기」(`url`). 띠(`.ext-notice`, 공유 링크 띠의 꼴)에 점 수와 「감추기/보이기」.
- 링크가 자리를 주지 않으면(지역 없는 링크 — 나라 밖의 점) 받은 점들로 맞춘다.

## 정한 것

- **저장하지 않는다.** 서버의 점묶음(`PointSet`)은 모두에게 남는 자료이고, 개인 레이어는 관리 화면에서 반입하는 것이라 둘 다 「임시」 가 아니다.
  그래서 따로 레이어 하나를 메모리에만 두고 **점묶음 목록에도 세우지 않았다** — 거기 서면 「점묶음으로 저장」 흐름을 탄다(gsm-63 의 말).
- **같은 사이트의 경로만 받는다** — `/` 로 시작하고 `//` 가 아니어야 한다. 남의 주소를 받으면 아무 자료나 이 지도에 얹혀 GSM 의 것처럼 보인다.
  팝업의 `url` 도 같은 규칙. 정적 판(Pages)에는 같은 사이트의 앱이 없어 `ext` 를 무시한다.
- **지역 없는 링크에서도 받는다** — SHARED 는 지역이 없으면 버려진다. 그 전에 `EXT` 를 떼어 둔다.
- 띠는 하나만 — 공유 링크의 「링크로 연 화면」 띠와 같은 자리에 겹쳐서, ext 가 있으면 ext 띠만 낸다(기억을 덧층에만 쓰는 것은 그대로다).
- 모양은 점묶음의 `pointStyle` 을 빌리고 색은 점마다(`color`, 없으면 점묶음 기본색).

## 하지 않은 것

- **X-Frame-Options 를 SAMEORIGIN 으로** — Cropobite 가 GSM 지도를 iframe 으로 담으려면 필요하지만 보안 설정이라 GSM 쪽 사람이 정한다(gsm-63).
  Cropobite 는 막혀 있으면 제 지도로 돌아간다.
- 3D·온 지구·달·화성 — 지역 지도만으로 충분하다(gsm-63).

## 시험

`test_mobile` — `test_넘겨받은_점`(점묶음 하나를 ext 로 넘겨 띠·점 수·덧층·점묶음 수가 그대로인지, 감추기), `test_넘겨받은_점_남의_주소는_거절`.
KEYS 에서 ext 를 빼면 앞의 것이 「넘겨받았다는 띠가 없다」 로 깨지는 것을 봤다. `test_i18n` 이 새 문장 일곱을 본다.

## 검토 뒤 (gsm-63)

- **열린 넘김을 막았다.** 팝업 링크를 앞 글자(`/` 이고 `//` 가 아님)로만 보면 `/\evil.com`·`/<탭>/evil.com` 이 브라우저에서 `//evil.com` 으로
  읽혀 바깥으로 간다. `sameSite()` 하나가 `new URL(…, location.origin)` 으로 풀어 오리진을 대고 푼 결과의 경로만 돌려준다 — `ext` 경로와 팝업 링크가 함께 쓴다.
- 팝업 제목은 `textContent`, 값은 `textContent`·`href` 만 쓴다(`valueCell`) — 이름·메모에 HTML 이 와도 글자로 선다. 고칠 것이 없었다.
- **점은 5 000 개까지**(`EXT_MAX`) — 넘으면 앞의 것만 띄우고 띠에 「{total}개 가운데 {n}개」.
- 시험: 남의 주소 거절에 `/%5C…`·`/%09/…`·`https://…` 를 더했다. 팝업 링크 쪽은 브라우저 시험에서 점을 누르기가 번거로워
  `sameSite` 를 노드로 대어 봤다(`/\evil.com`·`/\t/evil.com`·`//evil.com` → null).
