# 430 — 극지 점·선 레이어를 정적 판에 (빙저호·GTN-P·KGIS·ASPA·ACC 전선)

2026-10-29 · `feature/static-polar-points` · wetherilli (polar-a 세션). `feature/acc-fronts`(429) 위에 지었다 — ACC 전선을 함께 싣는다

418–425 에서 붙인 극지 자료 가운데 받아 둔 파일에서 짓는 덩이를 연구소 밖 정적 판(GSM-open)에도 싣는다. 판 세션(gsm-fc)이
"기본에 싣는다" 로 정했다 — 사용자가 이 자료들을 붙이라고 했고 조건이 다 열려 있다(CC BY 3.0·4.0).

| 레이어 | 조건 | 말마다 |
|---|---|---|
| 빙저호 남극·그린란드 (`orda:*`, 420) | CC BY 4.0 | 두 벌 |
| 영구동토 시추공 북극·남극 (`gtnp:*`, 422) | CC BY 3.0 | 한 벌 |
| 킹조지섬 KGIS 일곱 (`kgis:*`, 424) | CC BY 3.0 | 굽는 날의 답대로 |
| 남극 특별보호구역 면·점 (`aadc:*`, 423) | CC BY 4.0 | 굽는 날의 답대로 |
| 남극순환류 전선 (`acc:fronts`, 429) | CC BY 4.0 | 두 벌 |

## 왜 이렇게

- **`bake_static` 의 점 몫에 표 하나(`POLAR_FILES`)를 더했다** — 레이어마다 (이름, 있는지 묻는 손, 덩이를 짓는 손). 정적 판의 화면은 이미
  구운 점을 이름으로 싣고(`views._static_catalog` 의 `baked`) `points/<상류>/<이름>[.en].json` 을 부른다(165). 그래서 화면·`static_site.py` 는
  고칠 것이 없다 — 구운 것이 manifest 에 오르면 선다
- **운영의 파일이 없으면 그 레이어만 빠진다**(gsm-fc 가 지키라 한 것). 있는지를 먼저 묻고(`*.available`), 없으면 "자료가 없어 건너뛴다" 를 남기고
  다음으로 간다. 읽다 깨지는 것도 그 레이어만 뺀다 — 굽기는 판마다 사람이 지켜보지 않고 도는 일이라, 파일 하나가 판 전체를 멈추면 안 된다
- **말마다 답이 다르면 두 벌, 같으면 한 벌** — 극지연구소처럼 늘 두 벌로 쓰면 같은 파일이 두 번 실린다(GTN-P 330 KB). 두 답을 대어 보고 가른다.
  manifest 의 `lang` 이 화면에 그것을 알린다
- **RAISED 접지선은 싣지 않는다** — Quantarctica 사본에 조건 칸이 없어 "논문의 CC BY 를 건다, 정적 판에는 싣지 않는다" 를 사람이 정했다
  (420, 2026-10-23). 맡긴 글은 "빙저호·RAISED" 를 함께 적었지만 사람이 앞서 좁게 정한 것이 이긴다 — gsm-fc 에 묻고 그렇게 했다.
  시험이 지킨다(`test_bake_static.PolarFiles`)
- 출처는 레이어 행의 `attribution`(켠 레이어 밑의 출처 줄)이 이미 데이터소스마다 저작자·라이선스를 적는다 — 정적 판도 같은 행이다.
  README "라이선스와 자료의 출처" 의 표에는 넷의 줄에 "정적 판에 싣는다" 를 붙이고 `acc` 줄을 더했다

## 확인한 것

- 로컬에 빙저호·GTN-P 를 스크래치 자리에 받아(`fetch_subglacial_lakes`·`fetch_gtnp`, 한 번씩) 극지 몫만 구웠다 — 빙저호 191·19 KB(두 벌),
  GTN-P 331·32 KB, ACC 전선 122 KB(두 벌). KGIS·ASPA 는 파일이 없어 건너뛰었고 굽기는 끝까지 돌았다
- `static_site.py --baked` 로 판을 구워 `static_smoke.py` — 소개 둘·한국·그린란드·스발바르·북극해·남극 통과. 얀마옌은 "레이어 목록이 비었다" 로
  깨졌는데 시험용 묶음에 얀마옌 점을 굽지 않아서다(실제 `bake_static` 은 굽는다) — 이 일과 상관없다
- 같은 판의 남극 지도를 공유 링크로 열어 전선·빙저호·시추공을 켰다 — 세 파일 200, 페이지 오류 없음
- `manage.py test viewer --parallel 8` — 2 437 개 통과(13 건너뜀). 처음 한 번은 정적 판 브라우저 시험 하나(`내_위치를_기록한다`)가 시간을 넘겼는데, 다른 시험과 겹쳐 돌 때였고 혼자 다시 돌리니 통과했다
