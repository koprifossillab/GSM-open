# 구름 — 모델 구름량을 바람과 같은 시각으로, 다음에 위성 적외선 (계획)

2026-10-01 · `main` · koprifossillab

[docs/구름_시각화.md](../docs/구름_시각화.md) 의 검토를 사람이 "1, 2 차례대로 진행하자" 로 정했다. 그 앞에 레이어군을 "움직이는 지구"
(koprifossillab 010)로 모으라고 했다 — 구름은 거기 든다.

## 1. 단계 1 — 모델 구름량

| | 지금 | 지난 |
|---|---|---|
| 자료 | GFS `TCDC`·`LCDC`·`MCDC`·`HCDC` 순간값 — 바람과 **같은 요청**에 변수만 더한다 | ERA5 `total/low/medium/high_cloud_cover` 00 UTC |
| 시각 | 바람과 같은 장(분석 + 예보 +3–+12) | 바람과 같은 944 날 |
| 굽는 꼴 | 종류마다 PNG 한 장 — **흰색, 투명도가 구름량**(1440×721, 경도 −180 부터). 바람 장 곁(`<시각>/cloud-<종류>.png`) | 같다 |
| 받기 | `fetch_gfs_wind` 가 함께 | `build_era5_wind --clouds` — 이미 구운 날에 구름만 덧굽는다 |

- **화면** — "움직이는 지구" 에 레이어 "구름". 카드에서 종류(전체 기본/하층/중층/상층). **시각은 바람과 한 축** — 지금/지난, 날짜,
  재생을 함께 쓴다. 한 카드에서 바꾸면 다른 카드도 따른다
- **그리기** — 시각의 앞뒤 두 장을 겹친 영상 레이어 둘(구는 Cesium `SingleTileImageryProvider`, 평면은 OpenLayers `ImageStatic`
  4326 — 극 평면은 OpenLayers 가 옮겨 그린다)로 두고 **투명도로 섞는다** — 바람의 가중치(`w`) 그대로. 장마다 브라우저가 픽셀을
  다시 셈하지 않는다
- 바람이 꺼져 있어도 구름은 돈다 — 시각을 맞추는 일(목록·가중치·재생)을 바람 그리기에서 떼어 둘이 함께 쓴다
- 구름 장이 없는 시각(구름을 받기 전의 장)은 구름만 비운다

## 2. 단계 2 — 위성 적외선

GIBS 의 정지궤도 적외선(GOES-East·GOES-West·Himawari, 10 분)을 "위성 구름 (실측)" 레이어로. 브라우저가 곧장 부른다. 빈 곳
(Meteosat 자리)을 카드에 적는다. 1 단계를 마친 뒤 다시 정한다.

## 3. 버린 것

- **구름량을 회색 PNG 로 주고 브라우저가 흰색·투명도로 바꾸기** — 시각을 섞을 때마다 100 만 칸을 다시 셈해야 한다. 서버가 RGBA 로
  구워 두면 브라우저는 두 장의 투명도만 바꾼다
- **네 종류를 한 PNG 의 RGBA 에** — 투명도 칸(A)이 0 이면 캔버스가 나머지 칸을 버린다
- **구름을 입자처럼 Canvas 에** — 구 위에서 온 지구 영상을 화면 칸마다 다시 그려야 한다. 영상 레이어가 맞다
