# 관리 화면 저장 탭 — 휴대폰에서는 카드로

2026-10-05 · `fix/manage-cards` · wetherilli

wetherilli 365 에서 남겨 둔 것을 판 세션이 다음 일로 맡겼다. 저장 탭의 개인 레이어 표는 칸이 일곱이다(보이기·이름·종류·행·원본·날·크기·단추).
휴대폰(390 px)에서는 지우기·내려받기 단추가 표의 오른쪽 끝(x 826 언저리)이라 가로로 굴려야 보였다.

## 어떻게

- **휴대폰(640 px 아래)에서만 줄을 카드로 세운다** — CSS 만 바꾼다(`manage.css`). 데스크톱은 그대로 표다.
  - 머리줄은 숨긴다.
  - 첫 줄은 보이기 칸·색·이름 칸(이름 칸은 남은 폭을 다 쓴다)이다.
  - 그 밑에 종류·행·원본·반입한 날·크기가 "이름 값" 줄로 선다.
  - 끝 줄은 단추(⟳·연결·JSON·CSV·×)가 접혀 흐른다.
- 칸 앞의 이름은 JS 가 칸마다 단 `data-label`(머리줄과 같은 `T("종류")` 따위)을 CSS 가 `::before` 로 적는다. 영어판도 머리줄과 같은 말이 붙는다.

## 버린 것

- 휴대폰에 따로 카드 마크업을 짓기 — 같은 자료를 두 번 그리고, 이름 고치기·색·보이기 손을 두 벌 두게 된다. 표 그대로 CSS 로 세운다.
- 단추를 첫 칸으로 옮기기 — 데스크톱의 표 차례까지 바뀐다.

## 확인

- `test_mobile` 에 `test_저장_탭은_카드로_단추가_보인다` 를 더했다. 양식 예시를 저장하고 저장 탭을 연다. 단추가 모두 390 px 안이고 표 칸이 가로로 구르지 않는지 본다.
- 고치기 전 코드에서는 "'JSON' 단추가 굴려야 보인다(826 > 390)" 로 깨지고, 고친 뒤 통과한다.
- 연결 레이어(⟳·연결 단추가 더 붙는다)와 양식 예시 둘을 저장해 찍어 보았다. 두 카드 모두 단추가 한 줄에 든다.
