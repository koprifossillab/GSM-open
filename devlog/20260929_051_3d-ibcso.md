# 3D 남극 — IBCSO 를 배경과 지형으로

2026-09-29 · sclee · TODO 에서 사람이 골라 맡긴 둘 — "3D 남극 IBCSO 배경", "3D 남극 IBCSO 해저 지형
(Terrarium, REMA 와 잇기)".

047 은 IBCSO v2 를 2D 남극에 배경으로 깔았다. 3D 는 그때까지 남극 바다가 비어 있었다 — 배경은 민 바탕색,
지형은 AWS 인데 AWS 의 남빙양은 옛 GEBCO 라 해저가 뭉개지고 빙붕 밑을 모른다.

## 1. 배경 — 남극 3D 에 "배경" 고르개

남극 탭에서 3D 를 열면 패널에 **배경** 이 선다 — IBCSO 해저·얼음 위(기본)·해저·빙저·없음. 2D 의 두 판
그대로이고 고른 것을 기억한다. 서버가 3857 로 편 타일(`warp/ibcso/`, 040 의 GeoMAP 과 같은 길)이다. 판이
500 m 라 줌 8 넘어서는 브라우저가 늘린다.

**2D 의 3031 타일을 펴지 않고 원본의 9354 격자로 한 벌 더 잘랐다**(`wide-bed/`·`wide-ice/`, 둘 합쳐 30 MB).
2D 의 격자는 GeoMAP 의 것이라 ±3 333 km — 남위 60° 언저리의 네모다. 그대로 펴 보니 3D 에서 배경이 그 네모에서
물결처럼 끊기고 밖은 지형만 남았다(드레이크 해협이 반쯤 비었다). 3D 는 남위 50° 까지를 한 번에 보고 어차피
서버가 다시 펴므로 2D 의 격자를 따를 까닭이 없다. 이제 배경이 남위 50° 선에서 반듯하게 끝나고 포클랜드까지
보인다.

## 2. 지형 — 수치 격자를 따로 받았다

칠한 판은 색이라 표고로 되돌릴 수 없다. PANGAEA 937574 의 **수치 격자** 둘(`IBCSO_v2_bed.tif`·
`IBCSO_v2_ice-surface.tif`, int16 미터, 빈 곳 −32768, 합쳐 330 MB)을 받아 NAS 에 더 두었다(`SHA256SUMS`).
`manage.py build_ibcso` 가 이것도 원본 격자대로 자른다(`dem-bed/`·`dem-ice/`, 합쳐 430 MB, 10 분, 메모리
5.8 GB). `--dem` 이면 이것만.

- **16 비트 흑백 PNG 로 잘라 둔다** — 값은 `미터 + 32768`, 0 이 빈 곳. Terrarium 으로 구워 두지 않은 것은
  3857 로 펼 때 이웃 화소를 섞어야 해서다. Terrarium 의 세 띠를 따로 섞으면 띠 사이 올림이 깨져 값이 튄다.
  섞는 것은 미터여야 한다 — `warp.render_values` 가 값과 채움(빈 곳 0·1)을 따로 펴고, Terrarium 으로 바꾸는 것은
  맨 끝이다(`elevation.terrarium_encode`, ImageMath 로 띠마다 — 한 화소씩 돌지 않는다)
- **빈 곳이 섞인 화소는 AWS 로 메운다.** 채움이 1 이 아닌 화소는 남위 50° 가장자리뿐이다. 값을 채움으로 나눠
  되살리는 길도 있지만 가장자리 몇 화소에 꾀를 쓸 일이 아니다
- 줄일 때(단계 5→0) 빈 곳은 평균에서 뺀다 — 그러지 않으면 가장자리가 −32768 쪽으로 끌려 절벽이 선다
- 이 격자는 047 이 미뤄 둔 **누른 자리의 수심 읽기**에도 그대로 쓸 수 있다

## 3. REMA 와 잇기

`dem/` 의 갈림이 이렇게 된다(3D 는 남위 50° 남쪽이면 줌과 상관없이 서버를 부른다).

| 자리 | 얼음 위(`dem/`) | 빙저(`dem/bed/`) |
|---|---|---|
| 남위 50°–60° | IBCSO | IBCSO |
| 남위 60° 너머, 줌 11 밑 | IBCSO | IBCSO |
| 남위 60° 너머, 줌 11 부터 | **REMA 2 m**, 구멍(바다)은 IBCSO | IBCSO (REMA 로 넘어가지 않는다) |

- **얼음 위 판이 REMA 와 같은 면이라 잇는다.** 둘 다 해발이다(REMA 는 `Height Orthometric` 으로 받는다, 032).
  전에는 REMA 의 구멍을 AWS 로 메웠는데, 이제 남극 바다는 IBCSO 가 메운다(`elevation._hole_tile`)
- **빙저를 고르면 지형도 빙저다.** 얼음을 걷어 낸 배경에 얼음 윗면 땅이 서면(또는 그 거꾸로면) 둘이 어긋난다.
  배경을 바꾸면 표고 타일 주소에 `?bed` 를 달아 MapLibre 가 받아 둔 타일을 버리게 하고, `demRequest` 가 그 표를
  보고 `dem/bed/` 로 돌린다. 남극 밖은 떼고 AWS 로 보낸다
- 편 Terrarium 은 타일 캐시에 담는다(`ibcso-terrarium/<판>/v1/…`, 032 의 PGC 와 같다). 수치 타일을 새로 자르면
  `elevation.IBCSO_TERRAIN_VERSION` 을 올린다

## 확인한 것 (헤드리스 크롬, 이 서버)

- 서버의 값: Dome A 얼음 위 4 045 m·그 밑 기반암 2 061 m(감부르체프 산맥), 로스 빙붕 42 m·그 밑 해저 −623 m,
  웨들해 심해 −4 900 m. 한 장 0.05 초 남짓(AWS 로 메우는 가장자리는 1.5 초)
- 맥머도 둘레: 얼음 위를 고르면 빙붕이 희고 평평하고, 빙저를 고르면 빙붕이 걷혀 해저가 드러난다
- 대륙을 멀리서 비스듬히: 빙저 판의 서남극 분지들이 해수면 밑으로 푸르게 내려앉는다
- 드레이크 해협: 배경이 남위 50° 에서 반듯하게 끝나고 해저 지형이 이어진다
- 시험 605 개

## 운영에 둘 것

`/srv/GSM/db/ibcso/` 에 수치 격자 둘(NAS `sources/ibcso/`)을 더 두고 `manage.py build_ibcso` 를 한 번. 칠한 판도
다시 잘라 3D 배경(`wide-*`)이 생긴다. 수치 격자가 없으면 3D 남극은 전처럼 AWS 지형이고, 3D 배경을 잘라 두지
않았으면 그 자리에 안내가 뜬다.
