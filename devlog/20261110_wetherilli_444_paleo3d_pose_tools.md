# 남극 고지형 3D 의 시점 도구를 온 지구·달·화성과 같게

2026-11-10 · `feature/paleo3d-pose` · wetherilli

사람이 "시점 도구 및 시점 조작을 온지구/달/화성 화면에서 사용하는 것과 동일한 구성으로" 를 바랐다.
443 의 남극 고지형 3D 는 판 안의 단추 둘("남극점 위에서"·"비스듬히")과 Cesium 의 기본 손을 썼다 — 다른 구 화면에서
익힌 손(오른쪽 끌기로 기울이기, 나침반, 기울기·방위 읽기)이 여기서만 달랐다.

## 한 것

- **오른쪽 위의 "자세" 묶음** — `map.css` 의 `.toolbar`·`.tool-col` 그대로. 단추는 평면·처음·남극점·북쪽 위·방위·자전축
- **손** — `earth.js` 의 `screenSpaceCameraController` 설정 그대로(가운데·오른쪽 단추·Ctrl+왼쪽·두 손가락으로 기울이기, 휠·두 손가락으로 당기기)
- **가운데 점 둘레로 돈다** — `pivot`·`anglesAt`·`orbit` 을 `earth.js` 에서 옮겼다. 위도 89.5° 너머는 경도 0° 쪽이 방위 0° 라
  남극점 위에서 "북쪽 위" 를 누르면 2D 남극 탭(3031)과 같은 방향이 된다
- **좌표 막대** — 기울기·방위 읽기와 손 밑의 위경도. 휴대폰은 둘 다 숨으므로(`map.css`) 막대를 걷는다

## 고른 것과 버린 것

- **"평면" 은 2D 남극 탭으로 간다.** 다른 구 화면의 평면은 같은 페이지 안의 OpenLayers 지만, 여기에 극 평면을 새로 두면
  2D 남극 탭을 한 벌 더 만드는 셈이다. 연대는 `gsm.paleoage` 가 넘긴다
- **"남극점" 단추를 더했다.** 다른 화면에 없는 단추지만 지역 탭의 남극에만 서는 장보고·세종처럼 이 화면의 쓰임에 붙은 자리다.
  판 안의 "남극점 위에서"·"비스듬히" 는 "남극점"·"처음" 으로 옮기고 판에서 뺐다
- **자전축 끝의 이름은 구에 가리게 했다.** 온 지구는 극점이 뒤에 있어도 어느 쪽이 북인지 보이게 깊이 검사를 끈다.
  여기서 남극점 위에서 내려다보면 축이 시선과 겹쳐 뒤쪽 "북극점" 이 "남극점" 위에 찍혔다
- 도구 묶음(점·거리·넓이·범위·그림·링크)은 옮기지 않았다 — 사람이 말한 것은 시점이고, 그것들은 점묶음·공유 링크와 엮여 있다

## 확인

로컬 화면(데스크톱·390 px) — 처음 자리는 기울기 60°·방위 180°, 방위 단추로 0°, 남극점은 0°·0° 이고 "북쪽 위"·"방위" 가 흐려진다.
`PhonePaleo3D` 에 도구 묶음이 판과 겹치지 않는지와 남극점·처음 단추를 더했다.
