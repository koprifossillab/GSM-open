# 정적 판 — 휴대폰에서 KIGAM 지질도가 안 뜬다는 제보, 후보를 지우고 키가 받히는지 묻는다

2026-10-04 · `fix/static-mobile-kigam` · wetherilli

사용자 제보 — https://koprifossillab.github.io/GSM-open/ 에 KIGAM 키를 넣으면 PC 에서는 지질도가 뜨는데 휴대폰에서는 안 뜬다.
TODOs 가 적은 후보를 하나씩 쟀다. **우리 판과 상류 쪽 원인은 다 지워졌고, 재현되지 않았다.** 남은 것은 그 휴대폰에서만 알 수 있는
것이라, 화면이 키를 넣을 때 KIGAM 에 한 장 물어 **어디서 끊겼는지를 그 자리에서 말하게** 했다.

## 1. 지운 후보

키는 운영 키(`/srv/GSM/db/kigam_key`)를 스크립트 안에서만 읽어 썼고, 로그에는 `key=KEY` 로 지워 적었다.

- **상류 방화벽이 휴대폰 UA 를 막나 — 아니다.** iPhone Safari·Android Chrome·데스크톱 Chrome UA 로 `/openapi/wms` 를 부르니
  셋 다 200 PNG(같은 75 KB)다. 가짜 키에는 셋 다 같은 500 HTML 이다. curl UA 를 막는 것(CLAUDE.md)과는 다른 일이다
- **키가 도메인(Referer)에 묶이나 — 우리 키는 아니다.** Referer 없음·`github.io`·`example.org`·`localhost` 가 다 200 이다.
  사용자가 넣은 키가 같은지는 모른다 — 아래 §3
- **`data.kigam.re.kr` 인증서 — 문제없다.** 이 망은 HTTPS 를 가로채(KOPRI SSL) 여기서는 진짜 사슬이 안 보여 SSL Labs 에 물었다.
  Sectigo DV R36 → R46 → USERTrust 사슬이 Apple·Android·Mozilla·Windows 저장소에서 다 믿기고, Android 4.0–9·iOS 6–12 흉내가
  다 붙는다(B 등급은 TLS 1.0·1.1 이 열려 있어서다). 사슬에 뿌리가 끼어 있지만(issues 16) 해가 없다
- **바깥에서 닿나 — 닿는다.** check-host.net 의 20 개 나라 지점이 가짜 키 주소에 모두 nginx 500(앱의 응답)을 받았다. 나라·IP
  를 가리는 방화벽은 없다. 키는 남의 서비스에 싣지 않으려고 가짜 키로만 쟀다. IPv4 만 있어(AAAA 없음) IPv6 쪽 고장도 아니다
- **512 타일·`TILED`·화소비 — 아니다.** Playwright 의 iPhone 13·Pixel 7 흉내(화소비 3)로 **실제 Pages 주소**를 열어 창에 키를
  넣으니 타일이 512 그대로 200 으로 오고 5만 지질도가 그려졌다(인증서 검사는 이 망 때문에 껐다). OpenLayers 는 서버 종류를
  모르는 WMS 에 화소비를 싣지 않는다
- **localStorage·다시 연 뒤 — 실린다.** 저장하고 다시 연 뒤 `gsm.key.kigam` 이 있고 타일 주소에 `key=` 가 실린다. 사생활
  모드로 저장소가 막혀도 탭 동안은 `staticKeys` 로 돈다(162)

못 잰 것 — **진짜 WebKit**. 이 서버에는 Playwright WebKit 이 쓸 라이브러리(libwoff1·libavif16 따위)가 없고 sudo 없이는 못 깐다.
Chromium 흉내는 엔진이 아니라 화면 크기·UA·터치만 흉내 낸다.

## 2. 남은 갈래와 화면이 할 일

재현되지 않으니 원인은 그 휴대폰 쪽 셋 가운데 하나다.

1. **키가 틀렸다** — 휴대폰에서 30 자 키를 손으로 옮겨 적거나, 붙여 넣을 때 빈칸·줄바꿈·폭 없는 문자가 낀다. KIGAM 은 틀린
   키에 500 HTML 을 주고 타일 자리는 그냥 빈다 — **지금 화면은 아무 말이 없다.** PC 에서 되는 같은 사람이 휴대폰에서만 안 되는
   데 가장 그럴듯하다
2. **키가 신청 때 적은 곳(IP)에 묶였다** — 신청 화면은 로그인 뒤라 못 봤다(검토 `docs/정적_밖_경로.md` §6 의 숙제 그대로).
   연구소 PC 는 되고 휴대폰(모바일 데이터)은 안 된다면 이것이다
3. **그 망·기기가 막는다** — 회사 Wi-Fi, VPN, 광고 차단, 오래된 기기

그래서 **키를 넣을 때 KIGAM 에 한 장 묻는다**(`map.js` 의 `probeKigam`). 한국 한가운데 512 타일 하나를 화면이 묻는 것과
같은 꼴로 — 브라우저 캐시가 맞아 덤 호출이 거의 없다. `<img>` 가 받히면 그대로 다시 열고, 안 받히면 같은 주소를 `no-cors`
fetch 로 한 번 더 묻는다. 내용은 못 읽어도 **응답이 왔는지는 안다** — 왔으면 서버가 키를 거절한 것(1·2), 안 왔으면 망·인증서에서
끊긴 것(3)이다. 키 창에 그 까닭을 띄우고 "그래도 연다" 로 바꾼다. 이미 넣어 둔 키도 열 때마다 한 장 물어, 안 받히면 키 창을
까닭과 함께 띄운다 — 휴대폰에서는 알림 줄(`#static-key`)이 접힌 패널 안이라 거기에만 적으면 못 본다.

키를 저장할 때 빈칸·줄바꿈·폭 없는 문자(U+200B–200D·FEFF)를 다 지운다 — KIGAM·VWorld 키에는 빈칸이 없다. 전에는 앞뒤만 `trim()` 했다.

확인 — 로컬에 구운 정적 판(iPhone 13 흉내)에서 맞는 키(앞뒤에 빈칸·U+200B·줄바꿈을 붙여)는 다시 열고 지질도가 섰다. 틀린 키는
"주지 않았다", KIGAM 길을 끊으면 "닿지 못했다" 가 떴다. 틀린 키를 넣어 둔 채 열면 키 창이 그 까닭과 함께 떴다.

- **버린 것:** 타일 오류(`tileloaderror`)를 세어 띠를 띄우기 — 바다 쪽 타일도 오류 없이 오니 쓸 만하지만, 타일마다 까닭(거절/끊김)을
  가르려면 fetch 를 타일마다 더 해야 한다. 한 장이면 충분하다
- **버린 것:** 키를 KIGAM 의 다른 API(`/openapi/data`)로 확인하기 — CORS 가 없어 결과를 못 읽고, 타일 길과 같은 문인지도 모른다.
  재려는 것은 "지질도가 오나" 라서 그 타일을 묻는다

## 3. 사람에게 남긴 것

사용자가 휴대폰에서 이 판을 다시 열면 키 창이 둘 가운데 하나를 말한다. "주지 않았다" 면 키를 PC 에서 복사해 휴대폰에 붙여 넣어
보고, 그래도 같으면 같은 휴대폰을 연구소 Wi-Fi 에서 열어 본다 — 거기서만 되면 키가 IP 에 묶인 것(§2-2)이니 KIGAM 에 묻는다.
"닿지 못했다" 면 모바일 데이터로 열어 본다.
