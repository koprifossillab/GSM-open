# 대만 — 경제부 지질조사·광업관리중심 지질도, 대만 탭과 동아시아에

2026-10-02 · `feature/taiwan-geology` · wetherilli

[docs/새_상류_후보.md](../docs/새_상류_후보.md) §1 의 첫째 후보다. 동아시아 묶음의 빈칸을 메운다. 사용자가 둘을 정했다 —
**대만 지역 탭을 따로 두고 동아시아 묶음에도 넣는다**, 첫 판은 **지질도·구조 그림과 누른 자리의 지층까지**(환경지질·
민감구역·시추·온천은 다음 판, TODOs).

## 1. 상류 둘, 문 하나

같은 기관(經濟部地質調查及礦業管理中心, GSMMA)의 호스트 둘이다. 그림과 속성이 다른 집에 있어 `gsmma.py` 하나가 둘을 맡는다
— GSJ 의 `gsj.py` 가 심리스 타일과 CCOP WMS 를 함께 맡는 것과 같다.

| 무엇 | 어디 | 꼴 |
|---|---|---|
| 그림 | `geomap.gsmma.gov.tw/mapguide/mapagent/mapagent.fcgi` | MapGuide WMS 1.3.0. 레이어 62. 열쇠 없음 |
| 속성 | `www.geologycloud.tw/api/v1/zh-tw/<자료>` | 지질운 "자료 공급 서비스" — GeoJSON. `bbox`·`mapid` 로 묻는다 |

## 2. WMS 는 4326 만 받는다 — 4326 격자로 받아 옮겨 그린다

GetCapabilities 의 `CRS` 가 62 개 모두 `EPSG:4326` 하나다. 3857·900913·3826(대만 TM2)으로 물으면 `InvalidCRS`,
1.1.1 의 `SRS` 로 물어도 같다. 그래서 KIGAM·CCOP 처럼 3857 로 받는 길은 없다.

- **고른 것:** 화면은 3857 그대로 두고, 레이어만 4326 격자로 받아 OpenLayers 가 옮겨 그린다 — NPI 가 3413 으로 받는
  것(021)과 같은 틀이다. 카탈로그 행이 `projection: "EPSG:4326"` 을 싣는다
- 격자는 `createXYZ` 를 쓰지 않았다. 4326 범위(360°×180°)로 지으면 줌 0 이 360° 네모 한 장이라 위도가 -270° 까지 걸치고,
  상류는 그런 범위를 받지 않는다. **줌 0 을 180° 네모 두 장**으로 두는 격자(`TAIWAN_GRID`)를 따로 지었다 — WMTS 의
  WorldCRS84Quad 와 같은 꼴이다
- 지역 탭에서도 레이어에 범위(`bbox` + 0.5°)를 건다. 묶음 탭에서만 걸던 것인데, 4326 격자의 낮은 줌 타일이 대만 밖 바다까지
  덮어 빈 그림을 묻게 된다
- **버린 것:** 서버가 4326 을 받아 3857 로 다시 굽기 — 굽는 일이 서버로 오고(Pillow 로 줄마다 늘이기), 받는 타일과 화면의
  타일이 갈려 캐시가 둘이 된다. OpenLayers 가 이미 하는 일이다

3D 는 3857 WMS 만 얹으므로(`views` 의 3D 허용 상류) 대만은 3D 에 오르지 않는다. `map3d.js` 의 동아시아 묶음도 그대로 두었다.

## 3. 레이어를 엮는다

WMS 가 지층·지층 경계·단층·습곡·지층명을 따로 나눠 둔다. 지층 면만 켜면 경계선이 없어 읽기 어렵다. 카탈로그의 레이어 하나가
상류 레이어 여럿을 엮는다(`gsmma.LAYERS`) — MapGuide 가 `LAYERS` 에 쉼표로 여럿을 받아 한 장으로 그려 준다. 첫 판은 아홉:
5만·25만(1974)·50만(2000)·100만(1986) 지질도, 5만 지층명, 5만 도폭, 활성단층(2021), 5만 지층 자세, 50만 지체구조도(1978).

KIGAM 의 `COMPOSED` 와 다른 점 — 저쪽은 문서에 없는 GeoServer 로 가는 예외이고, 이쪽은 같은 문의 이름 바꾸기일 뿐이다.

## 4. 속성은 지질운에 작은 네모로

WMS 레이어는 모두 `queryable=0` 이고 `GetLegendGraphic` 은 559 다. 같은 기관의 지질운 API 가 1/5만 지층(`Stratum`)·1/25만
지층(`Stratum25`)을 GeoJSON 으로 주고 `bbox` 를 받는다.

- 누른 자리를 가운데 둔 0.0002° 네모(약 20 m)로 묻는다. 타이베이 한 점이 0.5 초, 1 KB 남짓이다
- 돌아온 면 가운데 **그 점을 품은 것**만 남긴다(반직선 세기, 구멍은 뺀다). 네모가 경계에 걸리면 둘이 오기 때문이다.
  품은 것이 없으면(좌표가 어긋난 가장자리) 네모에 걸린 것을 낸다
- 열은 `Name`·`Abbrev`·`Time`·`Note` 를 지층명·기호·지질시대·암상으로. `Code`(도식 번호)는 버린다
- 50만·100만·구조 레이어는 속성 자료가 없어 누르지 않는다(`queryable: False`). 범례 단추는 숨긴다(`noLegend`)
- `/featureinfo/` 길을 그대로 탄다. OpenLayers 가 4326 타일 기준의 `GetFeatureInfo` 를 지어 보내면 문이 위경도로 풀어
  지질운에 묻는다 — CCOP 가 4326 으로 다시 묻는 것과 같은 자리다

## 5. 지질시대를 번체 중국어에서 옮긴다

속성 값은 옮기지 않는다(CLAUDE.md "영어판"). 지질시대만 낱말을 짠 것이라 옮긴다. 지질운의 `Time` 은 서로 다른 값이 73 가지다
(1/5만 1 만 1 천 면·1/25만 1 천 5 백 면을 받아 셌다). `i18n.age_zh` 가 낱말(全新世·中新世…)을 영어로 세운 뒤 한국어는
`AGE_WORDS_KO` 로 적는다.

- 꾸밈말은 낱말 뒤(`中新世晚期`)에도 앞(`晚更新世`)에도 오고, 꾸밈말만 있는 조각이 앞뒤 낱말을 빌린다
  (`早期至中期始新世` → 에오세 전기~중기, `中新世早期至中期` → 마이오세 전기~중기)
- 잇는 말 `－`·`─`·`至` 는 `~`, `或` 는 "또는", `或更早` 는 "또는 그 이전", `（？）` 는 `(?)`
- `現代`(25만이 충적층에 쓴다)는 "현세"(Recent), `時代不詳` 는 "시대 미상", `先第三紀` 는 "선제3기"
- 73 가지 모두 옮겨진다. 모르는 글자가 남으면 원문이다 — 앞의 규칙과 같다

## 6. 이용 조건

기관 사이트의 "정부 웹사이트 자료 개방 선언" 은 무상·비독점으로 복제·가공·공중 전송, 상품·서비스 개발까지 허락하고
**출처 표시**를 조건으로 건다. 확인한 선언은 같은 기관의 활동단층 사이트(`fault.gsmma.gov.tw/Webservice/Opendata`)의 것이고,
지도 서버에 따로 붙은 문구는 찾지 못했다. GetCapabilities 는 `Fees=none`·`AccessConstraints=none` 이다. 그래서 `LAB_ONLY` 에
넣지 않고 출처(`ATTRIBUTION`)를 단다. 지질 민감구역 자료에는 "조사·연구·분석·계획에만, 법령 업무에는 쓰지 말라" 는 단서가
있다 — 다음 판에 민감구역을 올릴 때 화면에 적는다.

## 7. 차림 — 보라얼룩나비

이웃 탭이 벚꽃 분홍(일본)·코발트(중국)·비색(동아시아)이다. 대만은 "나비의 섬" 이라 그 상징인 보라얼룩나비(紫斑蝶)의
제비꽃빛으로 갔다. 붉은 기도 푸른 기도 덜어 내 이웃과 갈리게 했다.
