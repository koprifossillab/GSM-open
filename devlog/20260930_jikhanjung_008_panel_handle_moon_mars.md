# 달·화성 화면에도 패널 손잡이

2026-09-30 · `feature/panel-handle-moon-mars` · jikhanjung

## 1. 왜

지구 지도에 패널 접는 손잡이(007)를 단 뒤 사람이 달·화성 화면에도 청했다. 007 에서 "쓸모가 보이면 같은 틀로 옮긴다" 고 남겨 둔 것이다.

## 2. 무엇을 정했나

1. **모양은 그대로 따라온다** — 세 화면이 `map.css` 를 같이 쓴다. 템플릿에 단추 하나, JS 에 접는 함수 하나를 더했다.
   CLAUDE.md 대로 달과 화성에 나란히 같은 것을 둔다
2. **접고 편 뒤 평면과 구를 둘 다 다시 잰다** — 달·화성은 한 칸에 둥근 몸(Cesium)과 평면(OpenLayers)이 겹쳐 있고 하나만 보인다.
   보이는 쪽만 재면 모드를 바꿔 들어갈 때 숨어 있던 쪽이 옛 폭으로 그려진다. 평면을 볼 때는 구의 그리기 고리가 멈춰 있어
   (042) 스스로 폭을 못 따라가므로 `viewer.resize()` 를 부르고 한 번 그리게 한다
3. **접힌 채인지는 세 화면이 한 열쇠**(`gsm.panelFolded`)다 — 달의 다른 기억(`gsm.moon.mode` …)과 달리 화면마다 가르지 않았다.
   패널을 접어 두는 것은 보는 사람의 버릇이라, 지구에서 접고 달로 넘어가면 접힌 채인 편이 자연스럽다
4. **온 지구 화면(`earth.html`)은 이번에 두지 않았다** — 청한 것이 달·화성이다. 같은 틀이라 옮기기 쉽다

## 3. 확인

- 시험 847 개 통과
- 헤드리스 크롬(SwiftShader WebGL): 달·화성 모두 손잡이를 누르면 지도 칸·구의 캔버스·평면이 940 → 1280, 손잡이 `>`. 다시 누르면
  940 과 `<`. 콘솔 오류 없음
