## 1. 손잡이는 두 묶음이다 — 도구와 자세

오른쪽 위 손잡이는 하는 일이 둘이다. **달 위에 무엇을 남기는 것**(점·거리·넓이·범위·지우기)과 **달을 어떻게
보느냐**(구·평면·앞면·북쪽 위·자전축). 한 줄에 섞어 두면 "평면" 이 그리는 도구인지 보는 법인지 헷갈린다.
두 묶음으로 가르고 머리에 이름표(`.tool-cap`)를 달았다. 도구가 맨 오른쪽인 것은 2D 의 그리기 도구 자리와
같게 하려는 것이다 — 두 화면을 오가는 손이 같은 자리를 찾는다.

도구 넷은 2D 의 것과 같은 모양·같은 말·같은 손(다시 누르면 꺼짐, 두 번 누르면 끝, Esc 로 그만)이다.
"찍고 잰 것" 칸과 "점묶음으로 저장" 도 2D 의 것을 그대로 옮겼고, 저장하면 `body: "moon"` 점묶음이 된다(037).
"그림으로 내려받기" 는 옮기지 않았다 — 구(Cesium)와 평면(OpenLayers)을 한 장에 담는 길이 따로 있어야 한다.

### 찍고 잰 것은 경위도로 한 곳에 든다

구와 평면은 그리는 틀이 다르다. 한쪽에 그린 것을 다른 쪽이 모르면 넘어갈 때마다 사라진다. 그래서 찍은 점·범위·
잰 선을 **달 경위도 배열로 한 곳에 들고, 구는 Cesium 개체로, 평면은 OpenLayers 벡터로 저마다 그린다**
(`renderDrawn`). 켠 레이어·점묶음과 같은 길이다(038).

끝내지 않은 선만은 넘어갈 때 버린다. 대신 **그리는 동안은 저절로 넘어가지 않는다**(`drawing()`) — 선을 긋다
휠을 굴렸는데 평면으로 넘어가 그리던 것이 사라지면 화가 난다.

### 달의 구면으로 잰다

평면(등거리 원통)의 가로는 위도만큼 늘어나 있어 평면 좌표로 재면 틀린다. 지구의 `ol.sphere` 는 지구 반지름을
쓴다(P05 §3 의 3.67 배). 거리는 대권(하버사인), 넓이는 `ol.sphere.getArea` 와 같은 식에 반지름만 1737.4 km 다.
범위는 경위도 네모라 넓이가 닫힌 식(`R²·Δλ·(sin φn − sin φs)`)이다. 구에 그리는 범위의 위아래 변은 위선을 따라
촘촘히 찍는다 — 대권으로 이으면 극 쪽으로 휜다.

구에서 범위를 끄는 동안은 구가 끌려 돌지 않는다(휠은 된다). 끄는 손과 돌리는 손이 같은 왼쪽 단추다.

## 2. 누른 자리에 표를 꽂는다

팝업은 누른 자리 옆으로 비켜 서고, 구를 돌리면 누른 자리에서 멀어진다. "어디를 읽었나" 가 남지 않는다.
**속이 빈 고리**를 누른 자리에 꽂고 팝업을 닫으면 뽑는다(`markAt`). 속이 찬 번호 점(찍은 점)과 꼴을 달리한 것은
둘이 한 화면에 함께 있기 때문이다.

팝업이 오른쪽 위 손잡이를 덮던 것도 고쳤다. 손잡이가 두 묶음이 되며 넓어졌고, 팝업이 위라 덮으면 못 누른다.
겹치면 팝업이 손잡이 왼쪽으로 비킨다.

## 3. 위경도는 누르면 복사된다

2D 팝업의 첫 줄과 같다 — 누르면 `위도, 경도` 가 복사되고 "복사했다" 가 잠깐 뜬다. 운영이 http 로 열리는 자리가
있어 clipboard API 가 없으면 옛 길(textarea)로 복사한다. 2D 의 `copyText` 와 같은 꼴이다.

## 4. 자전축

구를 돌리고 기울이다 보면 어느 쪽이 북인지 놓친다. 달 고정 좌표의 Z 축이 곧 자전축이라, 극을 뚫고 반지름의
0.45 배씩 밖으로 뻗은 끊은 선을 긋고 끝에 북극점·남극점을 적었다. 달 속을 지나는 토막은 깊이 검사로 가려져
"꼬챙이" 처럼 보인다. 평면은 늘 북쪽이 위라 구에서만 선다. 켜 둔 것이 기본이고 켜고 끈 것을 기억한다.

## 확인한 것 (헤드리스 크롬)

- 구: 누르면 고리가 꽂힌다. 거리 세 꼭짓점 → 2533.89 km. 점 둘. 범위를 끌면 흰 네모와 꼭짓점·중앙·넓이 표
- 평면(아폴로 11 위): 넓이 세 꼭짓점 → 1 168 km². 팝업이 손잡이 왼쪽으로 비킨다. 위경도를 누르면 "복사했다"
- 자전축이 구의 위아래로 서고 북극점·남극점이 적힌다
