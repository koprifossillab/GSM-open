# KPDC 지도 서버 속성의 이름

2026-09-30 · sclee · TODO "KPDC 지도 서버 속성의 이름 옮기기"(057).

057 은 KPDC 지도 서버(GeoServer)의 속성을 상류 이름 그대로 올렸다 — `year`·`source_inf`·`reliabilit`·
`editor`·`coast_type`·`reference`. 2026-09-30 에 네 레이어의 속성을 WFS 로 두 개씩 받아 보고 이름표를 붙였다
(`kopri.WMS_PROPS`).

- **보이는 것만 고른다** — 해안선 변화는 연도·그린 근거·신뢰도·고친 날, 호수·빙퇴석은 갈래·바닥(밑)·출처,
  하천은 도폭(IMW)·출처·고친 날
- **뺀 것** — 편집자(`editor`, 사람 이름의 약자), SCAR 갈래 번호(`coast_type`·`scar_code`, 뜻을 적은 표를
  KPDC 가 주지 않는다), 참고 번호(`reference`, 가리키는 목록이 없다)
- 빈 값은 줄을 두지 않는다 — 해안선 1 만 3 천 가운데 근거가 빈 것이 많다
- 날짜(`revdate`)는 `19570101` 과 `13/01/1992` 두 꼴로 온다. 고쳐 적지 않고 그대로 둔다 — 어느 것이 일·월인지
  상류가 밝히지 않는다

이름표가 없는 레이어가 새로 오면 전처럼 상류 이름 그대로 뜬다.
