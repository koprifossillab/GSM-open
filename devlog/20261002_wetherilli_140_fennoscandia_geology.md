## 1. 상류와 조건

| | NGU (노르웨이) | GTK (핀란드) |
|---|---|---|
| 주소 | `geo.ngu.no/mapserver/BerggrunnWMS3` (MapServer) | `gtkdata.gtk.fi/arcgis/services/Rajapinnat/GTK_Kalliopera_WMS/MapServer/WMSServer` (ArcGIS) |
| 조건 | **NLOD 2.0** (NGU 자료 정책 — 출처를 밝히되 승인처럼 보이게 쓰지 않는다) | **GTK 오픈 라이선스**, CC BY 4.0 과 호환 (2025-12-01 부터) |
| 3413 | **안 된다** (`InvalidSRS`) | 된다 (목록엔 4326·3067 뿐인데 그려 준다) |
| 속성 | `text/plain` (JSON 없음) | `application/geo+json` |
| CORS | `*` | 보낸 곳을 되돌려 준다 |

둘 다 열쇠가 없고 밖에 열어도 걸리는 것이 없다. CORS 가 있어도 문을 거친다 — 속성을 추리고 캐시에 담는다.

## 2. 사용자와 정한 것

- **새 지역 탭 "노르웨이·핀란드"(`fennoscandia`, 3413)를 내고 북극 묶음에도 넣는다.** 다른 길로는 "북극 묶음에서만 보이기"·"스발바르 탭에
  얹기" 가 있었다. 스발바르 탭이 본토까지 맡으면 이름이 거짓말이 되고, 묶음에서만 보이면 넓은 북극 화면에서 본토를 찾아 들어가야 한다.
  `models.REGIONS` 가 늘어 0018 이주가 생겼다(대만 0017 뒤)
- **레이어는 축척마다 핵심 일곱** — NGU 넷(1:135만 암석 단위, 1:25만 주 암석, 1:5만 암석 단위, 1:25만 경계·구조선), GTK 셋(1:100만
  암석군, 1:20만 암석 단위, 1:100만 단층). 형성 연대·지구조 구분(NGU), 암맥군·변성상(GTK)은 뺐다 — 같은 면을 다른 색으로 칠한 것이다

## 3. NGU 는 3575 로

3413 을 거절하므로 받을 투영을 골라야 했다.

- **3857** — 된다. 그러나 북위 70° 에서 축척이 세 배 부풀어, 축척 따라 켜고 끄는 판(`med målestokkbegrensning`)이 엉뚱한 줌에서
  사라진다. NPI(021)·EMODnet(135)의 함정과 같다
- **25833 (UTM 33N)** — NGU 의 제 투영이고 화면도 이미 안다(NPI 배경). 그러나 핀마르크(동경 30°)에서 경선이 많이 기운다
- **3575 (북극 람베르트 등적, 경도 10°)** — 노르웨이 전체에서 왜곡이 작고 MapServer 목록에 있다. **이것으로 했다.** 화면에 proj4 정의와
  범위(적도까지, ±9 010 km)를 더했고, 타일은 `npolarSource` 가 카탈로그 행의 투영으로 받아 OpenLayers 가 3413 에 옮겨 그린다

그리고 축척 따라 켜고 끄는 판 대신 **늘 그리는 판(`_fullzoom`)** 을 골랐다 — 투영과 상관없이 어느 줌에서 켜도 빈 화면이 아니게.

## 4. 속성

- NGU — MapServer 의 `text/plain`. GEUS 와 같은 꼴이지만 **문은 서로를 타지 않는다**(CLAUDE.md) — 스무 줄짜리 읽는 함수를 `ngu.py` 에
  따로 두었다. 열은 노르웨이어(`bergartsenhet_tekst`·`hovedbergart_tekst` …)라 `FRIENDLY` 로 한국어 이름을 붙이고 **값은 노르웨이어
  그대로** 둔다(속성 값은 옮기지 않는다). 1:135만 판만 영문 암석 단위(`bergartsenhet_tekst_engelsk`)를 함께 줘서 그것도 싣는다
- NGU 의 연대 값(`Kambrium (541.0-485.4 Ma)`)은 **노르웨이어 지질시대**라 `age_ko` 가 읽지 못해 원문이다. 노르웨이어 낱말표를 둘지는
  쓰는 사람이 생기면 본다
- 1:5만 판은 도폭이 없는 곳을 `IKKE KARTLAGT`(지도 없음) 면으로 덮는다 — 그 자리를 누르면 팝업을 비운다(`friendly` 가 빈 것을 내고
  뷰가 건너뛴다)
- GTK — GeoJSON. 값이 없는 칸이 `Null`·`not determined` 로 와서 뺀다. 지질시대는 `EPOCH_` 가 있으면 그것, 없으면 `ERA_` 를 ICS
  한글판으로 옮긴다(`Statherian 1 (1800-1770 Ma)` 처럼 숫자가 섞이면 원문)

## 5. 남은 것

- GTK 20만 판의 상류 이름(`Litologiset_yksiköt_200k25132`)은 ArcGIS 가 붙인 번호를 달고 있다 — GTK 가 서비스를 다시 올리면 바뀔 수
  있다. 그러면 씨앗의 이름과 `LAYER_EN` 을 고친다
- 스웨덴(SGU)이 빠져 탭 가운데가 빈다. SGU WMS 가 열려 있으면 같은 탭에 더한다
- 선 레이어(경계·구조선, 단층)는 정확히 선 위를 눌러야 속성이 온다 — 상류의 버퍼가 작다
