# 깨진 출처 링크

2026-10-05 · `feature/source-links` · wetherilli

판 세션이 스스로 찾아 고르라 한 일 — "화면을 실제로 써 보며 막히는 곳" 가운데 깨진 출처 링크를 골랐다(3D 극지·누르기 없는 레이어는 다른 세션의 몫).

## 무엇을 링크로 셌나

화면에 뜨는 것만 — 문의 출처 문구(`ATTRIBUTION` 따위의 `href`)·템플릿·화면 스크립트·씨앗의 `source`·문의 `SOURCE_URL`. 103 개. 서비스 주소(WMS·REST)는
사람이 누르는 링크가 아니라 셈에서 뺐다 — 그것은 `verify_layers`(298)가 본다.

## 찔러 본 것 (1 초 간격, 한 번씩)

| 갈래 | 수 | 무엇 |
|---|---:|---|
| 살아 있다 | 96 | |
| **깨졌다 → 고쳤다** | 3 | 북아일랜드 GSNI(경제부 쪽 404 → BGS 의 GSNI 쪽), 네덜란드 TNO 지질조사부(404 → `geologischedienst.nl`), 아프리카 1:1000만 DOI(CCGM 의 판 쪽이 없어졌다 → CCGM 첫 쪽에 걸고 DOI 는 글로) |

콜롬비아 SGC 는 `GSM/0.1` 에 403 이고 브라우저 이름에는 200 — 살아 있다로 셌다. BGR 은 쿠키 확인 쪽으로 돌려보내 쿠키를 들고 가야 열린다.
