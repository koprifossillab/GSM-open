# 온 지구 시간 막대 — 처음엔 접고, 띠는 대·기·세 세 줄로

2026-10-07 · `feature/timebar-folded` · wetherilli

## 왜

373 에서 시간 막대를 지도 위 너비를 다 쓰는 ICS 띠(누대·대·기·세·절 다섯 줄)로 바꿨다. 사람이 처음엔 접어 두고,
띠도 지금보다 덜 자세해도 된다고 했다. 다섯 줄과 밑의 띠·캡션이 지도 위를 200 픽셀 넘게 덮고 있었다.

## 한 것

- **처음에는 접는다.** 머리줄(‹ 연대 › · 그때/오늘 · 대 › 기 › 세 › 절 · 오늘)만 보이고, ▾ 를 누르면 띠가 편다.
  사람이 펴거나 접은 것은 기억한다
- **기억의 열쇠를 바꿨다**(`gsm.earth.tbfold` → `gsm.earth.timebar.folded`). 373 은 처음 열 때도 "0"(편 것)을
  적어 두어서, 열쇠를 그대로 두면 한 번이라도 연 사람에게는 새 기본값이 닿지 않는다. 이제는 사람이 누를 때만 적는다
- **띠는 대·기·세 세 줄.** 누대는 대와 거의 겹쳐 말이 없었고(원생·현생), 절은 제4기 안의 일곱 칸뿐이었다. 휴대폰은 373 에서
  이미 그 둘을 숨겼다 — 이제 데스크톱도 같다. 머리줄의 갈래는 그대로 절까지 적는다(`timescale.py` 의 표는 그대로다)

## 버린 것

- 세(epoch) 줄도 빼는 것 — 그러면 넓게 편 제4기 구간이 "제4기" 한 칸이 되어 플라이스토세·홀로세를 가를 수 없다
