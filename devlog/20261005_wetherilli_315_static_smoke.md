# 정적 판 연기 시험

2026-10-05 · `feature/static-smoke` · wetherilli

판 세션이 준 일 — 정적 판(GSM-open Pages)은 연구소 망에서 밖으로 열어 볼 수 없어 아무도 화면을 본 적이 없다. 구운 정적 판을 로컬 파일 서버로 띄워
playwright 로 소개·지역 탭 몇·온 지구를 연다 — 페이지 오류가 없는지, 판 이력·레이어 목록이 뜨는지. 상류 타일은 빈 그림으로 갈아도 된다. 브라우저가
없으면 건너뛰고, `publish_pages.sh` 가 굽고 나서 부를 수 있게.

## 이미 있던 것과 다른 것

`test_static_site` 의 `Browser`(wetherilli 168)는 **작은 판**(한국 + 가짜로 구운 것 조금)을 시험이 굽고 띄운다. 그것은 코드가 깨졌는지를 보지,
**판 세션이 실제로 밀 판**을 보지 않는다 — 실을 지역(`--with`)·구운 것(`--baked`)이 판마다 다르다. 그래서 따로 서는 스크립트
`deploy/static_smoke.py <구운 폴더>` 를 두고 `publish_pages.sh` 가 굽고 나서 **밀기 전에** 부른다. 깨지면(끝 코드 1) `set -e` 로 밀지 않는다.
급할 때만 `GSM_SKIP_SMOKE=1`.

- 소개(한국어·영어) — 오류 없음, 지역 칩이 선다
- 지도 — 판의 `static-config.regions` 에 든 지역 **모두**(일이 말한 "몇" 보다 넓다 — 하나에 3 초 남짓이라 열셋도 1 분이 안 된다). 오류 없음,
  그 지역으로 섰는지, `.layer-row` 가 하나라도 있는지. 한국은 설정 창의 판 이력(`patchnotes.json`)까지
- **온 지구는 열지 않는다** — 정적 판에 없다(서버가 판을 돌린다, wetherilli 167). 일에 적힌 것과 다르다
- 판 밖으로 나가는 그림은 투명 1 픽셀로, 나머지는 끊는다 — 망이 없어도 같은 결과. 처음 열 때의 키 창은 "나중에" 로 넘긴다
- 브라우저가 없으면 끝 코드 0 으로 건너뛰고, `GSM_BROWSER_TESTS=1` 이면 1 — CI 의 휴대폰 job 과 같은 약속
- 판의 폴더 이름이 앞머리(`GSM-open`)와 다르면 임시 폴더에 그 이름으로 걸어(symlink) 띄운다 — `publish_pages.sh` 는 `$WORK/site` 에 굽는다
- `--shots` 로 화면을 찍어 둘 수 있다

스크립트가 깨지지 않았는지는 `test_static_site.Browser.test_연기_시험이_통과한다` 가 작은 판에 돌려 본다(제 브라우저를 띄우므로 다른 프로세스로).
