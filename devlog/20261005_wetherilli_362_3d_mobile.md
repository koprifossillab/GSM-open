# 3D 를 휴대폰으로 — 점묶음 팝업이 화면을 넘던 것

2026-10-05 · `fix/3d-mobile` · wetherilli

판 세션이 맡긴 일이다. 390×844 터치로 3D 화면을 돌렸다.
- 지역 3D(MapLibre) — 한국·스발바르·남극
- 달·화성·수성의 구(Cesium)

## 돌던 것

- **지역 3D** — 접힌 채로 열린다.
  - 펴서 레이어 고르기, 투명도(30 %), 지형 과장(×3.0)이 된다.
  - 두 손가락으로 함께 밀면 기울기가 60° → 80° 가 되고, 비틀면 방위가 -20° → -33.6° 로 돈다.
  - 남극은 배경(IBCSO) 고르개가 선다. 2D 로 돌아가는 링크도 있다.
- **구** — 처음은 내려다보는 자리라 "위에서 보기"·"북쪽 위로" 가 꺼져 있다(맞다).
  - 두 손가락으로 비틀면 방위가 360° → 310.8° 로 돌고, 기울이면 -90° → -85.8° 가 된다. 그 뒤 "위에서 보기" 가 켜지고 둘 다 되돌린다.
  - 자전축 단추가 돈다.
  - 이동 칸에 `90, 0` 을 넣으면 극으로 간다(북위 90°, 60 km 위, 평면으로 넘어간다).
  - 달·화성·수성 모두 같았다.
- 지역 3D 를 누르면 팝업은 점묶음·커스텀 지질도에만 뜬다(설계 그대로 — 3D 는 지질도 속성을 묻지 않는다).

## 막힌 것

- **3D 의 점묶음 팝업이 휴대폰 화면을 넘었다.**
  - 최대 폭이 320 px 라, 화면 가운데 왼쪽(x 155)의 점을 누르니 팝업이 155–475 로 85 px 넘쳤다.
  - MapLibre 는 화면 안에 두려고 붙을 쪽을 고른다. 그러나 폭 320 은 390 px 화면에서 어느 쪽에 붙어도 넘친다 — 왼쪽(x < 폭/2)으로 붙어 그대로 넘쳤다.
  - 고침: 최대 폭을 화면 폭 − 100 px(200–320 px)으로 줄였다(`popupWidth`). 점이 가운데 언저리면 위·아래로 붙어 가운데에 서고, 가장자리면 반대쪽으로 붙어 화면 안에 든다.
  - 커스텀 지질도 팝업도 같은 폭을 쓴다.

## 확인

- `test_mobile.Phone3D` — 긴 속성이 붙은 점을 화면 가운데 왼쪽에 두고 누른다. 팝업이 뜨고, 화면 안에 서는지 본다.
- 고치기 전 코드에서는 "475 > 391" 로 깨지고, 고친 뒤 통과한다.
