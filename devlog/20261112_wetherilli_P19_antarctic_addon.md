# ASM — GSM 위에 얹는 남극 덧붙이를 따로 저장소로 (계획)

2026-11-12 · `main` · wetherilli

**GSM 을 바탕으로 한 남극 도구를 따로 저장소로 낸다.** GSM 의 기능을 이어받고, GSM 에서 남극 쪽을 고치면 같이 따라오되,
남극에서만 쓰는 도구와 자료는 그쪽에만 둔다. "GSM 의 남극 addon" 이다.

이 문서는 **GSM 쪽에서 할 일** — 저장소를 어떻게 잇고 무슨 이음매를 내는지 — 만 적는다. 덧붙이 쪽의 계획(무엇을 얹는지·배포·단계)은
그 저장소의 devlog 에 있다(2026-11-12 에 옮겼다 — GSM 의 devlog 는 판마다 공개 사본에 실린다).


**이름은 `ASM` 이다**(사람, 2026-11-12). 아래의 "남극 도구"·"새 저장소" 는 모두 ASM 을 가리킨다. 표기는 GSM 의 규칙을 따른다 —
`ASM` 하나뿐이고, 기술이 소문자를 강제하는 자리(파이썬 패키지·이미지 이름)만 `asm`.

## 잇는 방식 — 셋을 견줬다

| | 방식 | GSM 의 고침이 따라오나 | 남극 도구만의 것 | 걸리는 것 |
|---|---|---|---|---|
| 가 | **갈라 고친다**(fork) — GSM 을 복사해 그 위에서 고친다 | 판마다 손으로 합친다 | 어디든 넣는다 | `map.js` 9 201 줄·`views.py` 7 462 줄을 양쪽이 고친다 — 판마다 부딪힌다. GSM 은 한 달에 판이 수십 번 오른다 |
| 나 | **GSM-open 꼴** — 판마다 GSM 소스로 통째로 덮고 남극 것만 덧댄다 | 덮으니 따라온다 | 덧대는 파일만 | 덧댈 수 있는 것은 새 파일뿐이다. GSM 파일을 한 줄이라도 고치면 (가)가 된다 |
| 다 | **GSM 이미지 위에 앱 하나를 얹는다** — 새 저장소에는 Django 앱 하나와 `FROM koprifossillab/gsm:<판>` 한 줄 | 판 번호 한 줄만 올린다 | 앱 안에 전부 | GSM 에 **이음매**(아래)를 먼저 내야 한다 |

**(다)로 간다.** "addon" 이라는 말에 가장 가깝고, 따라가는 품이 판 번호 한 줄이다. 새 저장소에는 GSM 의 코드가 한 줄도 없다 —
그래서 가볍고, 비공개 자료·무거운 의존(numpy·scipy 따위)이 GSM 으로 새지 않는다.

(나)는 (다)의 이음매가 서기 전의 임시 길로도 쓰지 않는다 — 덧대려면 어차피 같은 이음매가 있어야 한다.

```
koprifossillab/GSM ──태그──▶ koprifossillab/gsm:<판>      (지금 그대로, 태그마다 CI 가 굽는다)
                                  │ FROM
<새 저장소> ── 남극 앱 ─────────▶ 이미지 = GSM + 남극 앱    (연구소 안에서만)
              └ 호스트 굽기(numpy·scipy) ─▶ <DB 옆>/… 의 구운 격자
```

## "가볍게" 는 화면에서 뺀다 — 코드에서 빼지 않는다

GSM 의 코드를 덜어 낸 사본을 만들면 고침이 따라오지 않는다. 그래서 **코드는 GSM 그대로 두고 차림(profile)으로 가린다.**

- `GSM_REGIONS=antarctica` — 지역 탭을 남극 하나로. 다른 지역의 레이어군은 카탈로그에 넣지 않고(`seed_catalog`), 그 문의 길도 닫는다.
  처음 열면 남극이고 "+ 추가 지역"·"그 외" 가 없다
- 달·화성·수성 화면은 숨긴다. **온 지구와 남극의 3D(탭의 3D·남극 고지형 3D)는 둔다**(사람, 2026-11-12) — GSM 의 화면이라 이미지에 이미 들어 있고, 가리지 않기만 하면 된다
- `GSM_PUBLIC` 이 연구실 내부용을 내리는 것과 같은 자리(`settings`·`views`)의 스위치다 — 새 틀을 만들지 않는다

이 스위치는 GSM 의 것이다. 남극을 모르는 꼴로 내면(`GSM_REGIONS=korea` 도 된다) GSM 에도 쓸모가 있다.

## GSM 에 낼 이음매

GSM 은 남극 도구를 모른다 — "덧붙이가 있으면 싣는다" 만 안다. 덧붙이가 없으면 지금과 한 글자도 다르지 않게 돈다.

| 이음매 | GSM 에서 고칠 자리 | 덧붙이가 주는 것 |
|---|---|---|
| 앱 싣기 | `settings` — `GSM_ADDONS=<패키지>` 를 `INSTALLED_APPS` 에, `gsmweb/urls.py` 가 `GSM/x/<이름>/` 에 그 앱의 `urls` 를 건다 | Django 앱(모델·migration·관리 명령·템플릿·정적 파일) |
| 문 | `doors.py` 가 `viewer/` 만 긁는다 → 덧붙이 패키지도 긁는다 | 제 파일 끝의 `REGISTRY`(wetherilli 371 의 꼴 그대로) |
| 카탈로그 | `seed_catalog` 가 `data/*_layers.json` 만 본다 → 덧붙이의 `data/` 도 | 씨앗 JSON(레이어군은 남극 지역에) |
| 번역 | `i18n` 의 표에 덧붙이의 표를 합친다. `test_i18n` 의 긁기는 덧붙이가 제 시험에서 같은 함수를 부른다 | `EN`·`LAYER_EN`·`GROUP_EN` |
| 자료 명세 | `datastatus.ITEMS`·`sources` 씨앗에 덧붙인다 | 구운 파일·데이터소스의 줄 |
| 화면 | `map.html` 이 덧붙이의 JS·CSS 를 뒤에 싣고, `map.js` 가 **도구·패널·그리는 손을 등록받는 작은 손**을 낸다 | 도구 단추, 패널, 연대 막대 같은 손 |

**모형 화면은 따로 둔다**(사람, 2026-11-12) — 남극 앱의 제 화면(달·화성처럼 제 템플릿·제 JS)이라 `map.js` 의 이음매가 필요 없다.
지도에서는 링크로 넘어가고, 구운 예측·불확실도 격자만 카탈로그 레이어로 남극 탭에 선다. 그래서 화면 이음매를 쓰는 것은
지도 안에서 돌아야 하는 것(빙저 단면처럼 잰 선을 받는 도구)뿐이다 — 그것마저 모형 화면 쪽에 두면 화면 이음매 없이 간다.

**화면 이음매가 가장 불확실하다.** `map.js` 는 한 덩이라 밖에서 끼울 자리가 지금 없다. 먼저 필요한 만큼만 낸다 —
(1) 도구 줄에 단추 하나, (2) 누른 자리 팝업에 줄 보태기, (3) 잰 선을 넘겨받기(단면 도구가 쓴다), (4) 카탈로그 행의 새 `kind` 를 그리는 손.
처음 도구 둘(빙저 단면·예측 격자)이 쓰는 것만 열고, 쓰는 것이 생길 때마다 하나씩 더한다. 미리 넓게 열지 않는다 —
연 것은 GSM 이 지켜야 하는 약속이 된다.

**계약 시험** — GSM 의 시험에 가짜 덧붙이 하나(`viewer/tests/fake_addon/`)를 둬 이음매마다 한 번씩 지나가게 한다.
GSM 의 세션이 `map.js` 를 고치다 이음매를 깨면 GSM 의 CI 가 먼저 안다. 새 저장소의 CI 가 처음 아는 꼴이면 늦다.

## 어디서 고치나 — 가르는 규칙

| 고칠 것 | 자리 |
|---|---|
| 남극 탭의 레이어·버그·공개 자료(누구나 봐도 되는 것) | **GSM** — 지금처럼. 남극 도구는 판을 올리면 받는다 |
| 무거운 격자(원본 해상도)·모형·예측·미공개 자료·연구실 안에서만 쓰는 도구 | **새 저장소** |
| 새 저장소가 GSM 에서 필요한 것 | GSM 에 이음매로 낸다. **새 저장소에서 GSM 의 파일을 덮거나 고치지 않는다** |

새 저장소에서 만들었는데 누구에게나 쓸모 있고 조건이 열린 것은 GSM 으로 옮긴다(거꾸로는 옮기지 않는다).
GSM 의 원칙은 그대로 물려받는다 — 상류마다 문 하나, 키는 브라우저로 안 나간다, 굽기는 호스트·컨테이너는 내주기만,
말을 고르는 규칙, devlog. 새 저장소의 `CLAUDE.md` 는 그것을 되풀이하지 않고 GSM 의 것을 가리킨다.
