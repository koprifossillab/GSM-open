1. "UI 를 전반적으로 3D UI 를 따라 갔는데, 기존 2D 기반으로 짜면 어때? 범례는 우측 하단에 빼서 펼쳐줘."

4. "지질단위 선구조 지질 경계 이런 건 레이어 오버레이로 끼우는 게 낫지 않아?"

## 1. 화면은 2D 의 것이다

036 의 달 화면은 3D 실험 화면(`map3d.html`)의 떠 있는 판을 따랐다. 쓰는 사람에게 GSM 은 2D 화면이다 —
왼쪽 패널(머리·탭·상자·바닥), 오른쪽 위 도구 막대, 아래 좌표 막대, 누른 자리의 팝업. 달도 그 틀에 넣었다.
**CSS 를 새로 짓지 않고 `map.css` 를 그대로 싣는다.** 색만 `data-region="moon"` 의 흑백 토큰이다 — 지역
테마(016)와 같은 길이다. 사용자가 고른 테마는 따른다(먹갈색이면 검은 바탕, 한지면 흰 바탕). 둘 다 흑백이다.

- 머리의 지역 탭 자리에 **지구 | 달** — 달은 지역이 아니라 몸이다(037)
- 찾기는 좌표 막대로 옮겼다 — 2D 의 "좌표·주소·장소로 이동" 과 같은 자리·같은 목록 꼴
- **범례는 오른쪽 아래에 펼쳐 둔다.** 49 칸이라 패널 안에 접어 두면 아무도 안 편다. 머리를 누르면
  접히고, 접은 것을 기억한다. 상류의 범례 차례는 시대가 섞여 있어(에라토스테네스기 바다 `Em` 이 임브리움기
  크레이터 뒤에 온다) **시대별로 다시 모은다** — 서버가 단위마다 기호·시대를 붙여 준다(`trek.age_of_unit`)

## 2. 지질은 오버레이다

2D 처럼 **레이어 목록에서 골라 켜면 "켠 지질 레이어" 카드로 올라온다.** 카드마다 투명도·차례(↑↓)·끄기(×).
구(Cesium `raiseToTop`)와 평면(OpenLayers `zIndex`)이 같은 차례로 쌓는다. 목록은 `moon.js` 의 `CATALOG` 한
곳이다 — 원소·광물(P05 §8)이 오면 레이어군을 하나 더할 뿐이다. 켠 것은 `gsm.moon.layers` 에 기억한다.

## 3. 가까이 가면 평면으로

한 화면에 구(Cesium)와 평면(OpenLayers)을 **둘 다 띄워 두고 하나만 보인다**(`moon-globe`·`moon-flat`).
넘어갈 때마다 새로 짓지 않아서 켠 것·점묶음·팝업이 그대로 이어진다.

- **구 → 평면** — 곧장 내려다보며(기울기 −80° 밑) 250 km 밑으로 내려오면. 기울여 보는 동안은 넘지 않는다 —
  기울이는 사람은 지형을 보려는 것이다
- **평면 → 구** — 400 km 높이만큼 멀어지면. 두 문턱을 달리 둔 것은 되돌이다 — 같으면 문턱에서 오락가락한다
- **극(위도 75° 너머)은 구에 머문다.** 등거리 원통은 극에서 가로로 한없이 늘어난다. 극 평사도법 평면은
  P05 §3 에 남겨 둔다 — 구가 극까지 온전해서 급하지 않다
- 손으로도 오간다(도구 막대의 "평면"·"구"). 손으로 구로 돌아오면 한 번 멀어질 때까지 저절로 평면이 되지 않는다
- 높이 ↔ 해상도는 카메라의 세로 화각으로 바꾼다 — 넘어가도 보이는 넓이가 같다

### 평면의 투영 — 지구의 4326 을 빌리지 않는다

`IAU_2015:30100`(달 경위도, 도)과 `IAU_2015:30110`(등거리 원통, 미터) 둘을 OpenLayers 에 알렸다. 둘 사이는
곱셈 하나다(`R·π/180`). Trek 의 경위도 격자(줌 0 이 2×1 장)가 30110 의 타일 격자로 그대로 선다.

**축척 막대** — 등거리 원통은 남북이 참이고 동서가 `1/cos φ` 만큼 늘어난다. 투영에 `getPointResolution` 을
주어 가운데 위도의 cos 를 곱한다 — OpenLayers 가 지구 반지름으로 재는 길을 타지 않게 하려는 것이다.
아폴로 11 둘레(적도)에서 1 : 583 535, 0–20 km 막대가 선다.
