# KPDC 지도 서버의 WMS — 해안선 변화·호수·하천·빙퇴석

2026-09-29 · sclee · 053 의 다섯째.

KPDC 지도 서버(GeoServer)에 레이어가 54 개 있고 남극 것은 3031 을 그대로 준다. 넷을 골랐다.

- **해안선 변화(남극반도)** — 연도·출처가 붙은 선 1 만 3 천. 빙붕이 물러난 자리를 해마다 본다
- **호수·하천(남극반도)·빙퇴석**

**NPI 드로닝모드랜드(021)처럼 3031 로 곧장 받는다**(`projection`). 3857 로 받아 옮길 까닭이 없다. 브라우저가
GeoServer 를 곧장 부를 수도 있었지만(CORS 가 열려 있다) 서버의 `/wms/` 를 거친다 — 받은 타일을 캐시에 보태고
(007), 부르는 수를 세고(010), 상류가 바뀌면 `kopri.py` 한 곳만 고치려는 것이다. 속성(`GetFeatureInfo`)도
같은 길로 JSON 을 받는다. 속성 이름은 상류 것(`year`·`source_inf`) 그대로다.

**뺀 것.** 고해상 해안선(`antarctic_coastline_high`)은 뭍을 흰 면으로 칠해 위성 배경을 덮었다. 암석 노두
(`topography_rock_*`)는 GeoMAP(018)이 이미 그린다. 배경 래스터(BEDMAP·REMA·음영)는 IBCSO(047)·Esri(040)와 겹친다.
