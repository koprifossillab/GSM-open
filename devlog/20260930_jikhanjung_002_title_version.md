# 제목 옆에 판 번호

2026-09-30 · `feature/title-version` · jikhanjung

## 1. 왜

판 번호는 이미 두 곳에 있었다 — 왼쪽 아래 `GSM v0.19.1` 과 설정 창의 제목. 둘 다 **찾아야 보이는 자리**다.
배포한 뒤 "지금 떠 있는 것이 어느 판인가" 를 확인하려면 설정을 열거나 패널 밑까지 눈을 내려야 했다. 사람이
제목 `대돌여지도` 옆에 작게 적어 달라고 했다(같은 날).

## 2. 무엇을 정했나

1. **지구·달·화성 세 화면에 다 붙였다.** 제목 틀(`.brand h1`)이 셋 다 같고, 달을 고치면 화성도 본다는 규칙대로다.
   3D(`map3d.html`)는 제목이 `대돌여지도 3D` 로 따로 서 있고 패널이 좁아 두지 않았다
2. **이미 있는 `.ver` 를 그대로 쓴다** — 고정폭·11px. 제목 안에서만 색을 부제(`GREAT STONE MAP`)와 같은
   `--gold-muted` 로 두었다. 기본 `.ver` 의 `--ink-faint` 는 먹갈색 제목 줄에서 너무 흐리다. 지역 테마가
   `--gold-muted` 를 바꾸므로 벚꽃·청화백자·빙하빛에서도 부제와 함께 따라간다
3. 번역하지 않는다 — `v0.19.2` 는 낱말이 아니다

## 3. 버린 것

- 아래쪽 `GSM v…` 를 지우기 — 패널을 접어도 남는 자리라 두었다
