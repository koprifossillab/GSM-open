# 일본의 좌표 → 주소 — 국토지리원 역지오코더를 브라우저가 곧장

2026-10-04 · `feature/japan-reverse-geocode` · wetherilli

한국 탭은 누른 자리의 팝업에 도로명·지번이 붙는다(VWorld). 일본 탭에도 주소를 붙였다.

## 무엇을 부르나

- `mreversegeocoder.gsi.go.jp/reverse-geocoder/LonLatToAddress?lat=…&lon=…` — 지리원 지도(地理院地図)가 좌표 밑에 주소를 띄울 때
  쓰는 것. 열쇠가 없고 `Access-Control-Allow-Origin: *` 다. 답은 `{"results":{"muniCd":"13101","lv01Nm":"丸の内一丁目"}}` — 시군구는
  **코드만** 준다. 바다·경계가 정해지지 않은 곳(후지산 꼭대기)은 `{}`
- 코드 → 이름은 지리원 지도가 같은 일에 쓰는 `maps.gsi.go.jp/js/muni.js`(1 919 시군구, 2025-03-07 판)를 `manage.py build_japan_muni`
  로 `static/viewer/japan-muni.json`(58 KB)에 구워 저장소에 둔다. 화면이 처음 일본 주소를 물을 때 한 번 받는다. 상류의 코드는
  `01101` 처럼 앞에 0 이 붙고 표는 `1101` 이라 수로 맞춘다. `札幌市　中央区` 의 전각 빈칸은 뗐다
- 이용 조건은 주소 찾기(155)와 같다 — 공개 API 로 문서화되지 않았고 예고 없이 바뀔 수 있다. 그래서 **사람이 누를 때만** 부른다

## 문을 내지 않았다

TODOs 는 "문도 든다" 고 적었지만 155 와 같은 까닭으로 브라우저가 곧장 부른다. 열쇠가 없어 감출 것이 없고, CORS 가 열렸고, 서버가
대신 부르면 모든 사람의 누르기가 서버 IP 하나로 몰린다. 표도 정적 파일이라 정적 판에서도 그대로 돈다. 표를 굽는 명령은 상류를
부르지 않는다 — 사람이 받은 `muni.js` 를 넘긴다(다른 `build_*` 와 같다). 그래서 `requests` 를 쓰는 새 문이 없다

## 동아시아 탭

동아시아는 VWorld 를 쓴다(한국을 품었다). 경도·위도 네모로 한·일을 가르면 후쿠오카(동경 130.4°)가 한반도 네모에 걸린다. 그래서
**VWorld 에 먼저 묻고 빈 답이면** 일본 둘레(동경 122.5–154.5°, 북위 20–46°)일 때 국토지리원에 다시 묻는다. VWorld 열쇠가 없으면
곧장 국토지리원이다. 출처는 주소 줄의 `title`(마우스를 올리면) — 한국 주소 줄처럼 줄을 늘리지 않았다

  일본 탭 도쿄역 "東京都千代田区丸の内一丁目", 삿포로 "北海道札幌市中央区北一条西二丁目", 동아시아 탭 후쿠오카 "福岡県福岡市中央区天神一丁目",
  바다는 주소 줄이 없다. 삿포로는 상류가 10 초 남짓 걸린 적이 있다(155 의 찾기도 그랬다)
