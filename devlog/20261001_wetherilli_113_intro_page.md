# 첫 화면 — 스스로 넘어가는 소개, 지도는 `map/` 으로

2026-10-01 · `feature/intro-page` · wetherilli

사람이 dikesync 의 첫 화면(`/dikesync/web/`, 스크롤로 지구에서 암맥 하나까지 내려가는 이야기)을 보고, GSM 에도
처음 온 사람이 기능과 쓰는 법을 한눈에 알 수 있는 소개를 두자고 했다. 흐름은 사람이 정했다 — "지질도를 볼 때
불편하지 않았나요?" 로 열고, 만든 곳(극지연구소 고생물진화연구실)에서 남극·그린란드·스발바르로 가서 극지 자료를
정리했다는 것을 보이고, 한국으로 돌아와 3D·찍고 재는 도구, KIGAM → 국토교통부 → 일본 순의 여러 출처, 그리고
"지구를 넘어, 우주로" 달·화성, 끝은 갈래 단추. 오른쪽에 크게 "지도로 바로 가기".

## 정한 것

**뿌리(`/GSM/`)는 늘 소개이고 지도는 `/GSM/map/` 이다.** 사람이 골랐다. 견준 것은 둘 —
"처음 오면(쿠키가 없으면) 뿌리가 소개" 와 "소개는 `/GSM/intro/` 에만". 앞의 것은 같은 주소가 사람마다 다른 화면을
내 헷갈리고, 뒤의 것은 처음 온 사람이 소개를 못 본다. 지도는 이제까지 주소 인자를 읽지 않았으므로(자리·레이어는
브라우저 저장소에 있다) 옛 `/GSM/` 책갈피가 잃는 것은 없다 — 소개가 뜨고, 큰 단추 하나로 지도에 간다.

옮기며 고친 것:

- `map.js` 의 `BASE` 는 `location.pathname` 을 그대로 썼다 — `map/` 을 떼어 낸다. 타일·속성·점묶음 길은 뿌리 밑 그대로다
- 지도의 숨은 차림(온 지구·달·화성)과 3D 단추는 상대 주소(`earth/`)였다 — `map/earth/` 로 새지 않게 `{{ base }}` 를 붙였다.
  숨은 차림 끝에 "대돌여지도 소개" 를 더했다
- 온 지구·달·화성·3D 의 "지구로 돌아간다" 는 `{{ base }}` 였다 — 이제 소개로 가므로 `{{ base }}map/` 으로
- 지도가 `?region=` 을 받는다 — 소개의 "남극 지도로" 가 그 탭을 연다. 탭이 없으면 더하고, 주소에서는 지운다(새로 고칠 때마다
  끌려가지 않게)
- `smoke.sh` 는 소개와 지도를 둘 다 본다

**그림은 운영 화면을 찍어 둔다.** 사람이 골랐다. 견준 것은 "무대에 진짜 지도를 띄운다"(OpenLayers·MapLibre 를 장면마다
갈아 끼운다)였다 — 늘 지금 판을 따라가지만 무겁고, 상류가 느리면 장면이 빈 채로 뜬다. 소개의 할 일은 화면을 **보여 주는**
것이라 찍은 화면(패널·도구까지 보이는)이 쓰는 법을 더 잘 말한다. 값은 UI 가 바뀌면 다시 찍어야 한다는 것 — 그래서 찍는
스크립트를 저장소에 두었다(`deploy/host/intro_shots.sh` + `.js`, playwright-core). 지도의 저장소 열쇠(`gsm.region`·
`gsm.view.<지역>`·`gsm.layers.<지역>`)를 미리 넣고 열고, 거리·넓이는 마우스로 긋고, "그림으로 내려받기" 는 내려받은 PNG 를
그대로 받는다. 한국어·영어 두 벌(`static/viewer/intro/{ko,en}/`, webp)이다 — 그림 속 화면 글자도 언어를 따른다.

찍으며 걸린 것:

- **사내망이 HTTPS 를 다시 서명한다.** curl 은 시스템 인증서를 믿어 돌지만, 묶어 온 chromium 은 몰라 바깥 배경
  (NPI·PGC·GIBS)이 다 비었다. 찍는 브라우저에만 `ignoreHTTPSErrors` 를 켰다
- **배경은 비상업·제3자 조건이 붙은 것을 피했다**(040) — 그린란드·남극의 기본 배경(EOX Sentinel-2·Esri 남극 위성) 대신
  ArcticDEM·REMA 음영. 높이 색 음영은 지질도를 덮어 회색 음영으로 갔다
- 그린란드 서해안은 GEUS 50만이 성기다(편마암이 넓다). 정부 포털 시료(노란 점)는 지질도를 덮는다. 퇴적분지가 있는 동해안
  (스코스비순)을 시료 없이 찍었다
- 3D·달·화성·온 지구는 WebGL 이 소프트웨어(SwiftShader)로 돌아 장면마다 20~30 초를 기다린다

**극지연구소 시료는 좌표만, 출처를 붙여 보인다.** KOPRI 레이어는 `LAB_ONLY` 다(053 — KPDC 공개 정책을 사람이 읽기
전까지). 이번에 정책(「Data Disclosure and Utilization」 10·11조)을 헤드리스 브라우저로 그려 읽었다: 극지 자료는 과학
목적으로 자유롭게 쓰이도록 공개하되, 쓰는 사람은 범위·목적을 적어 신청하고 결과물에 출처를 밝히고 보고한다. 사람은
"단순히 좌표만 찍어서 보여주는 정도는 출처 표기로 허용될 것" 이라고 정했다. 그래서 시료 속성 팝업은 찍지 않았고, 장면마다
"시료 위치 극지연구소 KPDC" 를 적었다. `LAB_ONLY` 는 이번에 건드리지 않았다.

**스크롤하지 않아도 넘어간다.** 사람이 dikesync 와 다르게 해 달라고 했다 — 읽을 틈을 주며 저절로. 멈출 자리는 장면의
단계마다 하나, 자리마다 **보이는 글의 길이만큼** 머문다(한국어 한 글자 70 ms, 영어 32 ms, 3~12 초). 넘어갈 때는 스크롤을
부드럽게 민다 — 장면의 움직임(첫 장면의 종이가 모이는 것, 그림 틀의 기울기)이 스크롤에 걸려 있어 그대로 재생된다.
사람이 휠·터치·키·스크롤 막대로 움직이면 멈추고, 왼쪽 아래 단추로 다시 켠다. 단추 밑 막대가 머무는 시간을 센다.
다른 탭에 있는 동안은 세지 않는다.

**바탕색은 장면의 지역을 따른다.** 지역 탭의 테마(map.css 의 `[data-region]`)를 옮겼다 — 한국 먹갈색·금, 남극 오로라 청록,
그린란드 빙하빛, 스발바르 남색·빨강, 일본 벚꽃(출처 장면의 GSJ 단계), 달 흑백, 화성 녹슨 주황. "지도로 바로 가기" 도 지금
장면(단계)의 지도로 간다 — 남극 장면이면 남극 탭, 달이면 달 화면.

## 버린 것

- **쿠키로 처음 온 사람만 소개** — 위에 적었다. 주소 하나가 사람마다 다른 화면이 된다
- **무대에 진짜 지도** — 위에 적었다. 소개가 상류의 빠르기에 묶인다
- **장면을 하나의 긴 캔버스로**(dikesync 처럼 WebGL·2D 캔버스 셋) — 우리는 보일 것이 화면 캡처라 `<img>` 를 겹쳐 바꾸는
  것으로 족하다. 움직임은 CSS 변수(`--p`) 하나로 건다
- **글을 JS 에 두기** — 화면 문장은 다 템플릿의 `{% t %}` 다. JS 에는 문장이 없고, 단추의 두 낱말(자동 재생·멈춤)도
  템플릿이 `data-` 로 넘긴다

## 남은 것

- 사람이 판을 올린 뒤 글과 장면을 직접 손본다고 했다
- 화면이 크게 바뀌면 `deploy/host/intro_shots.sh` 로 다시 찍는다 — 지도 주소가 `map/` 이 아닌 옛 판이면 뿌리를 찍는다
