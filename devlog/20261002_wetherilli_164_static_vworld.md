# 정적 판의 VWorld — 공개 판용 키 하나로 배경·찾기·좌표→주소·레이어 그림

2026-10-02 · `feature/static-vworld` · wetherilli

검토(docs/정적_밖_경로.md §10)를 정적 판(162, #138)에 옮겼다. 정적 판의 한국 탭은 KIGAM 각자 키로만 돌았고, 찾기 칸은 십진 좌표만
읽었다 — 서버의 `search/`·`whereis/` 가 없어서다. #138 위에 쌓았다.

## 1. 키 — 공개 판용 하나, 운영 키로 돌아가지 않는다

`deploy/static_site.py` 가 `--vworld-key-file` 이나 `GSM_STATIC_VWORLD_KEY` 로 **공개 판용 키**를 받아 화면에 싣는다(`vworldKey`,
운영 화면과 같은 자리). 굽는 동안 `GSM_VWORLD_KEY` 를 지우고, 키 파일(`<DB 옆>/vworld_key`)은 빈 DB 옆이라 닿지 않는다 — **운영 키는
저절로 실리지 않는다.** 검토가 "운영 키와 반드시 갈라 둔다" 고 했다: 지금 우리 키는 도메인 검사를 받지 않아(§10.2) 공개 판에 실린
키는 누구나 뽑아 어디서든 쓰고, 그 호출이 하루 한도를 먹는다. 둘 다 없으면 VWorld 를 상류에서 빼고 굽고 그렇게 알린다.

**공개 판용 키는 아직 없다** — 사람이 vworld.kr 에서 서비스 URL `https://koprifossillab.github.io` 로 받아야 한다(§10.6). 그때까지
정적 판의 한국 탭은 VWorld 없이(배경은 다른 것, 찾기는 좌표만) 돈다.

## 2. 다섯 자리

| 자리 | 정적 판 | 어떻게 |
|---|---|---|
| 배경 WMTS | 된다 | 지금처럼 브라우저가 곧장(CORS `*`). 끊기면 서버(`vworld/`)로 돌던 길(033)만 끈다 — 돌아갈 서버가 없다 |
| WMS 레이어 그림 (지질 참고 36) | 된다 | `STATIC_VWORLD` 가 `api.vworld.kr/req/wms` 를 `<img>` 로 곧장. CORS 가 없어 `crossOrigin` 을 두지 않는다 — **그림으로 내려받기에서는 빠진다**. 레이어명 소문자(020). 범례는 이미지 API 를 `<img>` 로 |
| WMS 속성·WFS 벡터 (단층 등 4) | **안 된다** | CORS 가 없다. 속성은 묻지 않고(`info: null`), 벡터 넷은 정적 목록에서 뺀다(`views._static_catalog`) |
| 주소·장소 찾기 | 된다 | JSONP 로 곧장 — 서버의 `vworld.search` 를 JS 로 옮겼다(갈래 다섯을 한꺼번에, 이름이 같으면 하나로, 넣은 말로 끝나는 행정구역이 맨 앞) |
| 좌표→주소 (팝업 밑 주소) | 된다 | JSONP 로 곧장 — `vworld.reverse` 를 옮겼다 |

주소 CSV(#130, 각자 키로 가자고 검토가 권했다)는 정적 판에 점묶음 올리기가 없어(162 가 숨겼다) 이번에 짓지 않았다.

**JSONP** — VWorld 가 준 스크립트가 우리 화면에서 돈다(검토 §3 이 적은 위험). 콜백 이름을 매번 새로 짓고 받은 뒤 지우며, 8 초 넘으면
버린다. 정적 판에는 사람이 넣은 KIGAM 키 말고 다른 비밀이 없다는 것을 받아들였다. `domain` 에는 그 판의 출처(`location.origin`)를 싣는다 —
지금 키는 보지 않지만 안내가 https 에서는 붙이라고 한다(§10.2).

## 3. 버린 것

- **map.js 밖의 `static-kinds.js` 에 넣기** — gsm-85 의 극지 상류가 그 파일에 붙는 중이라 부딪히지 않게 map.js 안의 VWorld 전용
  코드로 두었다(`STATIC_VWORLD`·`staticVworldSearch`·`staticVworldWhereis`). `layerKind` 가 vworld 를 KIGAM 처럼 먼저 고른다
- **운영 키로 돌아가기** — 위 1

## 4. 확인한 것

- 시험 — 정적 판에 공개 판용 키가 실리고 KIGAM 키는 없는지, VWorld 벡터가 목록에서 빠지는지
- 이 기계에서 운영 키 파일을 넘겨 구운 판을 `/GSM-open/` 꼴로 띄워(확인한 뒤 바로 지웠다): VWorld 배경, "대전 유성구" 찾기(JSONP — 행정구역·
  도로명), 누른 자리의 주소(대전광역시 유성구 원내동 213-4), 수문지질단위 레이어 그림(WMS 9 장 200)과 범례. 페이지 오류·VWorld 4xx 없음
