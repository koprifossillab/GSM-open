# 정적 판을 앱처럼, 그리고 내 위치

2026-10-09 · `feature/mobile-app-locate` · wetherilli

사람이 "폰으로 볼 때 앱의 형태로" 와 "GPS 로 위치도" 를 바랐다. 갈림길 둘을 물었다 — 어디를 앱으로(공개 판 먼저), 어디까지(설치와 껍데기만,
**오프라인 지도는 나중에 한다** — TODOs).

## 앱 — PWA

- **공개 판(GitHub Pages)에만 싣는다.** 설치(홈 화면에 더하기)와 서비스 워커는 보안 연결에서만 돈다. 연구소 판(`http://paleolab/GSM/`)은
  평문이라 안드로이드가 설치를 받지 않는다 — 연구소 판에 HTTPS 를 거는 일은 admin HTTPS 와 함께 미뤄 둔 것이라 여기서 하지 않았다
- **매니페스트·워커는 굽는 쪽이 판마다 쓴다**(`static_site.write_app`). 워커는 제 폴더 밑만 맡아 Pages 뿌리에 있어야 하고, `en/` 에도 한 벌 —
  영어판에서 더한 앱은 영어 지도로 열린다. 시작 주소는 `map/`, 모양은 `standalone`(주소창 없이)
- **워커가 하는 일은 둘뿐이다** — 화면 파일(`static/`, 주소에 `?v=판`)은 처음 받은 것을 기기에 두고, 페이지는 망 먼저·끊기면 담아 둔 것.
  **다른 곳으로 가는 요청은 손대지 않는다** — KIGAM·VWorld 주소에는 보는 사람의 키가 든다. 기기의 캐시에 키 든 주소를 쌓지 않는다.
  판이 오르면 상자 이름(`gsm-<판>`)이 바뀌어 옛 것을 지운다
- 아이콘은 `emblem.svg` 를 Chromium 으로 192·512·maskable(안전 지대 안으로 작게)·애플 180 으로 떴다(`static/viewer/app/`). 바탕은 대기 화면의 먹갈색

버린 것 — 네이티브 껍데기(Capacitor 따위). 스토어·서명·갱신을 우리가 지게 되고, 지도가 웹에서 도는 것은 그대로다.

## 내 위치

- "자세" 묶음에 단추 하나 — `navigator.geolocation.watchPosition`(고정밀)으로 파란 점과 정확도 원을 띄우고 따라간다. **처음 잡힌 자리로 한 번만
  간다** — 그 뒤로는 점만 옮겨, 지도를 끌어 보는 사람을 붙잡지 않는다. 다시 누르면 끈다
- 자리는 위경도로 들고 그릴 때마다 지금 투영으로 옮긴다 — 극지 평사도법에서도 원이 맞고(`Polygon.circular`), 지역을 바꿔도 따라온다.
  지역 지도 밖이면(남극 탭에서 한국에 있으면) 그렇다고 적는다
- **보안 연결이 아니면 단추를 숨긴다** — 브라우저가 위치를 주지 않는다. 그래서 지금은 공개 판(과 localhost)에서만 보인다
- 위치는 어디에도 보내거나 적지 않는다 — 화면에만 그린다
