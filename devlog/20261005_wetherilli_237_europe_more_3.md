# 유럽 넷 더 — 오스트리아·폴란드·네덜란드·벨기에, 체코·덴마크는 사람에게

2026-10-05 · `feature/europe-more-3` · wetherilli

판 세션이 준 일 — 오스트리아·체코·폴란드·네덜란드·벨기에·덴마크의 열린 WMS 를 실측하고, 조건이 분명한 것을 나라 탭과 유럽 묶음에. 마이그레이션은
하나(`0039_region_europe_more_3`). 실측은 두 갈래로 나눠 맡겼다(호스트마다 6–9 번).

## 2. 함정들

- **폴란드 WMS 번호가 REST 와 거꾸로**다 — REST 번호(16·14)로 부르면 도폭 범위 선만 온다. 지도가 세 층(신생대 밑 기반 `1`·고신제3기 `6`·제4기 `11`)이라
  밑에서부터 이 차례로 한 장에 부른다. 누르면 층마다 하나씩, 셋이 뜬다(그 자리의 위아래가 보인다)
- **폴란드·오스트리아는 가까이서 그리지 않는다**(MinScaleDenominator 9만 4 천·14만) — 인도네시아(wetherilli 228)처럼 카탈로그 `maxZoom`(12·11)으로
  그 위는 화면이 늘린다
- **왈로니아는 넓게 그리지 않는다**(1:118만보다 넓으면 빈다) — 줌 9 부터. 단층은 줌 13 부터. 범례는 395 칸 약호뿐이라 두지 않는다
- **네덜란드·플랑드르(GeoServer)는 속성에 모양이 딸려 온다**(7.3 MB·193 KB) — `propertyName` 으로 열을 고른다. 공용 틀 `arcwms.Door` 에 `info_params`
  (레이어마다 더 붙일 변수)를 두었다. 이름은 ArcGIS 지만 GeoServer 도 이 틀로 돈다
- **오스트리아는 서비스가 둘**(지질·단층) — 문 하나 안에 `arcwms.Door` 둘을 두고 이름으로 가른다. 속성은 `Beschreibung` 한 열에 "암상; 시대" 가 붙어 온다

## 3. 시대 — 네 언어

독일어(`Perm - frühe Kreide`)·폴란드어(`jura górna`·`kampan`)·네덜란드어(`Holoceen`)·프랑스어(`Holocène`·`Dévonien inférieur`)를 ICS 영어로 옮기는
표를 `i18n` 에 하나 두었다(`AGE_LOCAL_WORDS`·`AGE_LOCAL_MODIFIERS`, `age_local`). 꾸밈말이 앞에 오든(독·네) 뒤에 오든(폴·프) 받는다. 낱말 하나라도 모르면
빈 글을 돌려주고 문이 원문을 보인다 — 반쯤 옮긴 것을 보이지 않으려는 것이다(`Mitteleozän` 처럼 붙여 쓴 것은 원문 그대로 뜬다). 나라마다 표를 두면
같은 낱말(`jura`·`trias`·`perm`)이 넷으로 흩어진다.

플랑드르는 시대 열이 없다 — 층(Formatie) 이름뿐이다.

## 4. 묶음

유럽 묶음(2D·3D)에 넷을 더했다. 처음 범위를 폴란드 동쪽 끝까지 넓혔다. EGDI 1:100만은 영국에서 빌리고, 바다를 낀 셋(폴란드·네덜란드·벨기에)은
EMODnet 도 빌린다.

## 5. 버린 것

- 체코 1:5만(GEOČR50) — 나라 줌 한 장이 22 초다. 조건이 풀리면 1:50만 영어판을 바탕으로, 1:5만은 가까이서만
- 덴마크 도로청이 다시 내는 ArcGIS(`kort.vd.dk`) — 기술로는 쉽지만 원자료의 GEUS 조건이 "자기 용도만" 이다
- 네덜란드 INSPIRE 판(`geomap`) — 속성이 `gml_id` 뿐이다
