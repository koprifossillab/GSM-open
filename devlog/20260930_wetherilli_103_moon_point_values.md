# 달 — 누른 자리의 광물·원소·지각 두께 값

2026-09-30 · `feature/moon-values` · wetherilli

다른 세션이 조사하고 사람이 달 세션에 넘긴 일이다(TODOs "노는 자료 › 달 — Trek ImageServer"). Trek 판 목록(060)의 광물·
원소·지각 두께 판은 Trek 이 색을 칠한 그림이라 누르면 아무것도 안 나왔다. 범례의 색띠로 어림할 뿐이었다. 같은 자료의
ImageServer 가 값을 주므로 누른 자리 한 점을 읽어 팝업에 적는다.

## 켠 판만 묻는다

TODOs 는 "한 번 누르면 판 6–8 개라 느리다" 고 적었다. **켠 판의 것만** 묻는다. 이미 팝업은 켠 레이어마다 `info`
갈래로 묻고 같은 갈래는 한 번만 묻는 틀이다(`onceBy`). Trek 판에 `info: "value:<갈래>"` 를 주면 그 틀을 그대로 탄다.
색 판과 회색 판(Kaguya FeO 컬러·그레이)이 같은 갈래라 둘을 켜도 한 번이다. 판마다 한 요청이고 캐시에 담는다.

모든 값 판을 늘 묻고 표 하나로 내는 길은 버렸다. 한 번 누르는 데 열 요청이 넘고, 켜지도 않은 판의 값은 읽는 사람도
어디서 온 수인지 모른다.

## 판마다 손으로 적은 표

씨앗에는 ImageServer 가 없어 판마다 단위·배율·그럴 법한 범위를 `trek.VALUES` 에 적었다. 2026-09-30 에 비의 바다
(서경 15.6°·북위 33°)·티코·남극 가까이에서 한 점씩 받아 보았다.

| 갈래 | 서비스 | 받은 값 → 적는 값 |
|---|---|---|
| FeO | Kaguya MI `FeOWeightPercent` | wt% 그대로 (비의 바다 16.7) |
| 감람석·단사휘석·사방휘석·사장석 | Kaguya MI `…Percent` | **0–1 비율**이라 100 을 곱해 wt% |
| 토륨 | LP GRS `LP_GRS_Th_Global_2ppd` | ppm (4.93) |
| 티타늄 | LP GRS `LP_GRS_TitaniumAbundance_2ppd` | wt% |
| 지각 두께 모델 1–4 | GRAIL `Model{n}_thick_eq` | km (10.8) |

범위 밖은 빈 값으로 보고 버린다. Kaguya MI 는 남북위 50° 안뿐인데, 밖을 물으면 빈 값이 아니라 "Invalid or missing input
parameters" 오류가 온다 — 50° 밖은 묻지 않는다(`VALUE_LAT`).

이름(감람석·토륨 …)은 팝업 속성 이름이라 `PROP_EN` 으로 옮긴다. 값·단위·출처는 옮기지 않는다.
