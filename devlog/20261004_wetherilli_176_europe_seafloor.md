# 유럽 바다 — EMODnet 의 제4기 퇴적층·지질 사건을 유럽 탭들에

2026-10-04 · `feature/europe-seafloor` · wetherilli

135 는 EMODnet 해저 지질을 북극해에 두며 제4기 퇴적층·지질 사건·해저 침식을 뺐다 — 스발바르·얀마옌 둘레에서 거의 비었다.
그 뒤 유럽 묶음(영국·아일랜드·프랑스·독일·스페인, 143·147)이 생겨 북해·발트해·대서양 연안을 볼 자리가 섰다.

## 1. 덮는 몫을 다시 쟀다

135 와 같은 법 — 바다 네모마다 레이어 한 장(512², 4326)을 받아 칠한 픽셀의 몫(2026-10-04, 1 초 간격 스무 장).

| 레이어 | 북해 | 발트해 | 영국해협·켈트해 | 비스케이만 | 서지중해 | |
|---|---|---|---|---|---|---|
| 제4기 퇴적층 — 암상 | 57 % | 21 % | 43 % | 35 % | 16 % | 넣음 |
| 제4기 퇴적층 — 시대 | 57 % | 22 % | 43 % | 35 % | 25 % | 넣음 |
| 지질 사건 분포 25만 | 63 % | 31 % | 61 % | 74 % | 49 % | 넣음 |
| 해저 침식 | 0 % | 0 % | 0 % | 0 % | 2 % | 뺌 — 여기서도 비었다 |

속성도 한 자리씩 물어 보았다 — 135 가 북극에서 "속성이 비었다" 고 적은 제4기 퇴적층이 북해에서는 암상·시대(바이크젤 빙기 …)·
원 범례·자료가 다 찼다. 지질 사건 분포는 칸마다 사건 다섯(해저 사태·해저 화산·제4기 구조운동·지진해일·해저 유체 분출)의
"보고됨·없음·자료 없음" 이다. **그림의 색은 해저 사태 하나만 칠한다**(Capabilities 의 설명) — 그래서 제목에 "(색은 해저 사태)" 를
붙이고, 다섯 가지는 누르면 보이게 `FRIENDLY` 에 열을 더했다. 값(`occurrences reported` …)은 속성 값이라 옮기지 않는다.

## 2. 어디에 두나 — 영국에 두고 빌린다

- **북극해 씨앗에 넣지 않았다** — 넣으면 북극해·북극·스발바르 탭에 거의 빈 레이어가 다시 선다(135 가 뺀 까닭 그대로).
  레이어는 지역 하나에만 걸리므로 새 씨앗(`data/emodnet_europe_layers.json`)을 **영국** 지역에 두었다 — EGDI 1:100만과 같은 자리다(143)
- **빌리기** — 프랑스·독일·스페인·아일랜드는 `uk: ["egdi", "emodnet"]`, 영국과 위 넷과 유럽 묶음은 `arctic_ocean: ["emodnet"]` 도
  빌린다(퇴적물 Folk 7·제4기 이전 지질·단층은 북극해 씨앗에 있다). 묶음 탭의 지역 머리말은 빌리는 상류라 붙지 않는다(`wherePrefix`)
- **한 칸으로 합친다** — 두 씨앗의 레이어군 이름이 같다("해저 지질 (EMODnet)"). 그대로 두면 같은 이름의 칸이 둘 선다.
  `renderCatalog` 가 이름이 같은 레이어군을 카탈로그 차례대로 이어 한 칸에 둔다 — 북극해의 넷(퇴적물·기반암)이 앞, 새 셋이 뒤.
  이름을 "유럽 바다" 로 갈라 두 칸을 세우는 길은 버렸다 — 사람에게는 같은 EMODnet 해저 지질이다

## 3. 투영 — 지역으로 가른다

EMODnet 은 북극해·스발바르를 위해 3413 으로 곧장 받았다(135). 영국에 둔 새 셋은 유럽 탭의 투영(3857)으로 받는다 —
`views._layer_extra` 가 레이어군의 지역으로 가른다. 빌려 온 북극해의 넷은 유럽 탭에서도 3413 으로 받아 OpenLayers 가 옮겨 그린다 —
북위 40–60° 에서 3413 의 축척 차는 20 % 안쪽이라(70° 에서 참) 퇴적물의 판 고르기가 크게 어긋나지 않는다. 레이어 하나를 지역마다
다른 투영으로 받으면 캐시 열쇠가 갈려 그만두었다.

정적 판의 `static-kinds.js` 는 EMODnet 을 3413 으로 둔다(161). 정적 판에는 아직 유럽 탭이 없어 두었다 — 실을 때 이 갈림을 옮긴다.

## 4. 남은 것

- **제4기 퇴적층이 땅 위까지 칠한 곳** — 스페인 북부처럼 BGR 의 판이 육지를 담은 자리가 있다(135 의 바렌츠해와 같다). 땅 위에서는
  각 나라 지질도가 더 자세하다
- **영국 둘레 제4기 퇴적층의 조건** — 그 면의 `copyright` 열이 "BGS ©UKRI. All rights Reserved" 다. EMODnet 은 산출물을 CC BY 4.0 으로
  열지만 나라가 낸 원자료의 조건이 따로 적혀 있다. 우리는 WMS 그림을 보이기만 하고 내려받게 하지 않는다. 밖에 열 때 다시 본다
- EMODnet 에는 이 밖에도 마지막 빙기 경관·옛 해안선(BGS)·해저 지형·해저 사태 등 수십 레이어가 있다 — 사람이 고르면 같은 씨앗에 더한다
