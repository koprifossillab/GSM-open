# 달 — 배경 영상 보정

2026-09-29 · sclee · 사람이 말했다: "우리가 보는 이미지를 개선할 수 있게 필터를 추가한다던가 해도 괜찮을 것 같고."
Esri UK 의 달 3D 지도(2019)와 Lutz 의 Cartographic Perspectives 94 글(2019)을 읽은 끝이었다.

## 1. 무엇이 섰나

"레이어 고르기" 의 배경 줄 밑에 접힌 **영상 보정** — 밝기·대비·감마·채도, "LOLA 음영 겹치기",
"선명하게"·"지형 강조" 두 벌, 되돌리기. **배경 영상만 고친다** — 지질도의 색은 범례와의 약속이라 건드리지 않는다.
고친 값은 이 브라우저에 기억한다(`gsm.moon.tune`). 고쳐 둔 동안은 접은 머리에 "고침" 이 뜬다.

## 2. 왜 이렇게 했나

### 구와 평면이 같은 공식이다

- 구 — Cesium `ImageryLayer` 의 `brightness`·`contrast`·`gamma`·`saturation`
- 평면 — OpenLayers `WebGLTile` 의 셰이더 변수 `exposure`·`contrast`·`gamma`·`saturation`

두 쪽의 셰이더를 읽어 맞췄다. 밝기는 곱(OL `exposure` = 밝기 − 1), 대비는 0.5 를 축으로 늘이기(OL `contrast` =
대비 − 1 이면 식이 같다), 감마는 색^(1/감마), 채도는 OL `saturation` = 채도 − 1. 그래서 구에서 평면으로 넘어가도
같은 그림이다.

**처음에는 평면에 CSS 필터를 걸었다.** CSS 에는 감마가 없어 SVG `feComponentTransfer` 로 대신했는데, 캔버스에 건
SVG 필터는 CPU 로 그려서 헤드리스 크롬에서 화면이 멎었다. 셰이더로 옮겼다. 셰이더가 영상을 읽으려면 CORS 로
받아야 한다 — Trek 은 `*` 라 `crossOrigin: "anonymous"` 로 받는다.

### 음영 겹치기는 곱하기다

Lutz 는 색 지질도를 음영 위에 곱하기(Multiply)·오버레이로 섞어 지형이 비치게 했다(CP 94, 표 1). 같은 수를 배경에
쓴다 — LRO WAC 영상 위에 LOLA 음영을 **곱한다**. 평면은 음영 레이어의 캔버스에 CSS `mix-blend-mode: multiply`
(규칙으로 둔다 — 캔버스가 나중에 생겨도 먹게). 구의 Cesium 에는 레이어를 섞는 법이 없어 반투명(0.4)으로 얹는다.
배경이 이미 LOLA 음영이면 끈다.

### 평면일 때는 구를 쉬게 한다

평면으로 넘어가도 숨긴 Cesium 은 쉬지 않고 그리고 있었다. 평면 배경이 WebGL 이 되자 둘이 GPU 를 다퉈 헤드리스에서
화면이 멎었다. 평면이면 `viewer.useDefaultRenderLoop = false`, 구로 돌아오면 다시 켠다 — 사람의 노트북에서도
전지를 아낀다.

  구워 넣었다. 우리는 Trek 에서 달 좌표 그대로 받으니 쓸 까닭이 없다. 다만 **아폴로 EVA 동선(선 387)·달에 남은
  인공물(점 50)** 은 공개 피처 레이어로 있다(출처 "Esri UK" 표기면 상업·비영리 모두 된다) — 착륙지 레이어를 지을 때
