# wetherilli 396 — 정적 판 GeoMAP 지질시대·암상을 누르면 범례 색으로 읽는다

2026-10-20 · `feature/static-geomap-legend-info` · wetherilli

공개 판(github.io)에서 남극 GeoMAP 을 눌러도 아무것도 뜨지 않았다. wetherilli 165 가 "속성은 서버가 gpkg 에서 읽던 것이라
묻지 않는다" 로 막아 두었기 때문이다. 사용자가 "주요한 건 다음에, 지질시대·암상만 가볍게" 를 골랐다.

## 한 것

- 구운 타일의 **누른 픽셀 색을 범례(`geomap_styles.json`)에서 찾는다**(`static-kinds.js` 의 `geomap`). 표는
  `static_tables.GEOMAP_LEGEND_LAYERS` 둘(지질시대·간추린 암상)만 싣는다 — 3.5 KB
- 구운 타일은 **알파 192 로 반투명**이다. 색은 범례와 1–2 차이로 맞는다(공개 판 타일 1 만 8 천 픽셀로 보았다).
  알파 128 밑과 가장 가까운 범례 색에서 24 넘게 먼 것(가장자리의 섞인 색·무늬)은 버린다 — 틀린 것을 띄우느니 띄우지 않는다
- 지질시대 스타일은 **한 시대에 암상 여럿이 같은 색**이다(백악기 넷 따위). 줄마다 띄우지 않고 한 덩이로 묶어
  `지질시대` 하나에 `암상` 을 ` / ` 로 잇는다

## 버린 것

- **gpkg 를 벡터 타일(PMTiles)로 굽기** — 속성이 온전히 오지만 3031 격자 굽기·무늬 옮기기가 커서 다음으로 미뤘다
  (검토는 `docs/정적_밖_경로.md` §7)
- 암층(무늬)·간추린 지질도·단층·자료 품질 — 암층은 무늬가 섞여 색이 흐트러지고, 나머지는 사용자가 고르지 않았다.
  표에 레이어를 더하면 같은 길로 선다

단위 이름·출처 문헌은 여전히 서버 판에만 있다. 팝업은 범례 한 줄만 안다.
