# 팝업 속성 이름의 영어를 시험으로 지킨다

2026-10-05 · `feature/prop-en-guard` · wetherilli

TODOs 의 "영어판 — 속성 이름은 처음 보는 열이 나오면 한국어로 뜬다. 보이면 `PROP_EN` 에 더한다(008)" 를 시험으로 바꿨다.
"보이면" 은 사람이 영어판 팝업을 눌러 봐야 안다는 뜻이다 — 상류가 아흔에 가까워 누가 다 눌러 보지 않는다.

## 왜 `test_i18n` 이 못 잡았나

`test_i18n` 은 `T("…")`·`{% t %}`·`msg("…")` 로 **감싼** 문장을 긁는다. 팝업의 속성 이름은 감싸지 않는다 — 문마다의 `friendly()` 가
`rows = (("암석", v("LITH")), …)` 짝이나 dict 열쇠로 한국어 이름을 짓고, 영어판일 때 `i18n.props_en` 이 `PROP_EN` 에서 찾는다.
표에 없으면 그대로 한국어가 나간다.

## 한 것

`test_prop_en` — `viewer/*.py` 의 이름에 `friendly` 가 든 함수를 AST 로 훑어

- 두 칸 짝의 첫 칸, dict 열쇠
- 그 함수가 부르는 **열 이름 표**(모듈 수준 dict, 이름에 `FRIENDLY`·`LABEL`·`COLUMN`·`FIELD`·`NAMES`·`PROPS` 가 든 것)의 값

가운데 한글이 든 것을 모아 `PROP_EN` 에 없으면 깨진다. 지금 227 개를 긁고, 빠진 것은 둘이었다 — `장소`(브라질 SGB 노두·화석 산지)·
`지구조 요소`(유콘). 채웠다. 긁기가 헛돌지 않게 200 개 아래면 깨진다.

## 버린 것

- **모든 dict 열쇠를 긁기** — 처음 해 보니 카탈로그 씨앗 열쇠(`레이어군순서`)·굽기의 건너뛴 수(`품질 E`)처럼 팝업이 아닌 것이 섞였다. 이름은
  `friendly` 에서 짓는다는 관례에 기대어 거기만 본다
- **함수가 부르는 모든 표** — `geus.PROVINCE_KINDS` 처럼 한국어를 **값**으로 내는 표가 걸렸다(영어판은 `lang` 으로 따로 고른다). 이름처럼
  생긴 표만 본다 — 새 열 이름 표를 짓는 사람은 그렇게 이름을 붙이면 시험이 따라온다
- 뷰·JS 가 따로 짓는 이름(화성 착륙지의 `임무` 따위) — 그쪽은 화면이 `T()` 로 옮겨 `test_i18n` 이 이미 지킨다. TODOs 줄은 남은 것만으로 줄였다
