## 1. 품 S 일곱

- **`/openapi/wms` 의 속성을 대조할 때마다 찔러본다.** "가끔 찔러본다" 를 사람의 기억에
  두면 안 한다. `verify_layers` 끝에 한 번(`--probe-info` 로 그것만). 제품의 길은
  건드리지 않는다 — 열려도 `DIRECT_REQUESTS` 는 사람이 지운다. 이 서버에는 키가 없어
  운영에서 처음 돈다
- **극지 줌 문턱은 3857 로 되짚는다(`mercZoom`).** 극 평사도법의 줌은 투영 범위 한 장이
  줌 0 이라 같은 땅을 두세 단계 낮게 읽었다. 문턱(점 6·이름표 11)을 투영마다 따로 두는
  대신 문턱은 3857 에서 맞춘 값 하나로 두고 해상도를 옮긴다. 화면 한가운데 위도로 옮기는
  것은 극지 탭이 017 전에 3857 로 그리던 모습과 같게 하려는 것이다
- **VWorld 속성은 8 초에 끊는다.** 운영 이틀 82 번에 실패가 0 이라 "잦으면" 의 조건은 차지
  않았다. 그래도 줄인 것은 팝업이 **모든 속성이 와야 뜨기** 때문이다 — 지질 참고 한 칸이
  지질도 속성까지 20 초 붙잡는다. 타일은 그대로 20 초다
- **지하수 등치선 둘을 되살렸다.** 020 은 GetFeatureInfo 가 빈 속성을 줘서 뺐는데, WFS 로
  보니 `legend` 가 선의 값이었다(등수위 m, 전기전도도 µS/cm). 단층과 같은 1° 칸 벡터로
  받는다. `vworld.friendly` 가 열 이름 하나에 뜻 하나라 레이어별 표(`LAYER_FRIENDLY`)를
  더했다 — 단층의 `legend` 는 구분, 등치선의 `legend` 는 값이다. 등수심(gimsdepth)은
  1° 칸에서 1000 줄에 잘려 빼 두었다. 칸을 줄이려면 칸 크기를 레이어마다 두어야 한다
- **영문지층명은 영어판에서 제자리로.** 둘 다 띄우면 영어판 팝업의 첫 줄이 한글이었다.
  원문은 `(Korean)` 으로 곁에 둔다 — 한국어 문헌과 맞춰 볼 때 쓴다. 지체구조운동은 다섯
  낱말뿐인 닫힌 말이라 지질시대처럼 옮겼다(마그마작용 → Magmatism …)
- **밖에 열 때의 스위치(`GSM_PUBLIC`)를 지금 만든다.** 여는 날 "무엇을 내려야 하나" 를 다시
  찾지 않게. 내리는 것은 geo3al(이용 조건)·한반도 지질도 셋(출처 모름)·암맥(연구실 기록).
  레이어 이름이 `<상류>:…` 꼴이라 이름 앞머리로 가른다 — 028 의 민판도 저절로 걸린다
- **`fetch_grportal` 이 NPI 점도 받는다.** 이름은 그대로 두었다 — 배포 스크립트와 사람 손이
  이 이름을 안다

phyloserver 의 DRF 쓰기 권한은 그쪽 저장소의 일이라 손대지 않았다.

## 2. 미리 데우기 — 상류마다 "브라우저와 한 글자까지"

010 의 원칙은 "받는 타일은 브라우저가 부르는 것과 한 글자까지 같다" 이다. 상류가 늘면서
받는 꼴이 넷으로 갈렸다(3857 WMS · 극지 투영 WMS · z/x/y · 우리가 굽는 것). 명령 하나에
꼴마다 계획(`WmsPlan`·`GsjPlan`·`GeomapPlan`)을 두었다. 열쇠는 뷰가 쓰는 함수를 그대로
부른다(`views.gsj_tile_key`·`geomap_tile_key`) — 둘이 따로 셈하면 언젠가 어긋난다.

극지 격자의 BBOX 는 **같은 판의 OpenLayers 를 node 로 돌려** 뽑은 값과 대조했다
(`test_tilegrid.PolarGrid`). 3857 을 브라우저 주소와 대조했던(010) 것과 같은 까닭이다 —
정수 끝자리 하나가 달라도 캐시가 헛돈다. GeoMAP 은 상류가 없어 쉬지 않는다.

## 5. 그림으로 내려받기

"인쇄·내보내기" 를 **PNG 한 장**으로 좁혔다. 인쇄용 CSS 를 따로 짜면 패널·도구·팝업을
하나하나 숨겨야 하고 브라우저마다 쪽 나눔이 다르다. 그림 한 장이면 인쇄도 되고 보고서에도
붙는다.

- 그림은 뷰어에서 떨어져 돌아다닌다. 그래서 **밑에 무엇을 봤는지 적는다** — 지역·켠 레이어·
  점묶음·가운데 좌표와 투영·축척 막대·출처·날짜. 화면에서는 레이어 이름이 곧 출처라 비워 둔
  KIGAM 도 그림에는 적는다(자료의 주인이다)
- 브라우저가 곧장 부르는 배경은 이미 `crossOrigin` 으로 받고 있어 캔버스가 더럽혀지지 않는다.
  그래도 막히면 "배경을 없음으로" 라고 까닭을 말한다. VWorld 배경은 이 서버에 열쇠가 없어
  운영에서 처음 본다
