# 구 화면에도 재는 것을 끝내는 단추 — 지역 지도와 같은 셋

2026-11-13 · `fix/measure-finish` · wetherilli

지역 지도에 세운 단추 셋(끝내기·한 점 무르기·취소, 글쇠 Enter·Backspace·Esc — 450)을 온 지구·달·화성·수성 화면에도 세웠다.
같은 말·같은 꼴·같은 자리(알림 밑)다. CSS 는 네 화면이 `map.css` 를 같이 읽어 따로 적지 않았다.

## 왜 이렇게 했나

- **구와 평면의 그리는 손이 다르다.** 구는 우리가 누른 꼭짓점을 `sketch` 에 쌓고, 평면(극 평면 포함)은 OpenLayers `Draw` 다.
  단추는 하나로 두고 `drawAct` 가 두 길로 가른다 — 끝내기는 구에서 `finishGlobeSketch()`(두 번 누르기·마지막 점을 다시 누르기와 같은 함수),
  평면에서 `finishDrawing()`(두 번 누른 것과 같은 `drawend`). 그래서 높이 그래프가 뜨는 길(`finishMeasure` → `showProfile`)이 두 번 누른 것과 같다
- **점의 수는 구에서 겹친 꼭짓점을 하나로 센다** — 마우스로 두 번 누르면 `LEFT_CLICK` 이 두 번 먼저 와 같은 자리가 두 번 든다.
  끝낼 때 거르는 것(1 m 안)과 같은 셈으로 세야 "끝내기가 켜졌는데 끝나지 않는" 일이 없다. 무르기도 겹친 것까지 함께 무른다
- **단추를 누른 뒤에는 `lastTap` 을 비운다** — 터치의 "마지막 점을 다시 누르면 끝"(342)은 앞의 누름 자리를 기억한다. 무른 뒤 그
  자리 가까이를 다시 누르면 새 점이 아니라 끝내기가 되어 한 점짜리로 끝나 버렸다
- **평면에서 새로 재기 시작하면 앞서 잰 것을 걷는다.** 구는 원래 그랬고 평면은 끝낼 때까지 옛 선을 두었다. 취소하면 "잰 것이 없다" 로
  돌아가야 하는데 평면에서만 옛 선이 지도에 남아 말과 그림이 어긋났다. 두 길을 구의 것으로 맞췄다
- **구에서 찍을 때마다 수를 낸다**(`showSketch`) — 지금까지는 누르개가 움직일 때만 셌다. 터치에는 누르개가 없어 끝날 때까지 수가
  비어 있었고, 무른 뒤에도 수가 바뀌어야 한다
- 글쇠는 지역 지도와 같다 — 단추에 손이 있으면 Enter·Backspace 는 단추의 것이다. Esc 는 전처럼 단추에 손이 있어도 먹는다
  (재는 중이면 취소, 범위를 끄는 중이면 그것을 버리고, 아니면 도구를 끈다)

## 버린 것

- **네 화면의 그리기를 한 파일로 뽑기** — 네 파일이 일부러 나란히 있다(CLAUDE.md "달 화면을 고치면 화성에도"). 같은 고침을 넷에 똑같이 넣었다
- **구에서 Cesium 의 두 번 누르기를 되살려 단추가 그것을 부르게** — 터치에는 오지 않는다(342). 단추가 곧장 끝내는 함수를 부른다

## 확인

`test_mobile` 의 `PlanetMeasureGlobe`·`PlanetMeasureFlat` — 네 화면마다 구·평면에서 선 세 점 → 무르기 → 끝내기(높이 그래프),
면 두 점에서 끝내기가 꺼져 있고 세 점에서 켜지며 취소하면 잰 것이 남지 않는다. 극 평면은 같은 `Draw` 라 따로 찍어 보지 않았다.
