# 수성 더 — 소개 화면에 수성, 도폭 경계는 우리가 긋는다

2026-10-02 · `feature/mercury-more` · wetherilli

판 세션이 맡긴 둘이다 — (1) 소개 화면에 수성, (2) USGS WMS 의 도폭 경계·마리너 10 모자이크. 수성 지질도(144) 위에 쌓았다.

## 1. 소개 화면

달·화성과 같은 자리 넷에 수성을 더했다.

- **우주 장면** — 단계가 셋에서 넷이 됐다. 지구가 물러나고 달·화성에 이어 수성이 다가온다. 멈출 자리가 ⅙·½·⅚ 에서
  ⅛·⅜·⅝·⅞ 로 바뀌어 구가 움직이는 때를 다시 나눴다(`intro.js` 의 `CHOREO.space`). 화성은 수성이 올 때 위로 비켜난다.
  수성은 천천히 돈다 — 공전 두 번에 세 바퀴다
- **첫 장면** — 둥근 수성 하나를 작게 띄우고 다루는 곳 칩에 "수성"
- **갈래** — 달·화성 옆에 수성 카드. 우주 줄이 두 칸에서 세 칸이 됐다(좁은 화면은 그대로 한 칸). 사람이 말했다: "달, 화성
  소개 폭을 줄이고 같은 줄에 수성을 급으로". 세 칸에 넓은 카드(그림 왼쪽·글 오른쪽)를 두니 1100 px 에서 글이 비좁고 달 카드만
  키가 컸다 — **지구 줄과 같은 카드(그림 위·글 아래)**로 바꾸고 셋의 키를 맞췄다
- **그림** — 구에 감는 그림은 MESSENGER 모자이크에 우리 지질도를 얹어 굽고(`intro_globes.py mercury`), 화면 사진은
  지질도가 보이게 서경 100° 쪽에서 찍었다(`intro_shots.js` 의 `mercury`). 운영에는 아직 수성 지질도가 없어(#115 를 굽기 전)
  **지질도를 구운 개발 서버에서** 찍고 구웠다 — 운영에서 다시 찍어도 같은 그림이 나와야 한다

## 2. USGS WMS — 둘 다 쓰지 않는다

- **`Mercury5M_Quads`(도폭 경계·이름)는 그림을 주지 않는다.** 어느 범위로 물어도 `msGetEncodedString(): Unknown identifier.
  Encoding not supported by libiconv (UTF8)` — 상류 MapServer 의 이름표 설정이 깨져 있다(2026-10-02)
- **`MARINER` 는 이름과 내용이 다르다.** 설명은 "전부 마리너 10 의 플라이바이 자료" 인데 마리너 10 이 찍지 못한 동경 90°
  둘레에도 자세한 영상이 있다. 무엇을 섞었는지 모르는 판을 "마리너 10" 이라 부르며 내지 않기로 했다

**도폭 경계는 화면이 긋는다**(`mercury.js` 의 `quads`). 경계가 위·경선뿐이라 상류가 필요 없다 — 극 66° 너머, 중위도
22–66°(경도 90° 씩), 적도 띠 ±22°(72° 씩), 모두 서경으로 나뉜다. 경계는 Wikipedia 의 수성 도폭 목록을 따랐다(그 표가
21–66°·22°S–22°N·67–90° 로 조금씩 겹치고 비어 22° 와 66° 로 맞췄다). 이름표는 "H-6 Kuiper · I-1233" — 원도가 있는 아홉에는
원도 번호를 붙여 지질도가 왜 반쪽인지 보이게 했다. 서버의 `mercurymap.quad_of` 도 같은 경계로 고쳤다(144 는 ±22.5°·±65° 였다).

## 3. 확인한 것

- 시험 — 소개의 구 그림·갈래 링크에 수성, 수성 화면에서 지구로 가는 길. 휴대폰 화면 시험(소개 포함) 통과
- 헤드리스 크롬 — 수성 구에 도폭 경계와 이름표, 평면에서 경계 점선. 소개의 우주 장면 넷째 단계에 수성이 크게, 갈래에
  수성 카드. 페이지 오류 없음
