그쪽에서 찾았다.

## 2. "벡터" 가 두 뜻이었다 — `vector` 와 `points` 로 가른다

019 와 020 이 서로 모른 채 둘 다 `/vector/` 와 `vectorLayerFor` 를 만들었다.
하는 일은 다르다.

- 단층(020) — VWorld 에서 **위경도 1° 칸**으로 선을 받는다. 화면이 움직이면
  칸을 더 받는다
- 포털의 점(019) — 레이어 하나를 **통째로 한 덩이**로 받는다

한 이름이 두 뜻을 겸하면 안 된다 (CLAUDE.md "말을 고르는 규칙"). 그래서
`kind: vector`(`/vector/`, `vectorLayerFor`)와 `kind: points`(`/points/`,
`pointLayerFor`)로 갈랐다. 얀마옌(022)은 면·선도 `points` 로 실었다 — 한 덩이로
받는 쪽이 같기 때문이다. 이름은 점이지만 속은 "한 덩이로 받는 모양" 이다.

## 3. 받아 그리는 파일은 `db/` 아래에 둔다

GeoMAP(018)·얀마옌(022) 갈래는 `/srv/GSM/geomap`·`/srv/GSM/npolar` 를 새로
마운트하자고 했다. **그 길은 막혀 있다** — 운영의 `docker-compose.yml` 은
root 의 것이라 우리가 못 고친다 (HANDOFF "배포한 자리에서 알아둘 것").
2026-09-23 에 이것으로 세 번 걸렸다.

다행히 두 설정 모두 기본값이 `<DB 옆>/geomap`·`<DB 옆>/npolar` 다. `db/` 는
이미 붙어 있고 우리가 쓸 수 있다. 그래서 마운트 제안을 되돌리고 파일을
`/srv/GSM/db/geomap/`·`/srv/GSM/db/npolar/` 에 두었다. 환경변수도 compose 도
건드리지 않고 판만 바꿔 올리면 된다. 원본은 NAS `N:\GSM\sources\` 에 둔다.

## 4. 가끔 깨지던 시험 — gzip 의 무작위 덧대기

`test_grportal.View.test_줄여서_보낸다` 가 전체를 돌리면 가끔 깨졌다.
`--shuffle` 의 같은 씨앗으로 다시 돌려도 붙었다 — 차례가 아니라 **값이 흔들리는
것**이다.

Django 의 `gzip_page` 는 BREACH 를 막으려고 줄인 본문에 **무작위 바이트를 덧대고,
줄인 쪽이 더 길면 줄이지 않는다.** 빈 점 목록은 본문이 짧아 덧댄 만큼 길어지는
때가 있었다. 점 50 개를 실어 본문을 넉넉히 하니 붙는다. 짧은 응답의 압축을
시험할 때는 이것을 기억한다.

## 5. 이미지에 에이전트 worktree 가 딸려 들어갔다

v0.7.0 이미지를 올린 뒤 `manage.py` 를 찾다가 `/app/.claude/worktrees/` 를 보았다.
에이전트 여섯의 작업 자리(34 MB)가 이미지에 들어가 Docker Hub 에 올라갔다.

- **샌 것은 없다.** 든 것은 테이블 하나 없는 빈 `GSM.db` 다섯과, GitHub 에
  이미 공개된 코드 사본뿐이다. 열쇠(`/srv/GSM/db/*_key`)는 저장소 밖에 있어
  worktree 에 복사되지 않는다
- 원인은 둘이다. `.dockerignore` 에 `.claude/` 가 없었고, **맨 `*.db` 는 맥락의
  뿌리에만 맞는다** — 하위 폴더의 DB 를 거르려면 `**/*.db` 라야 한다
- `.dockerignore` 를 고쳤다(`2c93fbb`). v0.7.0 이미지는 그대로 두고 다음 판부터
  줄어든다. 이 저장소는 public 이미지를 굽는다 — **굽기 전에 맥락에 무엇이
  들어가는지 한 번 본다** (`.env` 를 구울 뻔한 2026-09-23 과 같은 교훈이다)

컨테이너 안의 `manage.py` 는 `/app/web` 에 있다. `docker exec -w /app/web …` 로
부른다. HANDOFF 에 적은 명령도 그렇게 고쳤다.
