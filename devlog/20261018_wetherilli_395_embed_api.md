# 담긴 화면의 API — 형제 앱이 점·부채꼴을 얹고 누른 자리를 받는다

2026-10-18 · `feature/embed-api` · wetherilli

Cropobite 사용자: 「지금 GSM 외 다른 지도 띄우는 곳들 다 GSM으로 고쳐줘」. Cropobite 는 장소·노두 목록에서 이미 GSM 을 담는다(393) —
`#ext` 로 색 점을 넘기는 것까지다. 남은 다섯 곳(탐사·사진 화면의 **방위 부채꼴**, 노두·장소 고치기의 **지도를 눌러 위경도 넣기**,
권역 화면의 노두 지도와 카드 연동)은 `#ext` 로 안 된다. 지도 객체가 `map.js` 의 함수 안에 갇혀 있어, 같은 출처여도 감싼 쪽이 손을 댈 수 없다.

## 무엇을

**iframe 안일 때만 `window.GSMEmbed` 가 생긴다.** 지도 화면만 SAMEORIGIN 이라(393) 감싼 쪽은 같은 사이트다 — postMessage 를 거치지 않고
`frame.contentWindow.GSMEmbed` 를 곧장 부른다. 좌표는 언제나 위경도.

| | |
|---|---|
| `layer(id, items, {source, labels})` | 점을 얹는다(같은 id 면 바꾸고 null 이면 걷는다). 점 = `{id, lon, lat, color, heading, big, faded, name, note, url}`. `heading` 이 있으면 그쪽으로 벌어진 부채꼴(반각 30°), 지도를 돌리면 함께 돈다. 5 000 점까지(`EXT_MAX`) |
| `fit(ids, {maxZoom, padding})` · `view(lon, lat, zoom)` | 맞추기 |
| `highlight(id)` | 점 하나를 밝힌다 — 감싼 쪽의 썸네일에 마우스를 올렸을 때 |
| `on("hover", fn)` · `on("click", fn)` | 점 위의 마우스, 점 누르기. click 이 true 를 돌려주면 팝업을 띄우지 않는다 |
| `pick({lon, lat}, fn)` | 위경도 고르기 — 지도를 누르거나 표시를 끌면 `fn({lon, lat})`. `pick(null)` 로 그만둔다. 재기·점 찍기 중에는 넘기지 않는다 |
| `compact()` | 좁은 칸 — 패널·좌표 막대·손잡이·띠를 걷고 대기 화면을 바로 치운다(기억하지 않는다) |

팝업은 `#ext` 의 것(`extPart`)과 같은 꼴 — 이름·메모·「…에서 열기」(`_top`). 투영이 바뀌면 받아 둔 위경도에서 다시 그린다(`drawEmbed`).

## 함께 고친 것

- **담긴 지도는 그 사람의 기억을 덮지 않는다.** 링크(해시)가 없어도 덧층(`GSMShare.store({})`)에만 쓴다 — 감싼 쪽이 `view`·`fit` 할
  때마다 `saveView` 가 그 사람의 GSM 자리를 바꿨다. 레이어·배경을 고른 것도 그렇다.
- **담긴 지도에는 「링크로 연 화면이다」 띠를 띄우지 않는다.** 감싼 쪽이 주소를 지었고, 좁은 칸에서는 띠가 지도 가운데를 덮어
  누르기를 가로챘다(시험이 잡았다).
- **`map.css` 의 빠진 `}`** — 아프리카 밝은 테마(207)의 블록이 닫히지 않아 **그 뒤의 규칙이 모두 그 안에 갇혀 있었다.** 브라우저는 CSS
  중첩으로 읽어 `:root[africa][light] :root[italy]` 처럼 아무것에도 걸리지 않는다 — 이탈리아(211) 뒤 지역의 테마 색이 그동안 서지 않았다.
  `compact()` 의 규칙을 끝에 붙였더니 걸리지 않아 찾았다. `test_css` 가 스타일 파일마다 중괄호의 짝을 본다.

## 버린 것

- **postMessage 로 주고받기** — 다른 출처를 받을 일이 없다(SAMEORIGIN). 같은 출처면 곧장 부르는 편이 짧고, 돌려받는 값(`layer` 의 점 수)도 바로 온다.
- **`#ext` 를 넓히기**(GeoJSON 속성에 heading, 해시에 pick) — 고르기는 결과를 돌려받아야 하고, 썸네일 연동은 오가는 신호가 잦다. 해시로는 한 번만 넘긴다.
- **OpenLayers 객체(`map`)를 그대로 내놓기** — 감싼 쪽이 GSM 의 속(투영·레이어 쌓기·팝업)에 기대게 된다. 판이 바뀌어도 지킬 좁은 문만 연다(`version: 1`).

## 시험

`EmbedApi`(휴대폰 화면 시험의 반) — 소개 화면을 바깥으로 열고 그 안에 지도를 담아: 혼자 열면 없다 · 점을 얹고(위경도 없는 점은 건너뛴다)
누른 점을 넘기고 팝업은 안 뜬다 · 마우스를 올린 점을 넘긴다 · 좁은 칸에서 지도가 칸을 다 차지한다 · 위경도 고르기와 그만두기.
`test_css` — 중괄호의 짝. 둘 다 고침을 빼면 실패한다(빠진 `}` 를 되살리면 둘 다 깨진다). 전체 `viewer` 2 292 통과.
