# 3D 가 늦게 실패한 타일 뒤에 뜨지 않던 것 — 휴대폰 시험이 가끔 깨진 까닭

2026-10-06 · `fix/phone3d-cold-start` · jikhanjung

## 1. 왜

`test_mobile.Phone3D.test_점을_누르면_팝업이_화면_안이다`(wetherilli 362)가 생긴 10/05 뒤로 휴대폰 job 이 자주 깨졌다 —
#364·#365(판 0.70.0)와 `main` 세 번. 늘 같은 자리, 3D 의 첫 화면 신호 `window.__gsm3dReady`(`map.on("load")`)를 15 초
기다리다 넘긴 것이다.

## 2. 처음의 진단은 틀렸다

이 시험은 매번 병렬 갈래의 첫 시험이고, 실패한 날은 job 전체도 느렸다(168–173 초 대 134–169 초). 그래서 **느린 러너가
크롬·SwiftShader 의 첫 시동을 15 초 넘게 끈다**고 보고 기다림을 60 초로 늘리고, 넘기면 상태·콘솔을 적게 했다(사람도
"워커가 종종 느려진다" 고 짚었다). 그 PR(#366)의 첫 CI 가 **60 초를 기다리고도 깨졌고**, 적어 둔 상태가 까닭을 말했다 —

```
상태 {'map': True, 'styleLoaded': True, 'loaded': True, 'webgl': True}
```

지도는 다 떴는데(`loaded()` 참) 신호만 없다. 느린 것이 아니라 **`load` 가 오지 않은 것**이다.

## 3. 원인 — MapLibre 4.7.1 의 경합

- `load` 는 그리기(`_render`) 안에서 `this.loaded() && !this._loaded` 일 때 쏜다
- 타일이 **성공**하면 소스가 `data` 를 내고 지도가 다시 그린다. **실패**하면(404 말고) 타일을 `errored` 로 두고 `error` 만
  낸다 — **다시 그리지 않는다**(번들의 `_loadTile` 에서 확인)
- 그래서 **마지막 타일이 마지막 그리기보다 늦게 실패하면** `loaded()` 는 참이 되는데 그리기가 더 돌지 않아 `load` 가 영영 오지 않는다
- 시험은 바깥 요청을 다 끊으므로(모든 타일이 실패) 순서가 그때그때라 가끔만 깨졌다. job 이 느린 날 더 자주 그 순서가 됐을 뿐이다
- **운영에서도 일어난다** — 상류 지형·지질 타일이 실패로 끝나면 지형(`setTerrain`)·점묶음·개인 레이어가 사람이 지도를
  움직일 때까지 안 뜰 수 있었다

## 4. 무엇을 정했나

1. **`map3d.js` — `error` 마다 `map.triggerRepaint()`** 한 번. 다음 그리기에서 `loaded()` 가 참이면 `load` 가 간다. 처리기를
   달면 MapLibre 가 콘솔에 오류를 찍지 않으므로 `console.error(e.error)` 로 그 일도 대신한다
2. **회귀 시험** `Phone3D.test_늦게_실패한_타일에도_3D_가_뜬다` — 첫 지형 타일을 2.5 초 붙잡아 실패를 첫 그리기 뒤로
   미룬다(동기 API 라 그 사이 다른 요청도 줄을 서서 다 함께 늦게 실패한다). 고치기 전 코드로 두 번 다 깨졌고, 고친 뒤 세 번 다 지났다
3. 기다림은 **15 초 그대로** 둔다 — 느린 것이 원인이 아니었다. 넘기면 상태(지도·스타일·`loaded()`·WebGL)와 콘솔 끝 여덟 줄을
   실패 글에 적고(이번에 원인을 짚은 것이 이것이다), 걸린 초를 늘 기록에 남긴다(`3D 첫 화면 N 초`). 그러려고 `open()` 이 콘솔을 받아 둔다

## 5. 버린 것

- 기다림만 늘리기 — 위 2 절. 60 초로도 깨졌다
- `load` 대신 `idle` 을 기다리기 — `idle` 도 그리기 안에서 쏘므로 같은 경합에 걸린다
- 시험에서 타일을 끊지 않기 — 상류로 나가게 되고, 운영의 같은 경합을 덮어 버린다
- 달·화성·수성·온 지구 화면 — Cesium 이라 이 경합이 없다. 2D 는 OpenLayers 라 `load` 를 기다리지 않는다

## 6. 확인

- 늦은 실패를 만든 실험에서 고치기 전 `{'loaded': True, 'ready': False}`(CI 의 실패와 같다), 고친 뒤 `ready: True`
- 로컬 휴대폰 시험 전체(`--parallel 4`) 28 개 통과, 기본 시험 2 031 개 통과
