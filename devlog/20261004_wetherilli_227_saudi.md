# 사우디아라비아 — SGS 1:25만 합본, 보는 범위의 범례

2026-10-04 · `feature/saudi` · wetherilli

`docs/아시아_오세아니아_지질도.md` 의 추천 순서 여섯째. 속성이 이번 갈래에서 가장 넉넉하다.

## 1. 문 — `sgs.py`

- 상류는 SGS 국가 지질 자료(NGD)의 `Geology/Geology_250K` 하나 — WMS 와 REST 가 다 된다. 주소는 NGD 의 1:25만 안내 페이지 소스에서 찾았다
- **WMS 레이어는 이름으로 부른다** — `Geology_250K_Standard`. 번호 `0` 은 `LayerNotDefined` 다. 다른 ArcGIS 문이 번호로 부르는 것과 다르다
- 원본이 3857 이라 다시 투영하지 않는다(512² 한 장 3.3 초). **나라 전체가 아니다** — 서부(아라비아 순상지)와 둘레의 1:25만 도폭을 이어 붙였다.
  동부의 퇴적 분지는 비어 있다
- 속성은 geojson 이 모양 없이 2 KB 로 온다 — 영어 열 40 남짓. 팝업에는 기호·이름·주 암상·기(ICS)·나이(Ma)·지구조(Terrane·Sub_Terane)·도폭을 보인다
- **속성은 하나만 묻는다**(`feature_count=1`) — 도폭을 이어 붙인 합본이라 경계에서 같은 단위가 겹쳐 셋씩 왔다(알히수 도폭)
- **버린 것:** 아라비아 순상지 1:100만(`gis.sgs.org.sa`) — 이름 풀이가 안 된다. `gis.taadeen.sa` 의 WMS — 이름 있는 레이어가 없다

## 2. 범례 — 보는 범위의 것

REST `legend` 는 1 337 칸에 700 KB 다. 통째로 목록을 내면 쓸 수 없다. 칠하기 규칙이 `Symbol`·`Label` 두 열이라, 호주(wetherilli 212)처럼 보는
범위의 단위를 그 둘(과 `Period`)로 묶어 센다 — REST `query` 의 통계. 2° 네모가 142 칸·6.6 초, 1.5° 가 4.9 초였다. 그래서 3° 안에서만 뜨고 60 칸에서
끊는다(나머지는 "더" 로 센다).

견본은 무늬 채움이 많아 색 하나로 나타낼 수 없다 — `legend` 의 그림을 한 번 받아 `Symbol: Label` 로 찾는다. 700 KB 라 30 일에 한 번만 받는다.
통계와 견본은 같은 이름 짝(`Qu` + `Quaternary sand, …`)으로 이어진다.

## 3. 탭

- 지역 `saudi`(3857). 묶음에는 넣지 않았다 — 이웃(요르단·오만·아랍에미리트)은 서비스가 없거나 막혀 있다(docs)
- 3D 는 원본이 3857 이라 `MAP3D_WMS` 에 넣었다
- 색은 홍해 산호의 청록 — 바탕을 붉은 사막 모래로 두어 오세아니아(석호 청록)와 가른다
- 마이그레이션은 `0037_region_saudi` — #210 의 0036 뒤
