# 남극 고지형 3D 를 Cesium 으로 — 남극점까지 선다

2026-11-10 · `feature/paleo3d-cesium` · wetherilli

## 왜

441·442 로 3D(MapLibre)에 Gernon 고지형을 세웠는데, 사람이 보고 "도법을 남극점 중심으로 잡아야 했다" 고 했다.
**3D 는 웹 메르카토르 하나뿐이다.** 그래서 남위 85.06° 너머(남극점 둘레 반경 550 km)를 아예 그리지 못한다.
Gernon 격자(3031 의 x −1 000~+2 000 km, y −500~+2 500 km)는 남극점을 품으므로 격자의 1할쯤이 빈다.
동서로도 늘어난다(남위 70° 에서 2.9 배, 80° 에서 5.8 배). 품을 잴 때 이것을 먼저 말했어야 했다.

MapLibre 5 의 둥근 지구로 올려도 타일 자체가 메르카토르라 극의 빈자리는 그대로다. 그래서 **Cesium** 으로 갔다 —
달·화성·온 지구 화면이 이미 경위도(4326) 격자로 극까지 세운다.

## 무엇을 골랐나

- **3D 를 갈아엎지 않고 화면을 하나 더했다**(`/GSM/paleo3d/`). 3D 의 고지형(441·442)은 그대로 두고, 3D 패널에서
  "남극점 중심으로 보기" 로 건너온다. 3D 는 지질도·점묶음·내보내기 따위가 얽혀 있어 통째로 옮기면 일이 몇 곱이다
- **땅** — `paleo3d/dem/<연대>/<z>/<x>/<y>.png` 가 Cesium 의 높이 격자 그대로 65×65 Terrarium 을 낸다. 달(036)과 같은 꼴이다.
  고지형 격자는 441 의 `_gernon_grid`(값×무게, 가장자리 100 km 섞기)를 그대로 쓰고 MESH 만 경위도로 짓는다.
  격자 밖은 오늘의 IBCSO 빙저, 그것도 없으면 0 m 다 — **AWS 로 넘기지 않는다**. AWS 는 메르카토르라 극을 못 채우고, 남위 50° 북쪽은 화면이 묻지도 않는다.
  `paleo3d/dem/today/` 는 오늘의 빙저만 — 견주어 보려고 "땅" 고르개에 두었다
- **색** — `geo/<상류>/<판>/` 은 `warp/` 의 짝이다. 같은 원본(2D 의 3031 타일)을 Cesium 의 경위도 격자로 편다.
  `warp.Scheme` 하나로 3857 과 경위도를 가르고, 3D 의 `warp/` 는 손대지 않았다(캐시 열쇠도 그대로)
- **등고선·빙상 범위** — 2D·3D 와 같은 덩이(`points/?layer=&age=`)를 `GeoJsonDataSource` 로 땅에 붙인다. 색·굵기는 덩이의 범례 그대로다.
  땅에 붙인 면은 테두리를 못 그어 둘레를 선으로 따로 긋는다
- **연대 막대·▶** — 2D·3D 와 같은 꼴, 같은 기억(`gsm.paleoage`). ▶ 는 `globe.tilesLoaded` 까지(길어야 10 초) 기다린 뒤 다음 칸으로 간다.
  새 연대의 색 겹은 땅이 다 선 뒤에 옛 겹을 걷는다 — 재생할 때 깜빡이지 않게
- **시점 둘** — "남극점 위에서" 는 곧장 내려다보며 0° 가 위다(2D 의 3031 과 같은 방향). "비스듬히" 는 격자 가운데(남위 81°, 동경 27°)를 북쪽 바다에서 본다

## 걸린 것

- **극의 타일이 비었다.** 경위도 타일의 땅 해상도를 경도 쪽(cos 위도)으로 쟀더니 극 가까이서 원본 단계를 너무 촘촘히 골라
  원본 타일이 36 장을 넘었고(`_plan` 이 None), 빈 타일이 나갔다. 경위도 격자는 위도 쪽 간격으로 잰다(`_geo_meters`)
- 경위도 줌 0·1 은 반구를 덮어 모서리가 적도까지 간다 — 극지 격자(`Grid.north`)는 자료 북쪽 끝(남위 48°)으로 모서리를 접는다. 메르카토르 쪽은 그대로다

## 버린 것

- MapLibre 5 의 둥근 지구 — 극이 여전히 빈다
- 3D 를 Cesium 으로 통째로 — 위와 같은 까닭
- Bedmap3 을 땅으로 — 이번에는 IBCSO 빙저(500 m)로 둔다. 필요하면 따로 잰다

## 남은 것

- 5 km 격자라 가까이서는 거칠다(441 과 같다)
- Cesium 은 소프트웨어 WebGL(헤드리스)에서 느리다 — 시험은 요청이 나가는지만 보고 그림은 사람이 본다
