# 온 지구 — 그때의 자리를 EarthThruTime3D 에서 본다

2026-09-30 · `feature/ett-link` · wetherilli

P06 의 셋째 단계(§4)다. 사람이 "그 다음에 ETT 와 연결해보자" 고 했다. 온 지구 팝업의 "그때의 자리" 에 ETT 의 고지리
지구본을 여는 링크를 단다. 대돌여지도는 그 자리가 어디였는지 좌표로 적고, ETT 는 그때의 땅·바다·기후 위에 핀을 세운다.

## 1. 주소 하나만 넘긴다

ETT 는 보기를 주소에 담는다(ETT `docs/site-map.md`). `pin=경도,위도` 는 **오늘의 좌표**이고, ETT 가 PALEOMAP 2016 으로
옮긴다(`restorePins` → `pinAt(…, 0)`). 우리도 같은 모델·같은 줄임으로 옮기므로(087) 새로 넘길 것이 없다 — 오늘의 좌표와
연대뿐이다. 자료는 넘어가지 않는다. 링크라서 CLAUDE.md 의 "상류마다 문이 하나" 에도 걸리지 않는다.

- 연대 ≤ 540 Ma 는 **고도 격자**(`masks=paleodem2018`, PaleoDEM)로 연다. 지형·기온·해수면이 거기에만 있다
- 그보다 오랜 연대는 **기본 판**(PaleoAtlas 육지 마스크, 750 Ma 까지)으로 연다. 750 Ma 너머는 ETT 가 판 재구성만 보인다
- ETT 는 연대를 가장 가까운 시점에 맞춘다(700 → 705 Ma). 그 차이는 ETT 화면의 몫이라 우리가 맞추지 않는다

## 2. 어디에 다나

- 단위 표의 끝 — Macrostrat 단위의 윗·밑 연대 가운데 **옮겨진 것만**(서버가 `then` 으로 준다). 볼더의 화강암
  (2500–1600 Ma)처럼 판이 닿지 않는 연대에는 링크를 달지 않는다. 가 봐야 ETT 에도 핀이 없다
- "그때의 자리" 칸 — 넣은 연대로 옮겨지면 결과 옆에

## 3. 확인한 것

- 헤드리스 크롬 — 서울을 눌러 541 Ma 링크, 칸에 700 을 넣어 `?age=700&pin=-105.30,40.00`
- ETT 운영에서 `?masks=paleodem2018&age=250&pin=126.98,37.57` 을 열었다. ETT 의 핀 목록에
  "오늘 37.6°N 127.0°E · 판 604 · 지금 30.6°N 105.0°E" 가 섰다. 우리가 적은 "북위 30.58° · 동경 105.01°"(판 604)와 같은
  자리다
- 시험 — 옮겨진 연대만 `then` 에 든다
