# 현장 기록 — 내 위치를 개인 레이어에 적는다

2026-10-16 · `feature/field-record` · wetherilli

사용자가 "휴대폰에서 내 위치를 지도에 점으로 찍고 싶다 — 기록을 하고 싶다는 말" 이라고 했다. 380 의 "내 위치" 는 파란 점을
띄워 따라갈 뿐 아무것도 남기지 않는다. 그래서 "자세" 묶음의 내 위치 옆에 **기록** 단추를 두었다. 내 위치를 켠 동안만 뜬다.

누르면 메모 한 줄을 묻고, 누른 때의 자리·시각(시간대를 붙인 지역 시각)·GPS 오차·GPS 고도·그 자리의 지질 단위를
개인 레이어 **"현장 기록"** 하나에 한 점씩 쌓는다. 레이어가 없으면 생긴다. 기록한 점은 지도에 개인 레이어로 서고, 이름표는 메모다.

## 왜 개인 레이어인가

**GPS 는 보안 연결에서만 잡힌다** — 380 이 평문 http 인 연구소 판에서는 단추를 숨긴다. 휴대폰에서 GPS 가 도는 곳은
https 인 정적 판(GitHub Pages)이고, 거기에는 서버가 없다. 그러니 서버의 점묶음(`pointsets/create/`)으로는 적을 수 없다.
사람이 셋 가운데 **휴대폰 안 개인 레이어**를 골랐다(2026-10-16) — 망 없이도 남고, 오프라인 묶음(381)과 같은 자리(현장)에서 돈다.

- 버린 것 — 서버 점묶음. 연구소 서버에 https 를 붙이는 배포 일이 먼저 있어야 한다
- 버린 것 — 둘 다(휴대폰에 쌓고 서버 판에서 올리기). 개인 레이어를 점묶음으로 옮기는 길은 관리 화면에서 내려받아 올리면 된다

## 꺼내는 길

정적 판에는 관리 화면(`/GSM/manage/`)이 없다 — `.server-only`. 그래서 지도의 개인 레이어 줄마다 **CSV 내려받기(⤓)** 를 달았다.
글은 관리 화면과 같은 `Personal.toCSV` 다 — 다시 반입하면 그대로 읽힌다.

## 지질 단위

지도를 눌렀을 때 켠 레이어에 속성을 묻던 코드를 `readLayers(coordinate)` 로 떼어 기록이 함께 쓴다. 망이 없으면 그 길이 이미
오프라인 묶음의 지층 면(384)으로 떨어진다. **10 초만 기다린다** — 현장의 느린 망에 기록이 붙잡히면 안 된다. 늦으면 비우고 적었다고 알린다.
속성은 "레이어 — 키: 값; …" 한 칸의 글로 줄인다(레이어마다 여섯 칸, 모두 1 000 자). 열을 레이어마다 따로 두면 상류마다
칸 이름이 달라 표가 끝없이 넓어진다.

- 자리는 **누른 때의 것으로 못박는다** — 메모를 적는 동안 GPS 가 움직여도 기록은 누른 자리다
- 어디에도 보내지 않는다. 지질 단위를 묻는 요청은 지도를 누를 때와 같다(그 자리의 좌표가 상류로 간다)
