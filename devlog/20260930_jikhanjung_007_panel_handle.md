# 패널 접는 손잡이, 자세 기호 체크를 색 글자로

2026-09-30 · `feature/panel-handle` · jikhanjung

## 1. 왜

사람이 둘을 청했다. **왼쪽 패널을 접어 지도를 넓게 보는 길** — 패널 오른쪽 가장자리 가운데쯤에 옆으로 튀어나온 작은 손잡이,
안에는 `<` 하나, 접히면 `>`. 그리고 5만 지질도 카드의 체크 넷(005)에서 **"자세 기호" 문구와 색 막대를 없애고 글자를 그 색으로.**

## 2. 무엇을 정했나

1. **손잡이는 지도 칸(`#map-wrap`)의 왼쪽 가장자리에 붙인다** — 패널 안에 두면 패널과 함께 사라져 다시 펼 길이 없다. 지도 칸에
   붙이면 펴져 있을 때는 패널 가장자리에서 튀어나온 것으로 보이고, 접으면 화면 왼쪽 끝에 남는다
2. **가운데보다 조금 위(`50% - 120px`)** — 정확히 가운데에는 서쪽 가장자리의 경도(`122.6364°E`)가 뜬다. 처음에 `-64px` 로 두었더니
   겹쳤다
3. 접으면 패널을 `display: none` 으로 — 폭을 0 으로 줄이며 미끄러지게 하는 것은 지도 크기를 매 순간 다시 재야 해서 버렸다. 접고 편
   뒤 `map.updateSize()` 와 가장자리 좌표를 한 번 다시 그린다. 나란히 비교(`map2`)도 함께 잰다
4. 접어 둔 채인지는 이 브라우저가 기억한다(`gsm.panelFolded`). 좁은 화면(≤ 760 px)은 패널이 지도 위에 쌓이는 꼴이라 옆으로 접을
   것이 없다 — 손잡이를 숨기고 접힌 상태도 무시한다
5. **지구 지도 화면(`map.html`)에만.** 달·화성·온 지구 화면은 CSS 를 같이 쓰지만 JS 가 따로라 이번에는 두지 않았다 —
   쓸모가 보이면 같은 틀로 옮긴다
6. 체크 글자의 색은 지도 위 기호의 색(층리 빨강·엽리 파랑·편리 보라·절리 초록)과 같은 색조이되, **어두운 패널에서는 조금
   밝게** 했다 — 기호의 짙은 빨강(#b3261e)·파랑(#1f5fa8)은 먹갈색 바탕에서 안 읽힌다. 밝은 판(`data-theme="light"`)에서는
   기호 색 그대로다. "자세 기호" 문구가 빠져도 카드 안의 네 낱말이 무엇인지는 끌어 올렸을 때의 풀이(title)가 말한다

## 3. 확인

- 시험 847 개 통과
- 헤드리스 크롬: 손잡이 `<` 를 누르면 패널이 접혀 지도 폭 940 → 1280, 손잡이가 `>` 로. 새로 고쳐도 접힌 채, 다시 누르면 940.
  손잡이가 서쪽 경도 표시와 겹치지 않는다. 체크 넷이 어두운·밝은 판에서 제 색 글자로. 콘솔 오류 없음
