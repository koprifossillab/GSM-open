# 휴대폰 화면 — 접히는 패널, 아이콘 한 줄, 접힌 범례

2026-10-01 · `feature/mobile-layout` · wetherilli

사람이 "모바일 화면을 지원하냐" 고 묻고 전반을 손보자고 했다. 0.30.0 을 390×844(터치)로 열어 보니 소개 말고는
**열리기만 했다** — 2D 는 패널이 위 44% 를 늘 차지하고 오른쪽 손잡이 두 묶음이 남은 지도의 1/3 을 덮었다. 3D 는
판이 화면을 거의 다 덮었고, 온 지구·달·화성은 패널 밑에서 범례와 시간 축이 구를 덮었다. 터치로 2D 를 열면
스크립트 오류도 났다(`toLonLat` 에 null).

## 정한 것

- **패널은 접히고, 휴대폰에서는 접힌 채로 연다.** 접으면 머리(이름·지역 탭)만 남고 지도가 나머지를 다 쓴다. 손잡이는
  데스크톱에서 지도 칸 왼쪽 가장자리의 탭(jikhanjung 007)인데, 휴대폰에서는 지도 칸 위 가운데로 옮겨 ▾·▴ 로 쓴다.
  기억 열쇠(`gsm.panelFolded`)는 데스크톱과 같다 — 브라우저마다 따로 남으니 섞일 일이 없고, 적힌 것이 없을 때만
  화면 폭으로 고른다. 2D·온 지구·달·화성 네 파일에 같은 줄을 넣었다
- **손잡이 묶음은 이름표를 떼고 아이콘만, 한 줄로.** 이름은 `title` 에 이미 있다. 접혔을 때는 "자세" 를 위에, "도구"
  를 밑에 세로로 쌓고, 펴서 지도가 낮아지면 예전처럼 옆으로 둔다. 구 화면의 자세 이름표 몇이 맨 글자라 `<span>`
  으로 감쌌다 — 그래야 CSS 하나로 숨는다
- **범례는 휴대폰에서 접힌 채로 연다**(구 화면 셋). 편 채로 둔 기억이 있으면 그것을 따른다. 온 지구에서는 시간 축
  위로 올린다
- **3D 판은 데스크톱에서도 접힌다** — 머리의 단추 하나. 휴대폰은 접힌 채로 연다. 끌기 안내는 마우스 대신
  손가락 말(두 손가락으로 기울이고 비튼다)을 `pointer: coarse` 일 때 띄운다
- **화면 높이는 `dvh`** — 휴대폰 주소창이 들고 나며 `100vh` 가 화면보다 길어 아래 좌표 막대가 잘린다
- 좌표 막대는 한 줄로 두고 좌표계 고르기를 좁혔다. 남쪽·동서 가장자리 좌표는 축척 막대와 부딪혀 휴대폰에서 뺐다 —
  북쪽 하나는 남는다
- **`toLonLat` 오류** — `renderEdges` 가 첫 그림 전에 불려 `getCoordinateFromPixel` 이 null 을 줬다. 휴대폰에서는
  크기가 먼저 정해져 그 틈이 생긴다. 첫 그림 전에는 읽지 않는다

## 버린 것

- **패널을 아래에서 끌어 올리는 서랍(bottom sheet)** — 손가락으로 끄는 높이 셋을 두면 지도 끌기와 손짓이 겹치고,
  패널 안의 굴림과도 다툰다. 위에 쌓고 접는 것은 데스크톱의 접기를 그대로 옮긴 것이라 말이 하나다
- **손잡이 묶음을 접는 단추 하나로 감추기** — 점 찍기·재기가 한 번 더 눌러야 나온다. 아이콘만으로 40px 한 줄이면 자리가 된다
- 관리 화면·소개는 이미 좁은 화면 규칙이 있어 두었다
