# 화성·수성의 높이 그래프

2026-10-02 · `feature/planet-profiles` · wetherilli

잰 선을 따라 높이 그래프를 화성과 수성에도 — 달(wetherilli 100)의 것을 옮겼다. 판 세션이 맡긴 TODOs "표고 단면 — 화성 남음"
이고, 수성은 같은 틀이라 한 PR 로 묶었다.

## 한 것

- **서버** — `trek.profile(vertices, n, body)`. 몸마다 반지름·표고 읽기·출처가 다를 뿐이라(`_profile_body`) 함수를 셋 두지
  않았다. 거리는 화면의 구와 같은 반지름으로 잰다 — 화성 3 396.19 km, 수성 2 439.7 km. 그래야 그래프의 가로가 화면이 잰
  거리와 같다. 높이는 점묶음의 ⛰ 와 같은 `mars_values`(MOLA–HRSC 200 m, 아레오이드)·`mercury_values`(MESSENGER 665 m,
  2 439.4 km 구)다. 주소는 `mars/profile/`·`mercury/profile/`, 달의 뷰와 한 함수(`_body_profile`)를 쓴다
- **화면** — `moon.js` 의 그래프 코드를 `mars.js`·`mercury.js` 에 그대로 옮기고 주소·점 간격(표고 판 한 칸에 한 점 — 화성
  200 m, 수성 665 m)·설명 줄만 바꿨다. 세 파일을 나란히 고치는 짐은 그대로다
- **지질 띠는 넣지 않았다** — 점마다 상류(Trek)의 속성을 묻게 되어 호출 제한(010)과 부딪힌다. TODOs 에 남겼다

달의 뷰에서 바뀐 것 하나 — **점이 하나도 읽히지 않은 그래프는 캐시에 담지 않는다.** 지구(109)가 이미 그렇게 했다. 상류가
잠깐 비었을 때의 빈 그래프가 굳지 않게.

## 확인한 것

- 시험 — 몸마다 반지름으로 잰 거리·출처, 주소, 같은 선은 캐시, 빈 그래프, 꼭짓점이 하나면 400
- 헤드리스 크롬(실제 Trek) — 화성: 게일 크레이터를 가로지른 129 km 선이 바닥 −4.5 km 에서 샤프 산(+0.3 km)으로 오른다.
  수성: 쿠이퍼 크레이터를 지난 127 km 선. 꼴이 "테–바닥–테" 가 아니라 이상해 보였는데, 표고 판을 영상과 맞대 보니 맞았다 —
  쿠이퍼 남동쪽에 겹친 더 큰 옛 분지의 바닥을 선이 지나간 것이다
