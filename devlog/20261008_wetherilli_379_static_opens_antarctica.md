# 정적 판은 남극으로 연다

2026-10-08 · `feature/static-antarctica-default` · wetherilli

공개 정적 판(GitHub Pages)은 열자마자 한국 탭을 띄우고 KIGAM·VWorld 키 창을 내밀었다(174). 그런데 키가 드는 것은 한국 지질도와
VWorld 배경·찾기뿐이고, 정적 판에 실린 나머지 — 남극·그린란드·스발바르·북극해 — 는 키 없이 다 보인다. 처음 온 사람이 키부터
받아야 하는 것처럼 보이는 문을 거두려고 사람이 "남극을 기본으로" 정했다.

- **처음 여는 지역** — `STATIC` 이면 `region` 의 기본을 `antarctica` 로. 돌아온 사람은 여전히 지난번 지역(`gsm.region`)으로 연다.
  연구소 판은 그대로 한국이다
- **키 창은 키가 드는 지역에 들 때만** — `askStaticKeys()` 를 열 때와 `switchRegion` 끝에 부르고, 지역이 `vworld`(한국·동아시아)일 때만
  묻는다. "나중에" 의 탭 동안 기억은 그대로다. 넣어 둔 KIGAM 키가 안 받힐 때 창을 띄우는 것도 그 지역에서만
- **소개 화면** — 정적 판에서는 "지도로 바로 가기" 와 첫 장면이 남극 지도를 가리키고, 실리지 않은 지역으로 가던 장면도 남극으로 돌린다

버린 것 — 탭 줄에서 한국을 빼는 것. 키를 넣으면 한국 지질도가 그대로 돌고, 탭 줄(한국·북극·남극)은 연구소 판과 같게 둔다.
