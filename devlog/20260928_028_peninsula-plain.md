# 028 — 한반도 지질도 민판: 월드파일이 붙어 왔는데 또 고쳐 쓴 까닭

2026-09-28 · sclee · NAS `KimSunho/` 에 `geomap_new_5179.png`·`.pgw` 가 새로 들어왔다
(2026-09-22). "커스텀 지질도" 에 **한반도 지질도 (음영 없음)** 으로 얹었다.

## 1. 무엇이었나

027 음영판과 같은 지도에서 **음영기복을 뺀 판**이고, 월드파일이 5179 를 적었다.

| | 음영판 (027) | 민판 (이것) |
|---|---|---|
| 원본 | Geospatial PDF 속 JPEG | **무손실 PNG** + `.pgw` |
| 화소 | 9975×17310, 한 화소 59 m | 8865×12403, 한 화소 85 m |
| 범위 | 5179 x 697–1283 km · y 1546–2564 km | x 616–1366 km · y 1512–2562 km — 쓰시마·중국 해안선의 가는 선까지 든다 |
| 제주 | 없다 | 없다 (남쪽 끝 북위 33.5°) |

## 2. 음영판이 있는데 왜 또 얹나

- **색이 평평하다.** VWorld 영상이나 다른 지질도 위에 투명도를 주고 겹치면 음영판은
  기복 무늬가 배경과 겹쳐 흐려진다. 민판은 색만 얹힌다
- **무손실이다.** 한 화소의 색이 곧 지층 하나다. 나중에 색↔지층 표를 CorelDRAW 원본
  (026 §4)에서 뽑으면 클릭해 속성을 읽을 수 있다 — 벡터 없이. JPEG 인 음영판으로는 못 한다
- 해상도는 음영판보다 낮다(85 m). 가까이 볼 때는 여전히 스캔판(026, 16 m)이다

그래서 셋을 나란히 둔다. `peninsula.py` 는 판 하나를 전제로 짜여 있었는데, 판마다 범위·
크기·줌 끝이 달라 `Sheet` 하나로 묶고 판 둘(`SHADED`·`PLAIN`)을 둔다. 잘라 둔 것은
`tiles/`(음영판, 운영에 이미 있는 자리 그대로)·`tiles-plain/` 로 가른다.

## 3. 월드파일을 믿지 않았다

027 은 "QGIS 프로젝트의 원본이 오면 고친 값을 버리고 그것을 믿는다" 고 적었다. 그
원본이 온 셈인데, **대 보니 믿을 수 없었다.**

OSM 해안선(줌 13)과 열두 해안에서 땅/바다 가림막을 ±25 화소 밀어 가며 맞췄다. 027 의
열 곳에 북쪽 둘(청진·신의주)을 더했다. 월드파일 그대로는:

| 자리 | 동 · 북 (m) | | 자리 | 동 · 북 (m) |
|---|---|---|---|---|
| 신의주 | −375 · +375 | | 부산 | +718 · −319 |
| 태안 | 0 · −156 | | 포항 | +721 · −72 |
| 목포 | +137 · −343 | | 삼척 | +797 · +66 |
| 여수 | +458 · −401 | | 강릉 | +716 · +165 |
| 원산 | +378 · +530 | | 청진 | +873 · +623 |

서쪽은 서쪽으로, 동쪽은 동쪽으로, 북쪽은 북쪽으로, 남쪽은 남쪽으로 — **그림이 부풀어
있다.** 두 방향을 따로 한 줄로 맞추면 가로 **0.267%**, 세로 **0.137%** 늘어났다
(오차 = −2316.2 + 0.0026665·x, −2589.8 + 0.0013666·y). 엇갈린 항(가로 오차가 y 를 따르는
것)은 0 에 가까워 버렸다. 가로·세로가 다르게 늘어난 것은 음영판과 같은 꼴이다 — 누가
QGIS 에서 손으로 맞출 때 생긴다. 측지계를 잘못 옮긴 것이라면 한쪽으로 몰렸을 것이다.

고친 범위로 잘라, 잘린 타일로 다시 쟀다.

재는 눈금이 한 화소 55~80 m 라 ±160 m 는 두 화소 안이다. 한 곳씩 빼고 맞춰 그 자리를
재도 가로 ±125 · 세로 ±250 m 안이었다. 인천(갯벌)·군산은 맞출 때 쓰지 않았다. 군산은
새만금·군산항 매립으로 해안선이 바뀐 자리라 음영판(+1219)·스캔판(+1286)도 똑같이
어긋난다 — 지도가 매립 전이다.

월드파일이 적은 범위는 `PLAIN.stated` 로 남겨 **판을 알아보는 데만** 쓴다. 다른 PNG 를
넣으면 `build_peninsula` 가 멈춘다.

## 4. 음영판과 민판이 서로 맞나

고치기 전, 민판을 음영판(고친 범위)에 대 본 적이 있다 — 스물두 곳에서 가로 0.247%·
세로 0.167% 로 나왔고 한 줄로 맞추면 ±65 m 가 남았다. OSM 에 곧장 대 얻은 값(0.267%·
0.137%)과 0.03% 차이다. 음영판에 남은 어긋남(±120 m) 만큼이다. 두 판을 번갈아 켜도 한두
화소 안에서 겹친다.
