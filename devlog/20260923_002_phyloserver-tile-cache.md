# 002 — 옆 저장소의 지질도 캐시를 가져올까

2026-09-23

phyloserver 가 지질도 타일을 오래 캐시해 왔다. 631 MB(md5 구 캐시) + 158 MB
(z/x/y 신 캐시). 5만 지질도는 우리가 가장 많이 볼 축척이라, 이미 받아둔 것이
있다면 가져오는 것이 맞아 보였다. **견줘 보고 안 가져오기로 했다.**

## 저쪽이 하던 것

`dikesync/views.py: geology_tile_proxy()`.

| | |
|---|---|
| 상류 | `https://data.kigam.re.kr/mgeo/geoserver/wms` — **문서에 없는 그 주소** |
| 레이어 | `Geology_map:L_50K_Geology_Map_Latest_2015` |
| 타일 | 256×256, EPSG:3857, `tiled=true` |
| 옛 열쇠 | `md5(request.path + querystring)` — 요청 경로가 섞여 옮기기 어렵다 |
| 새 열쇠 | `geology_tiles/{z}/{x}/{y}.png` — bbox 에서 줌·타일번호를 되계산한다 |
| 지금 | 오늘(09-23) 낮에도 쌓고 있다. 살아 있는 캐시다 |

**z/x/y 로 옮겨 간 판단은 옳다.** 격자에 붙어 있어 어디 것인지 눈으로 알 수
있고, 저장소를 옮겨도 열쇠가 그대로다. 우리 `tilecache.py` 는 WMS 변수를
sha256 으로 묶는 쪽이라 임의의 범위도 받지만, 격자로 미리 데워 둘 수는 없다.
그 이야기는 TODOs 에 남겼다.

## 같은 그림인가 — 아니다

로그에 실제로 있던 타일 하나
(`bbox=14235632.147831228,4412556.768846657,14240524.117641479,4417448.738656908`,
괴산 부근)를 두 레이어로 똑같이 받아 픽셀로 견줬다.

```
우리   geoOpen:L_50K_Geology_Map                  33,633 B
저쪽   Geology_map:L_50K_Geology_Map_Latest_2015  28,119 B
다른 픽셀  2,225 / 65,536  (3.4%)
```

**3.4% 가 어디인지가 중요했다.** 지질 폴리곤은 한 점도 다르지 않다 — 경계도,
색도, 지층기호(`Kbgr`·`Jpgr`·`PZoch`·`Obgr`·`Kgp`·`Qa`)도 같다.

다른 것은 전부 **우리 쪽에만 있는 것**이었다.

- 주향·경사 기호와 그 숫자 (75·80·53·50·20 …)
- 단층선 한 줄이 타일을 가로지른다
- 암맥 표시 몇 개
- 지명 `괴산군`

즉 `_Latest_2015` 는 **구조지질이 빠진 판**이다. 이름에 `Latest` 가 붙어 있지만
2015 년 것이고, 우리가 오픈API 로 받는 `geoOpen` 판이 더 나중이고 더 담고 있다.

## 그래서 안 가져온다

가져오면 구조지질이 빠진 타일이 우리 5만 자리에 조용히 들어앉는다. 사람은
캐시에서 나온 것인지 새로 받은 것인지 알 수 없으므로, **주향·경사가 없는
지질도를 보고 없다고 믿게 된다.** 디스크 158 MB 를 아끼자고 치를 값이 아니다.

여기서 규약을 하나 세웠다 — CLAUDE.md "받아온 것의 순위".

**새로 받은 것이 언제나 이긴다.** 옆에서 가져온 것은 새로 받은 것을 덮지 않는다.
까닭 둘.

1. **새 것이 더 나중이다.** 상류가 판을 올리면 우리 것이 따라가지만, 옮겨온
   것은 옮겨온 그날에 멈춰 있다
2. **받아온 길이 다르다.** 저쪽은 문서에 없는 주소로 받았다. 우리는 그 길을
   개발 스위치로만 쓰고 제품은 `/openapi/wms` + 인증키로 간다. 길이 다른 것을
   섞으면 "이 타일은 어느 길로 온 것인가" 를 나중에 답할 수 없다

## 가져올 만한 것이 하나 남는다

`uploads/geolmap/` 925 MB. 5만 지질도 **원도 스캔**을 도폭별로 자른 것이다
(`map_info.json` 에 고성·백령도·속초양양·부산 … 도폭이 행렬 자리와 함께 있다).

이것은 **겹치지 않는 자료다.** 우리가 WMS 로 받는 것은 벡터를 다시 그린 것이고,
저것은 종이 지도를 찍은 것이다. 5만 지질도의 `도폭` 속성에 원도 PDF 링크가
딸려 오는 것(001)과 같은 갈래이기도 하다. 다만 지금 판에 넣을 것은 아니라
TODOs 에 적어 둔다.
