# 관리 화면과 개인 레이어 — 브라우저에만 두는 내 자료 (계획)

2026-10-01 · `feature/personal-layers` · wetherilli

사람이 정한 것 — 설정 왼편에 관리 화면으로 가는 단추를 두고, 관리 화면은 앞으로 기능을 늘릴 자리로 연다.
첫 기능은 둘이다.

1. **개인 레이어 반입** — 정해진 양식의 JSON·CSV 를 받아 그 브라우저에만 레이어로 띄운다. 서버에 저장하지 않는다
2. **저장 자료 관리** — 브라우저에 둔 것을 보고 지운다

## 갈림길에서 정한 것

- **주소는 `/GSM/manage/`** — `/GSM/admin/` 은 Django 관리 화면이 쓰고 있다. 관리 화면 안에서는 탭으로 기능을 늘린다
- **양식은 하나다. 점이냐 면이냐는 좌표 값의 꼴이 정한다** — 처음에는 점 양식·면 양식을 따로 두려 했으나 어드민이
  "좌표 값의 양식으로 구분하자" 고 했다. 따로 적는 칸이 없으니 틀릴 자리도 없다. 한 레이어에 섞이면 받지 않는다
- **JSON 은 GeoJSON + `gsm` 머리** — 우리만의 표 꼴(`{meta, fields, records}`)도 보았으나, GeoJSON 이면 QGIS 따위가 그대로
  연다. 머리를 모르는 프로그램은 넘긴다
- **CSV 는 맨 위 `#` 줄에 머리** — 머리를 곁 파일로 두면 둘이 떨어진다. `#` 줄이면 엑셀에서도 열리고(첫 칸에 보일 뿐)
  JSON 과 같은 것을 담아 **둘이 1:1** 이 된다. 면은 `geometry` 칸의 WKT — QGIS 가 CSV 로 내보낼 때의 꼴이다
- **저장은 IndexedDB** — localStorage 는 5 MB 남짓에 글자만 받는다. 첫 자료(nkfcluster)만 해도 JSON 이 1 MB 다
- **이름은 사람이 부른 대로 "개인 레이어"** — CLAUDE.md 는 레이어를 "상류가 주는 것" 으로 쓰지만, 화면에서 지질 레이어와
  나란히 켜고 끄는 것이라 사람이 레이어라 불렀다. 점묶음(`PointSet`, 서버에 남는 것)과 겹치지 않게 "개인" 을 늘 붙인다

## 단계

1. 양식 v1 — `docs/개인레이어_양식.md`. 점(Point·MultiPoint)·면(Polygon·MultiPolygon). 선은 받지 않는다
2. 읽개 하나(`personal.js`) — 관리 화면·지도·node 시험이 같은 코드를 쓴다
3. 관리 화면 — 반입(읽은 것을 보여 주고 저장), 저장 자료 관리(개인 레이어·브라우저 설정)
4. 지도 — "개인 레이어" 블록, 음영을 달리한 기호, 팝업
5. 첫 자료 — phyloserver nkfcluster 전체목록을 양식으로 옮기고 소실을 본다 (118)

## 뒤로 미룬 것

- 선(LineString)
- 개인 레이어를 점묶음으로 서버에 올리기 — "서버에 저장하지 않는다" 가 이 기능의 뜻이라 지금은 길을 내지 않는다
