# 관리·소개 화면을 휴대폰으로 — 언어를 바꿀 길, 상자 제목 꺾임

2026-10-05 · `fix/manage-mobile` · wetherilli

판 세션이 맡긴 일이다. 390×844 터치로 두 화면을 돌렸다.
- 관리 화면(`/GSM/manage/`) — 네 탭
- 소개 화면 — 서버판

## 돌던 것

- **개인 레이어 반입** — "양식 예시 → 받아 본다 → 저장" 이 돈다.
- **연결 레이어**
  - 브라우저에서 CORS 를 연 가짜 API(GeoJSON 점 둘)로 끝까지 돌렸다 — 주소, 인증 방식(?이름=키), 받아 본다, 저장.
  - 저장 탭에 "연결 · 곧장 받았다" 로 서고, 지도의 개인 레이어에 `example.org 🔗 2점` 으로 뜬다.
- **표 셋**(상류 응답 시간·구운 자료·대조) — 화면을 넘지 않는다. 열이 많은 표는 칸 안에서 가로로 구른다(`mg-scroll`).
- 네 탭 모두, 그리고 소개 화면의 그림이 깨지지 않는다.

## 막힌 것

1. **소개 화면에서 언어를 바꿀 길이 없었다.**
   - 머리줄의 언어 단추는 좁은 화면에서 숨는다(`intro.css`). 영어판은 제목 "Great Stone Map" 이 두 줄이라 머리줄에 남는 자리가 0 이다.
   - 그래서 휴대폰으로 소개를 연 사람은 한국어판·영어판을 오갈 수 없었다.
   - 같은 단추를 꼬리말 끝에도 두고, 좁은 화면에서만 보인다. 누르는 손(`intro.js` 의 `.langs button`)은 그대로 둘 다 잡는다.
2. **관리 화면의 상자 제목이 꺾였다** — 제목 옆 안내 글이 제목을 밀어 "개인 레이 / 어"·"상류 응답 / 시간" 이 되었다.
   - 휴대폰에서는 안내를 다음 줄로 내렸다(`manage.css`). 지도 패널의 상자 제목은 안내가 짧아 건드리지 않았다.

## 버린 것

- 머리줄에 다른 말의 단추 하나만 두기 — 영어판 머리줄에 자리가 없다. 제목 글씨를 줄이면 소개 화면의 얼굴이 바뀐다.
- 저장 탭의 표를 휴대폰에서 카드로 바꾸기 — 지우기·내려받기 단추가 표 오른쪽(가로로 구르는 곳)에 있어 찾기 어렵기는 하다. 그러나 표의 꼴을 갈아엎는 일이라 따로 둔다.

## 확인

- `test_mobile` 에 둘을 더했다.
  - 소개 화면에서 언어를 바꾸고 다시 돌아오는 단추가 보이는지 본다.
  - 관리 화면 네 탭의 상자 제목이 한 줄인지 본다.
- 고치기 전 코드에서는 둘 다 깨지고(`0 != 1`·`2 != 1`), 고친 뒤 통과한다.
