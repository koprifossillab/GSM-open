# 지역 지도를 투영마다 써 보기 — 나란히 보기를 끄면 지도가 깨지던 것

2026-10-05 · `fix/region-flows` · wetherilli

판 세션이 "스스로 하나 골라" 라고 했고, 권한 것(써 보며 막히는 곳 찾기)을 골랐다. 네 탭을 휴대폰(390×844 터치)과 데스크톱(1400×900)으로 돌렸다.
- 페루 3857
- 스발바르 3413
- 남극 3031
- 캐나다 3978

돌린 흐름:
- 켠 레이어의 범례와 투명도
- 둘째 레이어 켜기
- 주제도 비교(밀어 보기·나란히)
- 배경 모두 바꿔 보기
- 지도 누르기

## 돌던 것

- 범례 펴기, 투명도(20 % 로 내리면 줄에 20 %)
- 배경 넷–열 가지를 모두 바꿔 봤다 — 페이지 오류 없음
- 밀어 보기 — 막대를 손가락(CDP 터치)으로 끌면 195 → 99 px 로 따라오고 지도는 끌리지 않는다
- 누르기는 처음 상태에서 위경도가 맞다

## 막힌 것

1. **나란히 보기를 켰다 끄면 지도가 깨졌다** — 모든 탭에서 났고, 극 평사도법·람베르트에서 두드러졌다.
   - 끈 뒤 축척이 1:15,215,174,957 이 되고 줌 표시가 빈다. 휠로도 돌아오지 않는다(다시 불러야 했다).
   - 누른 자리가 엉뚱한 반구로 읽혔다. 스발바르에서 남위 78.9°, 남극에서 북위 76°, 캐나다에서 남위 88.6° 였다.
   - 휴대폰에서 본 "북위 85.24°, 서경 45°" 도 깨진 보기의 가운데였다.
   - 까닭: 오른쪽 지도(`map2`)가 왼쪽과 **같은 보기를 나눠 쓴다**(함께 움직이려고). 끄면 칸이 숨는데, 그 지도가 크기 0 으로 다시 재어지며 보기의 해상도를 끝없이 키웠다.
   - 고침: 끌 때 오른쪽 지도를 화면에서 뗀다(`setTarget(undefined)`). 다시 켜면 `buildMap2` 가 붙인다. 숨은 지도는 크기를 다시 재지 않는다.
2. **휴대폰의 나란히 보기 이름표가 서로 겹치고 손잡이·툴바 밑에 깔렸다** — 왼쪽 이름표가 화면의 40 % 라 가운데 선을 넘었다(56–212 와 207–363).
   - 손잡이 밑(위 30 px)으로 내렸다. 왼쪽은 가운데 선 앞까지, 오른쪽은 툴바 앞까지로 묶었다.

## 버린 것

- 오른쪽 지도에 따로 보기를 주고 서로 따라가게 잇기 — 두 보기를 맞추는 손이 생기고, 돌리기·줌의 미세한 어긋남을 따로 다뤄야 한다. 같은 보기를 나눠 쓰는 것은 그대로 두고, 숨을 때만 뗀다.

## 확인

- `test_mobile.RegionCompare` 를 더했다. 스발바르·캐나다에서 나란히 보기의 이름표가 서로·손잡이·툴바와 겹치지 않는지 본다. 끈 뒤 줌 표시·저장된 줌이 그대로인지도 본다.
- 고치기 전 코드에서는 이름표에서 깨진다. 이름표만 고친 옛 코드에서는 줌이 `''` 로 깨진다. 고친 뒤 통과한다.
