# 묶음 패키지의 격자 — 3857 밖(남극 3031·Esri 극 타일)을 세고 자르기 (P17 1 단계)

2026-10-21 · `feature/gsmpack-polar-grid`(`release/v1.2.0` 위) · wetherilli

P17(남극 묶음)의 1 단계다. 굽는 쪽은 3857 에 박혀 있었다 — 칸 세기·자르기가 `lonlat_to_3857` 이고 머리의 `grid` 는 늘 `EPSG:3857` 이었다.
남극 탭은 레이어마다 격자가 다르다. 이번에는 패키지가 소스마다 격자를 쓰게 했다. 남극 소스(GeoMAP·REMA·기지 위성)는 2 단계다.

## 무엇을 했나 — 왜

- **격자 꼴 `gsmpack.grid.Grid`** — 원점(왼쪽 위)·줌 0 의 칸 한 변·범위·투영. 셋을 둔다: `MERCATOR`(지금까지의 3857), `ANTARCTIC`(3031 의 범위
  ±3333134.0276 — GeoMAP·IBCSO·REMA·NPI), `ESRI_ANTARCTIC`(Esri 극 타일의 `tileInfo` — 원점 −33699550.99, 줌 0 이 238810.813354 m/px).
  소스가 `grid` 를 달고(`PartsSource` 는 `MERCATOR`), 굽는 고리가 그것으로 세고 자른다. 달지 않은 소스는 3857 이다 — 402–409 의 소스가 다 그렇다
- **범위로 지은 격자는 타일 크기와 상관없이 같은 칸이다** — GeoMAP(256 px)과 REMA(512 px, `createXYZ`)는 둘 다 3031 의 범위로 지었다. 칸 한 변이 `폭 / 2^z` 라
  열쇠의 줌만 다르다(한국의 KIGAM 512 px·VWorld 256 px 과 같다). 그래서 3031 격자는 하나다. 셈의 차례(해상도 × 타일 크기)는 화면을 따른다 —
  끝자리가 갈리면 WMS BBOX 글자가 어긋난다(407). `with_tile` 이 그것을 맞춘다
- **극 평사도법은 테두리 다각형으로 자른다** — 경위도 네모가 3031 에서는 부채꼴이다. 투영의 네모로 자르면 둘레가 샌다. 테두리를 한 변에 32 점씩 투영한 고리를
  칸의 픽셀로 옮겨 마스크를 그린다(`clip._clip_projected`). 3857 은 지금까지의 셈 그대로다 — 한국 묶음이 한 바이트도 바뀌지 않게
- **3031 의 투영 식은 옮겨 왔다**(`lonlat_to_3031`, `viewer/tilegrid.polar_forward` 의 Snyder 식) — 패키지는 viewer 를 import 하지 않는다(P16)
- **머리의 `grid` 에 진짜 이름** — 투영 코드, 원점이 투영 범위의 왼쪽 위가 아니면 `@<원점 x>`. 화면(`offline.js` 의 `gridName`)이 소스의 투영과 격자 원점으로
  같은 이름을 짓는다. 읽는 쪽(`gsmpack-reader.js` 의 `fits`)은 `tile_size` 에 더해 `grid` 가 다르면 그 레이어를 건너뛴다. **남극 탭에는 256 px 격자가 셋이라**
  (3031·Esri·옮겨 그리는 3857 의 VWorld 테마) 크기만으로는 못 가른다. `grid` 가 없는 옛 묶음은 3857 이다 — 꼴의 판(`GSMPACK1`)은 올리지 않았다
- **육지 마스크(409)는 3857 칸만 센다** — 한반도 둘레의 0.005° 그림이다. 다른 격자는 다 땅으로 센다(어림이 넘치는 쪽이다)
- `gsmpack info` 의 "박스 밖 타일" 도 머리의 격자로 센다

**버린 것 — `viewer/tilegrid.Grid` 를 그대로 쓰기.** 셈은 같지만 패키지가 viewer 를 타게 된다. 옮겨 오고, 시험이 둘을 견준다.

## 확인

- 격자 — 패키지의 격자를 `viewer/tilegrid` 와 견줬다. 3857 은 무작위 5 만 칸·박스 둘의 칸이 같다. 3031 은 256·512 px 마다 무작위 2 만 칸의 범위와,
  세종·장보고·남극 모자 박스의 칸(줌 3·8·12)이 같다. 투영 식은 장보고에서 0 m 다르다. 시험 `test_grid`(8) — 3031 의 두 타일 크기가 같은 칸,
  남극점을 품는 박스, Esri 범위, 극 자르기(가장자리는 일부를 비우고 먼 칸은 다 비운다, 다 안이면 그대로), 머리의 `grid`
- 읽는 쪽 — node 시험에 "같은 크기·다른 격자는 그리지 않는다" 와 "`grid` 없는 옛 묶음은 3857" 을 더했다. 휴대폰 시험 `OfflinePack`·`OfflineRequest` 가
  한국 묶음을 그대로 읽는다(viewer 오프라인 시험 35 OK)
- **한국 묶음이 한 바이트도 바뀌지 않는다** — 로컬 GSM(이 브랜치, 운영 캐시 읽기만)을 띄우고 진교 박스의 KIGAM 레이어 넷을 `--via` 로 두 번 구웠다.
  1.2.0 의 패키지와 이 브랜치의 패키지다. 966 장, 25.3 MB — **두 파일의 바이트가 같다**. 캐시에서 다 나와 상류를 타지 않았다(33 초)
