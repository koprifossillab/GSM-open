# 연결 레이어 — 전체 마감 20 초, https 에서 내려가면 키를 빼고

2026-10-01 · `fix/linked-deadline` · wetherilli

#72(122)를 병합하며 gsm-b5 가 `linked.py` 에서 둘을 짚었다.

- **시간.** `TIMEOUT=(5, 20)` 의 20 은 requests 가 "한 번 읽기" 를 기다리는 상한이다. 상대가 19 초마다 조금씩 흘려 보내면
  20 MB 를 다 채울 때까지 몇 분이고 워커 스레드를 붙잡는다 — 문서에 적은 "20 초" 와 다르다. 그래서 **넘겨주기·본문 읽기를 다
  합친 마감(`DEADLINE`, 단조 시계)** 을 두고, 덩이를 받을 때마다 본다. 넘을 때는 504. 읽기 상한도 남은 시간으로 줄인다
- **키.** 같은 호스트면 넘겨주기에도 키를 실었는데, `https → http` 로 내려가면 키가 평문으로 흐른다. 처음 준 주소가 https 였는데
  지금이 http 면 키를 빼고 부른다. `http → https` 로 오르는 것은 그대로 싣는다 — 흔한 넘겨주기이고 더 안전해지는 쪽이다

시험이 셋 늘었다(내려가면 키를 안 싣는다, 오르면 싣는다, 조금씩 흘려도 마감에서 끊는다 — 시계를 갈아 끼워 3 초씩 흐르게 했다).
