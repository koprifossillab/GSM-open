# GeoMAP 암층 — 무늬 채우기를 옮겼다

2026-09-30 · sclee · TODO "GeoMAP 암층(Lithostratigraphic) 채색"(018).

018 은 GNS 스타일 다섯 가운데 암층을 뺐다. 무늬 채우기(`LinePatternFill` 48·`PointPatternFill` 18)가
대부분이라 Pillow 로 옮기는 값이 크다고 보았다. 이번에 옮겼다 — 레이어 "암층"(`geomap_lithostratigraphic`).
시대마다 퇴적암·화산암·관입암·변성암을 색과 무늬(빗금 0°·45°·135°, 점, 반네모 점)로 가르는 지도다.
지질시대 레이어가 "언제" 만, 암상 레이어가 "무엇" 만 보이는 것을 한 장에 겹친다.

## 1. 색은 여전히 사람이 옮겨 적지 않는다

`manage.py geomap_styles` 가 .qml 을 읽는 범위를 넓혔다(018 의 원칙 그대로). 빗금은 각도·간격과
**서브심볼 SimpleLine 의 색·굵기**를 읽는다 — QGIS 3 은 층의 `color` 가 아니라 서브심볼로 그리고, 원본에 둘이
다른 심볼이 있다(고제3기 관입암 따위). 점 무늬는 가로·세로 간격, 홀수 줄의 어긋남, 마커(circle·square·
half_square)를 읽는다. 모르는 것(세로 어긋남 따위)이 나오면 멈춘다 — 대충 넘기면 조용히 틀린다.

- 원본 필터에 `'Cn'OR MAPSYMBOL = 'CTp'` 처럼 따옴표에 붙은 `OR` 가 있어 받게 했다
- 무늬가 없는 스타일은 JSON 이 **한 글자도 바뀌지 않게** 했다. 다시 뽑은 뒤 기존 넷의 diff 가 비었다.
  그래서 `geomap.RENDERER` 를 올리지 않았다 — 기존 레이어의 그림이 그대로이고, 새 레이어는 이름이 달라
  캐시 열쇠가 새로 생긴다

## 2. 무늬를 타일이 아니라 지도에 맞춘다

타일마다 무늬를 새로 깔면 타일 경계에서 빗금이 어긋난다. 무늬의 원점을 **지도 전역 픽셀 자리**
(`min_x·kx`, `−max_y·ky`)에 두고, 빗금은 법선 위 `k·간격` 자리마다 선을 새로 긋는다. 한 장을 만들어
바둑판으로 까는 길은 45° 빗금의 가로 주기가 정수 픽셀이 아니라서 경계가 어긋났다. 선의 끝을 그림 폭+높이로만
잡으면 모서리를 덮지 못해, 선의 발 거리만큼 더 늘였다. 시험이 이웃 두 타일의 같은 자리 픽셀이 같은지 본다.

간격·굵기·마커 크기는 QGIS 처럼 화면 mm(96 dpi)다 — 줌과 상관없이 무늬 크기가 같다.

## 3. 값

한 장 0.03–0.1 초, 간추린 지질(0.01–0.05 초)의 두 배쯤이다. 무늬 그림을 규칙마다 한 번 만드는 값이다.
그린 것은 다른 GeoMAP 타일처럼 캐시에 담는다(007).

## 4. 옮기지 못한 것

- Qt 의 촘촘함 브러시(`dense5` 따위)는 지금처럼 반투명 면(018)
- 마커 외곽선 굵기(0.1–0.2 mm)는 1 px 로 뭉뚱그렸다
- 범례의 글자는 GNS 스타일의 영어 그대로다(018)
