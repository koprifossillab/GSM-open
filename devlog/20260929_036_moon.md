## 1. 무엇이 섰나

`/GSM/moon/` — CesiumJS 의 달 타원체 위에,

- **영상 배경** — LRO WAC 모자이크 또는 LOLA 음영. 브라우저가 Trek WMTS 를 곧장 부른다
- **지질** — USGS 달 통합 지질도 1:500만의 단위·경계·선 구조. 서버의 문(`trek.py`)이 Trek 의
  ArcGIS `export` 를 경위도 격자로 받아 캐시에 담는다. 누르면 `identify`, 범례 49 칸
- **지형** — LOLA 128 ppd 표고를 서버가 65×65 Terrarium PNG 로 옮기고, Cesium 의
  `CustomHeightmapTerrainProvider` 가 세운다. 과장 ×1–×5
- **찾기** — 지명 7 990 개(IAU 사전 + 착륙지·충돌 지점). 저장소의 `data/moon_places.json`
- 자리·배경·켠 레이어·투명도·과장을 브라우저에 기억한다(`gsm.moon.*`)

**아직 없는 것** — 달 점묶음(`PointSet.body`), 평면(OpenLayers)에서 일하기, 달 지명의 한글 이름.
P05 §9 의 2·3 단계다.

## 2. 왜 이렇게 했나

### 표고를 `elevation.py` 가 아니라 `trek.py` 에

P05 §7 은 `elevation.py` 에 달을 더한다고 적었다. 짓다 보니 **상류 하나에 문 하나**(CLAUDE.md)가
더 무겁다 — 같은 Trek 에 두 문이 나가면 `upstream_stats` 의 `trek` 줄도 둘로 갈린다.
`elevation.py` 는 "지구의 표고로 나가는 문" 으로 남긴다. Terrarium 부호화 몇 줄만 겹친다.

### 표고는 TIFF 로 받는다

`exportImage` 는 `bsq`(날 바이트)·`lerc`·`tiff` 를 다 준다. 서버에 GDAL·numpy 가 없어도 Pillow 가
F32 TIFF 를 `mode "F"` 로 읽는다 — 그래서 TIFF. 받은 값을 Terrarium PNG 로 담는 까닭은 캐시가
`.png`·`.json` 만 안다는 것(`tilecache.SUFFIXES`), 그리고 북극 3D 의 `dem/` 과 같은 꼴이라는 것이다.

**격자의 가장자리를 반 칸씩 넓혀 묻는다.** ImageServer 는 픽셀의 가운데를 잰다. 65 점의 첫 점과 끝 점이
장의 가장자리에 오게 하지 않으면 장과 장 사이에 금이 간다.

**줌 8 너머는 부모 격자를 늘려 쓴다**(`moon.js` 의 `heights`). LOLA 128 ppd 는 줌 8 에서 한 칸이
한 픽셀쯤이다 — 더 묻는 것은 같은 값을 다시 받는 일이다. `CustomHeightmapTerrainProvider` 는 가용성
(availability)을 모르므로 끝을 알려 줄 수 없어, 화면이 스스로 멈춘다.

### 지질도는 문을 거친다, 영상은 곧장

Trek 은 CORS 가 열려 있어 둘 다 곧장 부를 수 있다(시험 화면은 그랬다). 지질도·표고·속성을 문으로
돌린 것은 **캐시**(007 — 같은 자리를 두 번 묻지 않는다)와 **호출 세기**(`upstream_stats` 의 `trek`)
때문이다. 영상 배경은 EOX·GIBS 와 같이 곧장 부른다 — 타일이 가장 많고, Trek 이 그렇게 쓰라고 WMTS 로
내놓았다.

### 달 지질시대의 한국어

값이 다섯 가지다 — 2026-09-29 `returnDistinctValues` 로 셌다. ICS 한글판에 없어 이렇게 두었다:
코페르니쿠스기 · 에라토스테네스기 · 임브리움기 · 넥타리스기 · 선넥타리스기(`trek.AGES_KO`).
**사람이 다시 본다**(P05 §8). 영어판은 받은 그대로다. 단위 이름·설명·해석은 값이라 옮기지 않는다.

### 지명의 갈래는 쉼표 앞만

Trek 색인의 갈래가 `"Lacus, lac?à?½s"` 처럼 **복수 쪽 글자가 깨져** 온다(상류의 인코딩). 단수
(`Lacus`)만 쓴다. 착륙지 북마크는 `Landing site` 로 두고, "Apollo" 를 치면 크레이터 Apollo 보다
먼저 뜨게 했다.

### 숨은 차림

아이콘(`#emblem-btn`)을 누르면 뜬다. 지역 탭에 두지 않은 까닭은 P05 §3 — 달은 몸이 달라 점묶음·
배경·좌표계가 다 따로 논다. 지구 밖이나 실험 화면이 더 오면 이 차림에 줄을 더한다.
