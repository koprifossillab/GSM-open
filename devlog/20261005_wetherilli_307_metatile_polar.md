# 극지 격자의 메타타일 — 3413·3031·3575·3978·대만 4326

2026-10-05 · `feature/metatile-polar` · wetherilli

판 세션이 맡긴 일이다. 메타타일(wetherilli 282)은 3857 격자의 칸만 알아봤다. 극지 탭(3413·3031)에서 지역의 투영으로 곧장 받는 느린 상류
(그린란드 서남부 1:10만 13 초 — wetherilli 301, verify_layers 의 EMODnet folk 7·대만 5만 자세 — wetherilli 298)에는 쓸 수 없었다.

## 어떻게

- `metatile.GRIDS` — 투영마다 (원점, 줌 0 의 칸 한 변, 줌 0 의 칸 수). 3857 은 `createXYZ`, 극지·북극 람베르트·캐나다 람베르트는 화면의 `npolarSource` 가
  짓는 `createXYZ({extent})`(범위는 `tilegrid.EXTENT` 를 그대로 읽는다), 4326 은 대만의 `TAIWAN_GRID`(줌 0 이 180° 네모 두 장). 스페인 IGME 1:100만도 4326 이지만
  줌 0 이 360° 한 장인 격자다 — 같은 칸이 여기서는 줌이 하나 크게 셈해질 뿐 칸의 테두리는 같아 맞는다
- `cell(params)` 가 bbox 에서 (투영, z, x, y, px) 를 거꾸로 셈하고, `_bbox` 가 같은 격자로 블록의 bbox 를 짓는다. **WMS 1.3.0 의 4326 은 위도가 먼저**라 읽을 때와
  지을 때 둘 다 축을 바꾼다(1.1.1 이면 바꾸지 않는다)
- **화면 주소·캐시 열쇠는 그대로다.** 조각 열쇠에는 3857 이 아닐 때만 투영을 넣는다 — 3857 의 열쇠가 앞 판과 같게(담아 둔 조각을 버리지 않게), 그리고 한 레이어를
  투영 둘로 부르는 일(북극 탭 3413·유럽 탭 3857 의 EMODnet 따위)에 조각이 섞이지 않게
- `test_metatile` 의 표 시험은 "3857 레이어만" 에서 "메타타일이 아는 격자로 부르는 레이어만" 으로 넓혔다

## 어느 상류를 넣었나 — 재고 정했다 (2026-10-05, 2 초 간격)

| 상류 | 512 px 한 칸 | 1 024 px 블록(칸 넷) | 정한 것 |
|---|---:|---:|---|
| 그린란드 서남부 1:10만 (`geusarc`, 3413) | 40–42 초 | 40–48 초 | **넣는다** — 요청마다 드는 값이다 |
| 그린란드 자력 편찬 (`geusarc`) | 1.9–2.2 초 | 2.3–2.5 초 | 같은 꼴이라 `geusarc:` 앞머리로 다 넣는다 |
| EMODnet folk 7 (3413) | 4.6–15.7 초 | 14.5 초·시간 초과 | 넣지 않는다 — 그리는 값이라 블록이 칸 넷만큼 든다 |
| 대만 5만 자세 (4326) | 시간 초과(20 초) | — | 잴 수 없었다. 격자는 섰으니 재고 나서 `gsmma.METATILE` 한 줄이면 된다 |

서남부 1:10만은 블록 한 장이 48 초까지 걸린다 — 문 한계 60 초 안이고 잠금 기다림(20 초)을 더해도 nginx 90 초 밑이다(wetherilli 300).
운영과 같은 길(뷰 → 문 → GEUS)로 자력 편찬의 이웃 칸 넷을 불러 상류를 한 번(`1024,1024`)만 타는 것을 봤다.
