# 관리 화면에 상류 응답 시간 표

2026-10-05 · `feature/upstream-dashboard` · wetherilli

판 세션이 맡긴 일이다 — #278(wetherilli 290)이 날마다 센 응답 시간을 관리 화면(`/GSM/manage/`)에서 본다. 읽기만 하고 키·주소는 보이지 않는다.

## 무엇을

관리 화면의 셋째 칸 "상류 응답 시간" — 상류마다 **오늘**과 **지난 7 일**(오늘 포함)의 건수·실패·평균(초)·p95. 지난 7 일의 평균이 느린 차례로 서고,
잰 것이 없는 상류(배치로만 묻는 것, 아직 부르지 않은 것)는 뒤에 "—" 로 선다. 실패(차단 조짐을 함께 센다)가 있으면 붉게.

## 어떻게

- 셈은 `usage.summary` 하나 — `manage.py upstream_stats` 의 평균·p95 셈(`usage.mean`·`usage.p95`)을 `usage.py` 로 옮겨 둘이 같은 값을 보인다
- 서버가 표를 지어 내준다(템플릿). 화면이 따로 묻는 길(JSON)은 두지 않았다 — 관리 화면을 열 때 한 번 세면 되고, 묻는 길이 하나 늘면 밖에 열 때 볼 것이 는다
- 보이는 것은 `UpstreamDay` 에 든 것뿐 — 상류의 이름과 수다. 주소·키는 애초에 담지 않는다(290)
- 아홉 칸이라 휴대폰에서는 표만 안에서 가로로 굴린다(`.mg-scroll`) — 페이지는 넘치지 않는다(390 px 에서 재 0 px)

## 버린 것

- 그래프 — 수 몇 줄이면 느린 상류를 고르기에 넉넉하다. 날마다의 흐름은 `upstream_stats` 가 보인다
- 밖에 열 때(`GSM_PUBLIC`) 숨기기 — 상류 이름과 걸린 시간은 감출 것이 아니다. 숨길지 사람이 정하면 그때 한 줄이다
