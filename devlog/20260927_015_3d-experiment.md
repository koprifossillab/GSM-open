# 015 — 3D 실험: VWorld 가 아니라 MapLibre 로

2026-09-27

## VWorld 3D 는 지형이 서지 않는다

004 에서 VWorld 3D 엔진(Cesium 포크)이 지형을 받아 오는 창구 —
`xdworld.vworld.kr/XDServer/requestLayerNode?Layer=dem` — 가 닫혀 있는 것을 봤다.
2026-09-27 에 다시 쏴 봐도 `ERROR_DB_GENERAL` 이었다(https·8080 둘 다). 지형
없이는 3D 가 평평한 판이다. 게다가 VWorld 3D 는 자기 OpenLayers 7.5.2 를
`document.write` 로 심어 우리 OL 9 와 한 페이지에 둘 수 없다.

## 대신 — MapLibre + 공개 표고 타일

- **표고**: AWS Terrain Tiles (Terrarium 인코딩). 열쇠가 없고 CORS 가 열려
  있다. 우리나라는 SRTM(약 30 m) 이다. 한 장을 풀어 보니 값이 제대로 나왔다
- **엔진**: MapLibre GL JS 4.7.1 (BSD). 저장소에 담았다(`vendor/maplibre/`,
  803 KB) — CDN 을 쓰지 않는 집 규칙
- **지질도**: 2D 와 같은 서버 중계(`wms/`)를 탄다. 인증키도 캐시도 그대로다
- 2D 에서 보던 자리를 그대로 열고, 돌아갈 때 3D 의 자리를 가지고 간다

`/GSM/3d/` 에 두었고 **설정의 "실험 기능" 을 켠 사람에게만** 도구 막대에 단추가 뜬다. 헤드리스 브라우저는
그래픽 카드 없이 CPU 로 지형을 그리느라 14 분 동안 끝나지 않아 **눈으로
확인하지 못했다.** 실제 브라우저에서 한 번 열어 보고 링크를 걸지 정한다.

## 이 길이 여는 것

표고 타일을 우리가 직접 읽으므로 **시료 고도 붙이기**가 서버에서 된다 —
004 에서 VWorld 창구가 닫혀 못 한다고 적었던 일이다. 아직 하지 않았다.
