# 003 — 배경지도를 무엇으로 깔까

2026-09-23

배포한 날 화면 전체에 `403 Access blocked` 가 깔렸다. 우리 지질도가 아니라
**배경으로 깔아 둔 OpenStreetMap** 이었다.

```
App is not following the tile usage policy of
OpenStreetMap's volunteer-run servers: osm.wiki/Blocked
```

기관 망의 바깥 IP 가 OSM 정책 위반으로 막혀 있다. 우리가 한 일 때문인지 같은
IP 를 쓰는 다른 누구 때문인지는 알 수 없다. 어느 쪽이든 **우리가 고칠 수 있는
것이 아니다.**

## 중계하지 않기로 했다

서버로 중계하면 화면은 살아난다. 그런데 **그것이야말로 OSM 이 막는 행동이다**
— 자원봉사로 도는 타일 서버 앞에 프록시를 세워 몰아 쓰는 것. 이번엔 서버 IP
가 막히고, 그때는 우리 잘못이 분명해진다.

오늘 이미 "문서에 없는 주소" 로 한 번 타협했다(CLAUDE.md "두 개의 상류 주소").
같은 종류의 타협을 하루에 두 번 하지 않기로 했다.

## 재 본 것

| | 방식 | OpenLayers 에 끼우나 | 열쇠 | 걸림돌 |
|---|---|---|---|---|
| OpenStreetMap | 타일 | 된다 | 없다 | **지금 막혀 있다** |
| OpenTopoMap | 타일 | 된다 | 없다 | 같은 자원봉사 서비스라 같은 위험. 그림이 화려해 지질도와 다툰다 |
| 네이버 NCP Maps | **JS SDK** | **안 된다** | Client ID/Secret | 지도 엔진을 통째로 교체해야 한다. 도메인 등록 필요 |
| 카카오 지도 | **JS SDK** | **안 된다** | JavaScript Key | 위와 같다 |
| **VWorld** | **WMTS 타일** | **된다** | 무료 | 열쇠를 받아야 한다 |

네이버·카카오가 탈락한 까닭은 값이 비싸서가 아니라 **결이 다르기 때문이다.**
둘 다 자기 렌더러를 들고 오는 JS SDK 라, 쓰려면 OpenLayers 를 버리고 레이어
쌓기·투명도·`GetFeatureInfo`·점묶음을 그쪽 API 로 다시 짜야 한다. 배경지도
하나에 뷰어의 심장을 바꿀 일이 아니다.

VWorld 는 WMTS 를 그대로 준다. 그림도 연한 톤이라 지질도 밑에 깔기 좋다 —
지질도가 분홍·자홍·연두를 쓰는 통에 배경이 진하면 둘이 다툰다.

## 그래서 정한 것

**기본은 "없음" 이다.** 배경 고르개를 두고 처음에는 아무것도 안 깐다.

배경이 없어도 읽힌다 — 상류 지질도가 **지명·행정경계·수계를 함께 그려 준다.**
화면을 보면 유성구·서구·중구·대덕구가 제자리에 적혀 있다. 종이 지질도가 본래
그렇게 생겼다. 배경은 있으면 좋은 것이지 없으면 못 보는 것이 아니었다.

`GSM_VWORLD_KEY`(또는 `<DB 옆>/vworld_key`)가 있으면 고르개에 VWorld 둘이
더 오른다 — 배경지도와 위성+지명. **열쇠가 브라우저로 나간다.** 상류
인증키와 다른 점인데, VWorld 의 WMTS 는 브라우저가 직접 부르는 것을 전제로
하고 도메인 제한으로 지킨다. 서버가 중계하면 그 제한이 뜻을 잃고 타일을
전부 우리가 짊어진다.

WMTS 의 자리 차례가 **`z/y/x`** 다. `z/x/y` 로 적으면 엉뚱한 곳이 그려진다.

## 붙였다 — 같은 날

열쇠를 받아 `/srv/GSM/db/vworld_key` 에 두었다. 확인한 것들이다.

- **자리 차례는 `z/y/x` 가 맞다.** 둘 다 쏴 보고 갈랐다 —
  `…/Base/10/402/874.png` 는 48 KB PNG 를 주고, `…/Base/10/874/402.png` 는
  XML 오류를 준다. 문서대로 적은 것이 맞았다
- `Base`·`Satellite`·`Hybrid` 셋 다 200
- 내부 이름(`http://paleolab/GSM/`)으로도 막히지 않았다. 도메인 제한에
  걸릴까 걱정했는데 걸리지 않는다
- 브라우저가 타일 46 장을 받는 동안 오류 응답이 하나도 없었다

**지질도 투명도를 내려야 배경이 보인다.** 지질도는 불투명하게 그려지므로
100% 로 두면 배경을 덮는다. 55% 쯤에서 갑천·유성온천역·도로가 지질도 아래로
비친다 — 지질을 지형·시설과 견주어 보는 자리가 이것이다.

열쇠는 저장소에 넣지 않는다. 브라우저로 나가는 것은 맞지만
(도메인 제한으로 지키는 방식이다) 저장소에 적을 까닭은 없다.
