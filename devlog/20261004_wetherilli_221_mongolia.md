# 몽골 — MonGeoCat 국가지질도첩 지질도·단층, 동아시아 묶음에

2026-10-04 · `feature/mongolia` · wetherilli

`docs/아시아_오세아니아_지질도.md` 의 추천 순서 넷째. 국가 원본이고 영어 속성이 함께 온다.

## 1. 문 — `mris.py`

- 상류는 `gismap.mris.mn/arcgis` 의 `Atlas/1_Geology`(지질)·`Atlas/2_Faults`(단층 1:50만)다. **문서에 없는 주소다** — MonGeoCat 화면
  (`webgis.mris.mn`)의 JS 묶음에서 찾았다. 예고 없이 바뀔 수 있어 주소는 `GSM_MRIS_URL` 한 곳에 둔다
- 조사 때는 REST `export`·`identify` 로 보았는데, 서비스에 **WMSServer 가 켜져 있어** WMS 로 붙였다. 다른 ArcGIS 문(DINAMIGE·IIGE)과 같은
  길이라 화면이 따로 할 일이 없다. Capabilities 는 4326·CRS:84 만 적지만 3857 GetMap 이 그린다(256² 1.2 초)
- **WMS 번호와 REST 번호가 거꾸로다** — WMS `1` 이 지질, `0` 이 국경. 우루과이(wetherilli 196)와 같다. 이름은 WMS 번호로 `mris:<판>:<번호>`
- 속성은 `application/geojson` 이 모양 없이 1 KB 로 온다 — 몽골어·영어 두 벌. 팝업은 영어 열을 쓰고 몽골어 이름은 "원 이름" 으로 함께 둔다
- **버린 것:** `Atlas/9_Tectonic`(구조도). WMSServer 가 꺼져 있다. REST export 로 따로 붙일 만큼 급하지 않다
- **버린 것:** 같은 서버의 `MonGeoCol/*`. 1:5만 진행 사업의 현장 수집용이라 건드리지 않는다

## 2. 시대 — 러시아식 층서 지수에서

지질시대 열이 따로 없다. 기호(`Label`)가 러시아식 층서 지수다 — `aQ₂`(충적층·제4기 2), `J₂₋₃`(쥐라기 중~후기), `γ₂O₂₋₃b`(화강암·
오르도비스기 중~후기). 앞의 소문자·그리스 글자(성인·암석)를 건너뛰고 대문자 지수를 읽어 ICS 이름을 짓는다(`mris.age_of`).

- **제4기는 둘로만 가른다** — 이 지질도첩은 Q2 를 홀로세, Q1 을 플라이스토세로 쓴다(속성의 `aQ₂` 가 "Holocene sediment"). 러시아 표준의
  Q1–Q4 와 다르다
- **`E` 가 둘을 겸한다** — 속성의 기호는 `Є`(캄브리아기)·`₽`(고진기)를 제 글자로 쓰는데, 범례 칸 이름은 둘 다 `E` 로 적는다.
  단위 코드로 가른다 — 다섯 자리 3xxxx 는 고진기, 여섯 자리(310xxx·관입암 9xxxxx)는 캄브리아기. 범례 255 칸에서 이 규칙이 맞았다
- 석탄계 C1·C2 는 미시시피아·펜실베이니아로, 실루리아계 S1–S4 는 랜도버리~프리돌리로 옮겼다. 러시아의 석탄계 3 분은 ICS 의 2 분과
  경계가 다르다 — C2 를 펜실베이니아로 친 것은 어림이다
- 범례 255 칸 가운데 252 칸이 풀린다. 못 푸는 셋은 코드만 있는 칸(`10000`), 멜란지, `bazF1v`

## 3. 범례 — 목록으로

WMS 의 그림 범례는 칸이 255 라 쓸모없이 길다. 우루과이처럼 ArcGIS REST `legend?f=json` 을 받아 목록으로 낸다(`mris/legend/`). 칸 이름이
`10100_Q2` 꼴이라 코드는 떼고 지수를 기호로, 풀린 시대를 곁에 적는다. 단위 이름은 범례에 없다 — 누르면 뜬다.

- **버린 것:** 보는 범위의 범례(호주·페루의 꼴). REST 통계 질의를 더 해야 하는데, 전국 한 장이라도 칸이 255 뿐이라 목록으로 충분하다

## 4. 탭과 동아시아 묶음

- 지역 `mongolia`(3857). **동아시아 묶음에 넣었다** — 같은 3857 이고, 중국(geo3al)과 맞닿아 넓게 볼 때 이어진다. 묶음 탭은 레이어가 제
  범위 밖 타일을 묻지 않아(024) 한국을 볼 때 몽골 상류를 타지 않는다. 묶음의 처음 범위(한국·일본)는 그대로 두었다
- 3D 는 ArcGIS WMS 가 3857 로 그려 `MAP3D_WMS` 에, 3D 의 동아시아 묶음에도 넣었다
- 색은 고비 바얀작 "불타는 절벽"의 주황 — 공룡 알이 나온 백악기 사암의 빛이다
- 딱지는 `NGS`(국가지질조사소) — "MonGeoCat" 은 칸을 넘친다
- 마이그레이션은 `0035_region_mongolia` — #203 의 0034 뒤에 걸었다
