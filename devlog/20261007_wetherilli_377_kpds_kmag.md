# 다누리 자기장 측정기(KMAG) 궤적 — KPDS 문과 모아 두기

2026-10-07 · `feature/kpds-kmag` · wetherilli

## 왜

사람이 우주항공청(KASA)에 올라온 API 를 찾아 달라고 했다. 우주항공청이 직접 여는 오픈 API 는 우주환경센터의 우주기상 열 개
(경보·예보·지자기·전리층)뿐이라 지도에 얹을 것이 없었다. 쓸 만한 것은 산하 항우연의 **KPDS** — 다누리(KPLO) 과학자료를
PDS4 로 내는 곳이다. 회원가입·인증키가 없고 "모든 과학자료는 계획된 일정에 따라 제약없이 일반인에게 공개" 한다.

## 본 것

- **지도가 될 가공 산출물이 없다.** Derived 는 SPICE 커널뿐이고, 탑재체 자료는 궤도마다·날마다의 관측이다 —
  KGRS(감마선) Calibrated 는 하루 900 MB 의 스펙트럼 CSV, PolCam 은 한 장 500 MB, LUTI 는 한 장 1.8 GB
- **문서화된 API 가 없다.** 검색 화면의 자바스크립트가 부르는 주소(목록 `dataTableList`, 라벨 `xml/<_id>`, 내려받기
  `download/<이름>`)를 그대로 쓴다. 목록은 검색 화면을 한 번 열어 받은 쿠키가 있어야 답한다
- **LUTI 촬영 자리는 접었다** — 다른 세션이 맡았는데, 목록 한 행에 base64 썸네일이 붙어 16 887 행이 4–5 GB 였다(TODOs)
- KMAG Calibrated 는 하루 한 파일(CSV 2.6 MB, 4 초 간격, 942 날)이고 우주선 자리(SEL, km)와 자기장(nT)이 함께 있다

## 한 것

- `kpds.py` — KPDS 로 나가는 문. 목록에서 썸네일을 버리고, 내려받은 zip 을 푼다
- `kmag.py` — 하루치를 **32 초마다 한 점**(50 km 남짓)으로 줄여 `<KPDS_DIR>/kmag.sqlite`(R*Tree)에. 궤적(`tracks`)과 누른 자리(`nearest`)
- `manage.py fetch_kmag` — 1.5 초 간격으로 새 날만. 처음 40 분 남짓

## 고른 것과 버린 것

- **|B| 로 궤적을 칠하지 않는다**(사람이 골랐다). 고도 60 km 의 |B| 는 태양풍·지구 자기권의 바깥 자기장이 대부분이라 칠하면 지각
  자기 이상처럼 읽힌다. 바깥 자기장을 걷어 내는 것은 연구 수준의 일이다. 누른 자리에서 시각·고도·|B| 만 보인다
- SEL 을 달 고정 좌표계로 읽었다 — 라벨이 정의를 적지 않는다. 궤도 경도가 하루에 13° 남짓 서쪽으로 밀리는 것이 달의 자전과 맞다
- 달에서 3 000 km 넘게 떨어진 점(2022 년 8–12 월 달로 가던 길)은 버린다
- 4 초를 다 두면 2 천만 점이다. 32 초면 250 만 점 남짓

## 남은 것

- 달 화면의 레이어(타일·극 평면·누른 자리) — 다른 세션에 넘긴다
- KPDS 는 석 달마다 더한다 — cron 에 둘지는 레이어가 선 뒤에 정한다
