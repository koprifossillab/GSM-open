# 005 — 손질이 안 뜬 까닭, 그리고 로고

2026-09-23

## 무엇을 겪었나

v0.2.0·v0.2.1 에서 손본 것 — 먹갈색 테마, 지도 위 손잡이, 팝업 첫 줄의
위경도, 카탈로그 접기, 그리기 박스 — 이 **배포한 화면에 하나도 안 떴다.**
배포는 됐다. 컨테이너는 `v0.2.1` 이었고 HTML 도 새것이었다.

## 까닭 — 주소가 그대로인 `immutable`

`deploy/nginx/GSM-subpath.conf` 가 `/GSM/static/` 을 이렇게 내보낸다.

```
expires 7d;
add_header Cache-Control "public, immutable";
```

`immutable` 은 "이 주소의 내용은 절대 안 바뀐다" 는 약속이다. 그런데
`map.css`·`map.js` 는 판이 바뀌어도 주소가 같았다. 브라우저는 약속대로
7 일 동안 묻지도 않고 옛 파일을 썼다. **HTML 만 새것이고 CSS·JS 는 옛것**
이라, 새 HTML 의 손잡이 칸이 옛 CSS 에서는 자리를 못 잡고 지도 아래로
흘러내렸다 — "스크롤 아래로 내려가서 더 불편해졌다" 가 그것이다.

settings.py 에는 "해시 이름은 쓰지 않는다 — 판 올리기로 충분하다" 고 적혀
있었는데, 판 번호가 주소에 들어가지 않으니 충분하지 않았다.

## 고친 것 — 내용 표를 주소에 붙인다

`views.asset_stamp()` 가 `map.css`·`map.js`·`emblem.svg` 의 내용과 판 번호로
짧은 표를 만들고, 템플릿이 `?v=<표>` 로 붙인다.

- **해시 이름(Manifest)으로 가지 않은 까닭**은 settings.py 의 앞선 판단과
  같다. 파일 하나가 빠지면 화면 전체가 멈추는 쪽보다, 붙이는 표 하나가 틀려도
  캐시만 헛도는 쪽이 낫다
- **판 번호만 붙이지 않은 까닭** — 같은 판을 다시 구울 때가 있다 (오늘도
  두 번 있었다). 내용으로 만들면 판을 안 올려도 바뀐 것이 새 주소를 탄다
- nginx 는 그대로 둔다. 주소가 바뀌니 `immutable` 이 이제 참말이 된다

## 옛 판의 CSS 도 틀려 있었다

캐시를 걷어도 v0.2.1 은 먹갈색이 아니었다. 밝은 크림색 판 위에 어두운 판과
금색 판이 **덧칠로** 올라가 있었는데, 어두운 판의 몇 줄이
`:root[data-theme="auto"]` 에도 걸려 **밝은 화면에서도** 좌표 막대와 손잡이만
검게 칠했다. 바탕은 크림, 막대는 먹색인 어정쩡한 화면이 그래서 나왔다.

CSS 를 토큰 한 벌로 다시 썼다. 테마는 토큰만 바꾼다. 기본은 로고의 색
(`#2b1d10` 바탕, `#c9a24b`·`#e8c876` 금)이고, 밝은 바탕은 **한지** 하나만 둔다.
"자동" 을 뺀 것은, 기기가 밝은 설정이면 자동이 크림색을 골라 버려서 먹갈색을
기본으로 삼는다는 뜻이 무너지기 때문이다.

## 페이지가 밀려 올라가던 것

캐시와 따로, 새 판에도 페이지가 906px 로 늘어나는 탈이 있었다. 휴지통
단추 안의 화면 읽개용 이름(`.sr`)이 `position: absolute` 인데 기준이 되는
조상이 없어서, 패널의 굴림 칸을 빠져나가 페이지 맨 밑까지 내려가 있었다.
무엇이든 `scrollIntoView` 하면 페이지째 올라가 지도 위 손잡이가 사라진다.
단추들에 `position: relative` 를 주어 제 안에 가뒀다.

## 로고와 대기 화면

로고는 사람이 그린 것을 받았다(`docs/brand/`). 화면에 쓰는 `emblem.svg` 는
**선을 굵게 다시 그렸다** — 원본은 240px 판에 선 굵기 1.2 라, 46px 로 줄이면
0.2px 가 되어 사라진다. 바탕의 육각 무늬도 작게는 얼룩이 되어 뺐다.

대기 화면은 gif 의 바탕색과 똑같은 `#2b1d10` 위에 띄운다. 다르면 gif 의
네모 테두리가 드러난다. **CSS 파일보다 먼저 그려져야** 해서 `<head>` 안에
인라인으로 두었다. 첫 `rendercomplete` 에 걷되, 너무 빨리 걷히면 깜빡이는
것처럼 보여 1.2 초는 보이고, 상류가 멈춰도 12 초 뒤에는 걷는다.
