# 024 — 일본, 그리고 동아시아: GSJ 심리스 지질도를 타일째 중계한다

2026-09-28

사람이 GSJ(산업기술종합연구소 지질조사종합센터)의 심리스 지질도를 받아 올 수
있느냐고 물었고, 일본을 **따로 된 탭으로도, 한국과 묶은 동아시아로도** 보고
싶다고 했다. 문은 `viewer/gsj.py` 하나다 — `gbank.gsj.jp/seamless/v2/api/1.3` 만 부른다.
열쇠가 없고, 이용 조건은 일본 정부표준이용규약 2.0 이다(출처만 밝히면 상업 이용까지 된다).

## WMS 가 있는데 타일 API 를 쓴다 — WMS 는 옛 판이다

GSJ 는 WMS(`gbank.gsj.jp/ows/seamlessgeology200k_b`·`_d`, MapServer)도 연다. 우리
프록시(`/wms/`)에 그대로 얹히니 처음에는 그쪽이 쉬워 보였다. 같은 자리(후지산
서쪽, 3857 로 35.45°N 138.57°E)를 둘에 물어 대조했다.

| | WMS (`/ows/…_d`) | 타일 API (`/seamless/v2/api/1.3`) |
|---|---|---|
| 기호 | `N1vb` | `N12-221_som_N2` |
| 속성 | `legend_ja`·`expl_ja` — 일본어뿐 | `formationAge_en`·`lithology_en`·`group_en` 에 일본어 짝 |
| 범례 | 칸이 수백 — V1 | 2 416 칸 — V2, 2026-05-10 판 |
| 한 장 | 0.3–2.2 초 | 0.13 초 (구워 둔 타일) |

WMS 는 **V1** 이다. CLAUDE.md "받아온 것의 순위 — 새 것이 이긴다" 대로 V2 를 준 쪽을
쓴다. 영어 속성이 딸려 오는 것도 크다 — 영어판의 팝업을 우리가 옮기지 않아도 된다.

그래서 WMS 꼴이 아니다. 타일은 z/x/y(자리 차례는 **z/y/x**)로, 속성은
`legend.json?point=위도,경도` 로 받는다. `/wms/`·`/featureinfo/`·`/legend/` 를 타지
않고 `gsj/<레이어>/{z}/{x}/{y}.png`·`gsj/info/`·`gsj/legend/` 셋을 따로 뒀다. 캐시·옛것
내주기·안내 타일은 다른 상류와 같다. 화면은 한국과 같은 3857 이라 옮겨 그릴 것이 없다.

## 무엇을 얹었나 — 한 장씩 받아 보고

001 의 함정(목록에 있는데 그리면 빈 레이어)을 피하려고, 레이어마다 네 자리(후지산·
시코쿠 중앙구조선·도쿄 서쪽·히다카)에서 줌 6·11·13 한 장씩 받아 칠해진 몫을 쟀다.
GetCapabilities 가 없는 API 라 레이어는 API 안내의 `layer`·`type` 에서 골랐다.

| 레이어 | API | 줌 | z11 칠해진 몫 |
|---|---|---|---|
| 20만 심리스 지질도 | `layer=g` | 0–13 | 99–100 % |
| 간략 (14 구분) | `layer=g&type=level2` | 0–13 | 99–100 % |
| 지질 경계 | `layer=l` | 10–13 | 4–19 % |
| 단층·요곡 | `layer=f` | 10–13 | 0–13 % |
| 범례 기호 | `layer=s` | 11–13 | 0–1 % (z13 에서 1–2 %) |

- 원본 API 의 `glfs` 같은 겹친 레이어는 두지 않았다. 따로 켜고 끄는 편이 KIGAM 과 같다
- `type=level1`(6 구분)은 얹지 않았다 — 14 구분과 뜻이 겹치고, 6 구분은 지질도라기보다 암석 대분류다
- 경계·단층·기호는 줌 10·11 밑에서 상류가 빈 타일을 준다. **서버는 그 줌을 묻지 않고**
  빈 타일을 내고, 화면은 레이어를 숨기며 "줌 N 부터 그려진다" 를 적는다

**빈 자리는 `blank.png` 로 301 이 온다.** 따라가면 한 자리에 두 번 묻는다. 따라가지
않고(`allow_redirects=False`) 우리가 투명 타일을 내며, 그것도 캐시에 담는다 — 바다
한가운데를 다시 물을 까닭이 없다.

## 속성 — GSJ 가 붙인 영어를 올린다

| 팝업 | 받은 열 | 한국어판 | 영어판 |
|---|---|---|---|
| 지질시대 | `formationAge_en` | 옮긴다 (아래) | 그대로 |
| 암상 | `lithology_en` | **그대로 (영어)** | 그대로 |
| 구분 | `group_en` | 퇴적암·화성암·변성암·부가체·기타 | 그대로 |
| 기호 | `symbol` | 그대로 | 그대로 |
| 암상 (원문) | `lithology_ja` | 그대로 (일본어) | 그대로 |

**암상은 영어로 둔다.** 우리가 옮긴 것이 아니라 GSJ 가 붙인 영어이고(CLAUDE.md
"속성 값은 옮기지 않는다" 에 걸리지 않는다), 한국어판을 쓰는 사람에게 가나 섞인
일본어보다 읽힌다. 일본어 원문은 밑에 한 줄로 둔다. 간략판은 `group_en` 없이
대분류가 곧 암상으로 와서(`Accretionary complex`), 그때는 대분류를 옮긴다(부가체).

**지질시대는 위 단위부터 겹쳐 온다** — `Cenozoic Quaternary Holocene`. `age_ko`(021)는
한 조각에 낱말 하나만 받아 이 꼴을 못 옮긴다. `i18n.age_ko_stacked` 를 새로 두었다.
규칙은 021 과 같다 — **모르는 낱말이 하나라도 섞이면 통째로 원문**이다.

- 2 416 칸의 시대 값 112 가지 가운데 **23 가지(393 칸)만 옮겨진다.** 나머지는 절(Age)
  이름(`Albian`·`Norian`·`Burdigalian` …)이 섞여 영어로 뜬다. 절의 한국어 표기가 하나로
  굳지 않은 것은 스발바르(021)와 같은 사정이다
- **꾸밈말이 겹친 것도 원문이다** — `late Late Pleistocene` 는 후기 플라이스토세를 다시
  나눈 것인데, 옮기면 "플라이스토세 후기 후기" 가 된다. 화면에서 이것을 보고 막았다
- 바다·매립지를 누르면 `symbol` 이 null 인 200 이 온다. 빈 목록으로 돌려준다
  ("이 자리에는 아무것도 없다")

## 범례 — 보는 범위의 것만, 화면이 그린다

원본은 범례가 2 416 칸이다. 그림 한 장으로 붙일 수 없다. API 가 `box=` 로 범위의
범례를 주므로 **지금 보는 범위에 든 것만** 묻고, 지도를 옮기면 다시 묻는다.

- **줌을 함께 준다.** `box` 만 주면 상류가 줌 13 으로 세어 1°×2° 범위부터 400 을
  돌려보낸다. 화면의 줌을 주면 범위가 늘 화면 한 장 크기라 한도 안에 든다(1°×2° 를
  z8 로 물으면 167 칸, 0.2 초)
- 범위는 소수 둘째 자리(1 km 남짓)로 잘라 캐시에 담는다. 칸은 200 까지만 보이고
  "…그 밖 N칸 — 더 들어가면 줄어든다" 를 붙인다
- **그림이 아니라 JSON 으로 받아 HTML 로 그린다.** 서버의 Pillow 는 한글·일본어 글꼴이
  없다(`tiles.py` 머리글). NPI(021)처럼 그림을 이어 붙이면 네모가 찍힌다
- 간략판은 14 칸을 통째로 준다. 선·기호는 API 가 범례를 주지 않아 GSJ 원본 뷰어로 잇는다
- 색은 `r·g·b` 를 쓴다. `value` 는 원본의 색이라 간략판에서 어긋난다

## 배경 — 국토지리원 지리원 타일

VWorld 의 짝으로 국토지리원 타일 넷(담색·표준·항공사진·음영기복)을 얹었다. 브라우저가
곧장 부른다 — 열쇠가 없고 CORS 가 열려 있다(`*`, 2026-09-28 확인). 일본 밖(서울)은
줌 8 까지만 그리고 9 부터 비어 있다. 일본 탭의 기본은 **담색**이다 — VWorld 백지도를
고른 까닭(004)과 같다. EOX 둘도 일본에서 고를 수 있다.

## 동아시아 — 북극처럼 묶음이다

한국과 일본이 같은 3857 이라 섞어 켜는 데 걸릴 것이 없다. 북극(021)과 같은 틀이다 —
`REGIONS.eastasia.includes = ["korea", "japan"]`, DB 에는 지역으로 적지 않는다.
레이어·레이어군 앞에 "한국 ·"·"일본 ·" 이 붙는다.

- **동아시아는 한국을 품으므로 한국 것이 다 돈다** — VWorld 배경·주소 찾기·한국
  좌표계·KIGAM 인증키 띠(`korea-only` 가 동아시아에서도 보인다)
- 기본 배경은 EOX 지형 음영이다. 한국과 일본을 다 덮는 것이 그것이다(VWorld 는
  한국만, 지리원은 일본만 자세하다)
- 처음 켜는 것은 한국 100만·일본 20만 — 넓게 보는 탭이라 각자 가장 넓은 판이다
- **묶음 탭에서는 레이어의 범위(`bbox`) 밖 타일을 묻지 않는다.** 처음에는 일본을 볼 때
  한국 100만 지질도가 일본·바다 자리까지 KIGAM 에 물었다(키가 없는 자리에서는 안내
  타일이 일본을 덮어 눈에 띄었다). KIGAM 은 호출 제한을 조심하는 상류다(010).
  레이어에 범위를 걸어 도쿄 둘레에서 KIGAM 요청이 0 이 되었다. 상류가 적은 범위가
  빠듯할 수 있어 0.5° 넉넉히 둔다. 한국 탭은 그대로 두었다 — 거기서는 늘 한국을 본다.
  북극(3413)은 위경도 네모가 부채꼴이라 걸지 않는다
- 다른 나라가 오면 `includes` 에 더한다. 옆 세션이 중국 지질도를 받을 곳을 찾는 중이다

## 색

일본은 **벚꽃** — 짙은 자두빛 바탕에 벚꽃 분홍. 처음에는 쪽빛·주홍을 생각했지만
쪽빛은 스발바르의 국기 남색과, 주홍은 얀마옌의 용암 주황과 겹친다. 동아시아는
**청자** — 먹녹 바탕에 비색. 두 나라가 함께 빚은 것에서 땄고, 품은 지역의 색(금·
분홍) 어느 쪽도 아니다. 남극의 청록보다 회색이 돌고 밝다.

## 옆 세션과 겹치지 않게

같은 저장소에 다른 세션(중국 지질도 조사)이 떠 있어서 `japan` 가지를 worktree 로 떼어
지었다. 마이그레이션(0009)·devlog(024) 번호는 그쪽에 물어 맞췄다 — 그쪽은 뒤의
번호(0010·025)를 쓴다. 023 의 규칙대로 CHANGELOG·version·TODOs·HANDOFF·CLAUDE.md 는
이 가지에서 건드리지 않았다. 넣을 줄은 합칠 때 사람이 적는다.

## 남은 것

- **찾기 칸** — 일본 탭은 좌표로만 간다(남극과 같다). 국토지리원의 주소 검색 API 가
  있는 것으로 알지만 이번에 살피지 않았다. 붙이면 문이 하나 더 는다
- 절(Age) 이름의 한국어 — 스발바르(021)와 같은 표가 생기면 GSJ 도 저절로 따라온다
- `prewarm` 이 GSJ 를 모른다. 타일이 0.13 초라 급하지 않다
- GSJ 는 호출 제한 수치를 밝히지 않는다. `upstream_stats` 에 `gsj` 로 쌓인다 — 지켜본다
- 캐시 열쇠에 판이 없다. 상류가 판을 올려도(V2 의 다음 갱신) API 주소(`1.3`)가
  그대로면 알 길이 없어 3 년 규칙(007)을 따른다. 주소가 바뀌면 `GSM_GSJ_URL` 을 고친다
- 개발 기계에서 헤드리스 브라우저로 확인할 때 GSI·EOX 타일이 인증서 오류로 막혔다
  (망이 TLS 를 가로채는 듯하다 — 설정에 `CA_BUNDLE` 이 있는 까닭). 인증서 검사를 끄고
  봤다. 사람의 브라우저에서는 EOX 가 이미 같은 길로 돌고 있어 걸리지 않을 것으로 본다
