# 미리 데우기의 메타타일 계획을 극지 격자로

2026-10-05 · `feature/metatile-polar-2` · wetherilli

판 세션이 맡긴 일이다 — wetherilli 307 이 화면 길의 메타타일을 극지·캐나다·4326 격자로 넓혔는데, 미리 데우기의 메타타일 계획(`MetaPlan`, wetherilli 284)은
3857 만 골랐다. 307 위에 쌓았다.

## 고친 것

- `plan_for` 가 메타타일 레이어를 고를 때 "3857 이면" 을 "3857 이거나 메타타일이 아는 지역 격자(`metatile.GRIDS`)면" 으로 넓혔다. 블록을 짓는 셈은
  `WmsPlan.fetch_block` 이 이미 격자(`tilegrid.Grid`)를 따라 했으므로 손대지 않았다 — 블록의 칸 (bx·2, by·2) 는 화면 길의 `x // 2 * 2` 와 같다
- 잘라 낸 칸을 조각 열쇠에 담을 때 **화면 길이 셈하는 칸 그대로**(`metatile.cell`)를 쓴다 — 극지는 열쇠에 투영이 들고, 스페인 IGME 4326 은 미리 데우기의 격자
  (줌 0 이 360° 한 장)와 메타타일의 격자(줌 0 이 180° 두 장)의 줌 번호가 하나 다르기 때문이다. 칸의 테두리는 같다
- **그린란드 GEUS ArcGIS(`geusarc`)는 아예 미리 데우기의 목록(`PROJECTED`)에 없었다**(wetherilli 259 가 빠뜨렸다). 더했다 — 이제 메타타일 계획으로 데운다
- 한 블록에 상류 한 번, 블록 사이 12 초(메타타일 상류의 하한, 284)와 차단 조짐이면 멈추는 것은 그대로다

## 확인

시험이 서남부 1:10만을 계획으로 골라 3413 블록 하나(`1024,1024`, `bboxSR=3413`)를 받고, 칸 넷을 화면 길이 찾는 조각 열쇠에 담는지 본다.
