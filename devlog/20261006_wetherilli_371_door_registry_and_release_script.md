# 문이 제 파일에 자기를 적는다 — 공유 줄 충돌을 없애고, 판 내기를 명령 하나로

2026-10-06 · `feature/door-registry` · wetherilli

## 왜

2026-10-04~05 에 세션 넷이 이틀 만에 팀이 함께 쓰는 사용량의 92% 를 썼다. 다시 보니 일의 상당 몫이 기능이 아니라 **맞추기**였다.

- **같은 줄이 부딪혔다.** 상류 하나를 더하면 고칠 자리가 공유하는 긴 줄 일곱에 흩어져 있었다.
  - views 의 import 줄·`UPSTREAM_ERRORS`·`_Door.MODULES`·"열쇠 없는 상류" 줄·`MAP3D_WMS`
  - prewarm 의 `PROJECTED`
  - map.js 의 `UPSTREAM_TAGS`·`UPSTREAM_NAMES`·`LAYER_KINDS`

  세 세션이 같은 줄 끝에 이름을 붙이니 PR 마다 충돌이 났다. "main 에 맞춰 주세요" 가 수십 번 오갔고, 판 세션이 정규식으로 충돌 덩이를 합친 것도 여러 번이다.
- **판 하나에 대화가 열 번 남짓 오갔다.** CI 기다리기 → 병합 → 릴리스 → 태그 CI → 이미지 → 컨테이너 확인 → 배포 → healthz → 소스·정적 판. 하루에 19 번 냈다.
- **순찰이 길었다.** gh·docker 를 여러 번 부르고 긴 출력을 대화에 쌓았다. 끝난 일을 다시 맡긴 것도 세 번이다(남은 TODOs 줄 때문).

## 한 것

### 1. 문의 명세 — `REGISTRY` 와 `doors.py`

문 파일마다 끝에 `REGISTRY` 를 둔다. 상류마다 dict 하나에 다음을 적는다.
- 딱지·기관 이름
- 중계하는가(`relay`)
- 투영으로 받는가(`projected`)
- 3D 에 얹는가(`globe`)
- 열쇠가 필요한가(`ready`)

`doors.py` 가 `viewer/*.py` 를 글자로 훑어 `REGISTRY =` 가 든 파일만 import 하고, 위의 일곱 표를 짓는다. 화면에는 `upstreams` JSON 으로 싣는다.
- map.js 는 딱지·이름을 그 표에서 읽는다.
- `LAYER_KINDS` 에는 손이 다른 상류(GSJ·대만·점 레이어 따위)만 남긴다. `projected` 상류는 `npolarSource` 를 쓴다.

이제 새 상류는 **제 문 파일과 씨앗만** 고친다. `seed_catalog` 의 씨앗 줄과 settings 의 경로, CLAUDE.md 의 문 목록은 아직 공유 줄이다(아래 "남긴 것").

옮기는 동안 표 일곱의 값을 스크립트로 뽑아 그대로 옮겼다. 달라진 것은 둘이다.
- **오류 튜플** — `REGISTRY` 를 둔 파일이 정의한 예외를 다 모은다. 전에는 손으로 적어 BAS 의 것만 들고 대만 문의 `LegendTooWide`(GsmmaError 의 자식이라 이미 잡혔다) 따위는 빠져 있었다. 중계하지 않는 문(STRI·VMME 따위)의 예외도 들지만, 중계 길에서는 일어나지 않는다.
- **미리 데우기의 `PROJECTED`** — `projected` 에서 `NO_STORE`(파는 자료 — 남아공·나미비아)를 뺀 것이다. 전 목록에는 미국 주 넷(네바다·워싱턴·오리건·알래스카 DGGS)이 빠져 있었다. 줄 끝에 붙이다 놓친 것으로 보고 넣었다.

### 버린 것

- **가운데 표 하나(`doors.py` 에 모든 상류)** — 충돌하는 자리가 한 파일로 옮겨 갈 뿐이다. 문마다 제 파일에 적어야 PR 끼리 같은 줄을 만지지 않는다.
- **import 해서 훑기(`pkgutil`)** — 호스트에서만 도는 문(gfs·era5 — numpy·ecCodes)을 컨테이너에서 부르면 깨진다. 그래서 글자로 먼저 거른다.
- **views 의 import 줄 지우기** — 다른 뷰가 문을 이름으로 부르는 자리가 많다(퀘벡·유콘의 `friendly` 따위). 새 문이 거기 들 일이 없으면 import 할 까닭도 없어진다.

### 2. `deploy/release.sh` — 판 내기

`prep`(판 PR)·`ship`(CI 기다리기, 깨지면 한 번 다시 → 병합 → 릴리스 → 태그 CI → 이미지)·`deploy`(컨테이너 안에 다른 일이 없으면 갈아 띄우고 healthz)·`publish`(GSM-open·정적 판)를 `all` 로 잇는다.
판 세션이 10-05 에 손으로 돌린 명령을 그대로 옮겼다. 다른 점은 둘이다.
- 색인 줄을 글쓴이마다 그 표 끝에 붙인다(전에는 wetherilli 만).
- 컨테이너 안에 gunicorn 아닌 것이 돌면 멈춘다.

### 3. `deploy/status.sh` — 순찰을 스무 줄로

- 운영·main 의 판
- 열린 PR 과 CI 상태
- 마지막 태그 뒤에 병합된 PR 수와 제목

`status.sh <말>` 은 그 말이 든 PR 을 열린 것·병합한 것 모두에서 찾는다 — 일을 맡기기 전에 끝난 일인지 본다.

## 남긴 것

- **`seed_catalog` 의 씨앗 줄·settings 의 `*_CATALOG_SEED`** — 씨앗 JSON 이 `_지역`·`_상류` 를 이미 품으니 글롭으로 바꿀 수 있다. 레이어군 차례(`_레이어군차례`)가 겹치지 않는지 따로 봐야 해서 이번에 넣지 않았다.
- **i18n 의 `LAYER_EN`** — 레이어마다 한 줄이라 충돌이 덜하지만 끝에 붙이면 부딪힌다. 씨앗 JSON 에 영어 제목을 두는 길이 있다.
- **CLAUDE.md 의 문 목록** — 사람이 정할 것(#153)으로 남아 있다. 문 목록을 "`REGISTRY` 가 안다" 로 바꾸면 이 충돌도 사라진다.
