# 정적 판 — 판 이력을 떠 두고, 소개의 첫 장면에서 없는 화면을 뺀다

2026-10-04 · `fix/static-intro-history` · wetherilli

사용자: "정적 판에서는 판 이력이 안 나오네?", "소개 페이지 첫 화면에 지원하지 않는 지도들이 같이 표시되는데, 이것들도 보이지 않게 처리해야겠다."

## 1. 판 이력

설정 창은 서버의 `patchnotes/`(CHANGELOG.md 를 그때그때 읽는 뷰)를 부른다. 정적 판에는 그 주소가 없어 "판 이력을 읽지 못했다" 가 떴다.
굽을 때 같은 뷰를 한 번 불러 `patchnotes.json` 으로 떠 두고, 정적 판의 화면은 그것을 읽는다. 판 이력은 한국어뿐이라 말마다
따로 두지 않고 뿌리에 한 벌이다(`map.js` 의 BASE 는 영어판에서도 뿌리다).

`patchnotes/index.html` 에 JSON 을 넣어 주소를 그대로 두는 길도 있었다 — 화면은 안 고쳐도 되지만 HTML 이름에 JSON 이 든 파일이
남는다. 화면 한 줄을 고치는 쪽을 골랐다.

## 2. 소개의 첫 장면

wetherilli 167 은 문(갈래 카드)과 장면(3D·우주)만 뺐고, 첫 장면은 서버 판 그대로였다 — 구에 달·화성·수성이 떠 있고, 칩에
일본·동아시아·온 지구·달·화성·수성·"3D 지형" 이 있었다.

- **구는 지구 하나** — 정적 판이면 템플릿이 달·화성·수성 그림(`data-moon` 따위)을 싣지 않고, `Globes` 는 그림이 적힌 몸만 그린다.
  안 쓰는 그림 셋을 받지도 않는다
- **지역 칩은 실린 지역만** — 칩마다 `data-region` 을 달아 문과 같은 잣대(`loaded`, 묶음은 둘 이상 실려야)로 감춘다. 지역을
  더 실으면 칩이 저절로 돌아온다. 온 지구·달·화성·수성·"3D 지형" 은 지역이 아니라 서버 화면이라 템플릿이 뺀다
- **둘째 장면에 쏟아지는 그림**에서도 3D·온 지구·달·화성·수성·실리지 않은 묶음(동아시아)을 뺀다. 템플릿의 `data-names` 는
  `test_intro` 가 원문을 읽어 그림 파일이 있는지 보므로 그대로 두고, 화면(`intro.js`)이 거른다

정적 3D 는 이슈 #153 에 미뤄 두었다 — 서면 "3D 지형" 칩과 3D 장면을 돌린다.

## 3. 시험

`test_static_site` 에 넷 — `patchnotes.json` 을 떴는지, 구운 소개의 첫 장면에 달·3D 가 없는지(한국어·영어), 설정 창에 판 이력이
뜨는지, 소개 칩이 실린 지역만 남는지.
