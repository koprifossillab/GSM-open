# 관리 화면 — 반입 탭에 양식 예시를 펼쳐 보인다 (CSV·JSON·API)

2026-10-01 · `feature/manage-format-examples` · wetherilli

사람이 "우리 양식 예시를 업로드 페이지에 같이 보여 주면 좋겠다", 이어서 "API 양식도 예시가 있어야겠다" 고 했다. 118 의
반입 탭에는 예시를 **내려받는** 단추 넷(점·면 × JSON·CSV)뿐이라, 열어 보기 전에는 무엇을 적어야 하는지 알 수 없었다.

## 예시 상자

반입 상자 바로 밑에 "양식 예시" 상자를 둔다. 모양(점·선·면) × 꼴(CSV·JSON·API)을 골라 글을 그 자리에서 보이고, 꼴마다
지킬 것을 다섯 줄 남짓 적는다. 복사·내려받기·**이 예시로 읽어 본다**(그 글을 반입처럼 읽혀 미리 보기에 띄운다).

- **글은 손으로 적지 않고 내려받기·반입과 같은 코드(`P.toCSV`·`P.toGeoJSON`)로 만든다.** 손으로 적은 예시는 읽개가 바뀌면
  어긋난다 — 126 에서 선을 더했을 때처럼. 시험 삼아 여섯 가지를 다 "읽어 본다" 로 돌려 모두 받아들여짐을 보았다
- JSON 은 `JSON.stringify(…, 2)` 로 펴면 좌표가 한 줄에 하나씩 서서 화면을 다 덮는다. 머리는 펴고 열 설명·피처는 한 줄에 하나로
  적었다
- 점 예시에 좌표가 빈 행(S-03)을 일부러 둔다 — "좌표 없는 행도 버리지 않는다" 를 보이려고
- 선 예시를 더했다(126 에서 선을 받게 되었다). 첫 머리의 안내 문장도 "점·선·면, 섞이면 나눈다" 로 고쳤다

## API 탭

연결 레이어(122·126·129)의 상대가 지킬 것을 요청·응답 한 쌍으로 보인다 — `GET` 과 인증키를 싣는 세 꼴(머리·Bearer·주소 뒤),
응답의 `Content-Type`·CORS 머리, 본문은 JSON 예시 그대로. 밑에 지킬 것(200, 인증 넷, CORS 를 열면 곧장, IP 로 막으면 우리
서버 IP, 20 MB·20 초·넘겨주기, 목차 주소도 된다). 양식 문서(`docs/개인레이어_양식.md` "연결")의 줄임이다. "API 로 잇기" 상자에도
이 탭으로 가는 단추를 두었다.

영어판의 번역 키에 `\"` 가 끼면 JS 의 원문(`"`)과 표의 열쇠(`\"`)가 갈려 옮겨지지 않는다 — 따옴표를 쓰지 않게 문장을 고쳤다.
