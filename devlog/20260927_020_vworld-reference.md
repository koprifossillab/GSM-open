## 왜 처음부터 중계인가

배경지도(WMTS)는 브라우저가 곧장 부른다(003). WMS 는 그러지 않았다.

- `GetFeatureInfo`·WFS 가 CORS 로 막혀 있다(004). 속성을 읽으려면 어차피 중계다
- 중계하면 **열쇠가 안 나간다.** WMS 는 도메인 없이도 돌았다(아래) — 열쇠가
  페이지에 실리면 누구든 그것으로 WMS·WFS 를 부를 수 있다
- 타일 캐시(007)를 그대로 탄다. `views.wms` 는 레이어의 `upstream` 을 보고
  문(`vworld.py`)만 바꾼다 — 캐시·옛것 내주기·안내 타일은 KIGAM 과 같이 쓴다

**도메인(`domain=`)은 붙이지 않는다.** 서버에서 부르니 도메인이 있든 없든 같은
타일이 왔다. 주소 검색(009)도 붙이지 않고 돈다.

알아둘 것 — VWorld WMS 는 **레이어명이 소문자라야** 돈다(대문자면 예외 XML).
`styles` 는 비워도 된다. 속성은 GeoServer 의 JSON 그대로다.

## 단층은 선으로 받는다

WMS 단층은 초록 선 한 가지다(VWorld 범례). 지질도 위에서 초록은 묻히고, 줌을
당기면 번진다. WFS 로 모양을 받으면 선 색·굵기를 우리가 정하고, 누르면 속성이
**상류를 다시 타지 않고** 뜬다.

**문서화된 열쇠 길로 간다.** 선은 KIGAM GeoServer(문서에 없는 주소)의 25만
지질도에도 있지만, 제품이 도는 길은 식별되는 쪽이어야 한다(CLAUDE.md "두
개의 상류 주소"). VWorld WFS 는 공개 문서가 있고 열쇠로 계량된다.

WFS 와 데이터 API(`data=LT_L_GIMSFAULT`) 둘 다 돈다. **WFS 를 골랐다** — 모양마다
`id`(`lt_l_gimsfault.156`)가 있어 칸 경계에서 겹쳐 온 것을 하나로 칠 수 있고,
길이(`leng`)도 준다. 데이터 API 는 `legend` 하나만 준다.

### 칸으로 받는다 — bbox 도 타일도 아니다

- **화면 범위(bbox)를 그대로 넘기면** 지도를 조금만 움직여도 요청이 달라져
  캐시가 맞지 않는다. 상류를 매번 탄다
- **XYZ 벡터 타일 격자로 자르면** 줌마다 격자가 달라 같은 선을 줌마다 다시
  받는다. 게다가 격자가 EPSG:3857 에 묶인다 — 지역마다 투영이 달라지는
  중이다(극지)

그래서 **위경도 1° 칸**으로 자른다. 칸 이름(`lon=127&lat=36`)은 투영과 상관이
없고, 줌이 바뀌어도 같은 칸이다. 브라우저는 보이는 범위를 위경도로 바꿔 덮는
칸만 부르고 받은 칸은 다시 부르지 않는다. 서버는 칸 하나를 한 번 받아 캐시에
담는다. 레이어 범위 밖의 칸은 상류에 묻지 않고 빈 것을 준다.

**한계를 쟀다.** 남한 전체 단층이 2414 개다. 1° 칸 하나에 많아야 150 개 남짓
(대전 둘레 167 개, 84 KB)이라 WFS 상한 1000 에 닿지 않는다. 남한을 다 덮어도
50 칸 남짓이고, 한 번 받으면 캐시에서 나간다. 경상분지를 한 화면 보는 데
WFS 가 5 번 나갔다.

### `legend` 의 뜻은 모른다

값이 두 가지다 — 1 이 2259 개, 2 가 155 개. 2 는 경상분지(129°E 35°N,
128°E 36°N)에 몰려 있고 선이 짧다(꼭짓점 평균 2.8 개, 1 은 6.5 개). 추정단층이나
다른 도폭에서 온 것일 수 있지만 VWorld 는 밝히지 않았고, VWorld 범례도 한
가지 선뿐이다.

**뜻을 지어 붙이지 않았다.** 팝업과 범례에 "구분 1·2" 로 값 그대로 적고, 눈으로
갈리게 2 를 끊은 선으로 그린다. 뜻이 밝혀지면 `map.js` 의 `VECTOR_STYLES` 와
`vworld.FRIENDLY` 두 자리만 고치면 된다.

## `Layer.kind` 를 더했다

레이어가 "타일을 얹는 것" 과 "모양을 받아 그리는 것" 으로 갈린다. 이름으로
가르거나(`…@wfs`) 코드에 목록을 두는 길도 있었지만, 그러면 카탈로그 밖에서
레이어의 성질이 정해진다. 씨앗 한 칸(`"kind": "vector"`)이 정하게 했다.
그린란드의 점 레이어도 같은 칸을 쓰면 된다.

화면에서는 `makeLayer()` 가 둘을 가르고, 벡터는 `vectorLayerFor(row)` 한 곳에서
짓는다. 켜기·끄기·투명도·차례·밀어 보기·나란히는 OpenLayers 레이어라면 다
돌기 때문에 손댈 것이 없었다. 팝업만 갈랐다 — 벡터는 누른 선의 속성을 서버가
곁들여 보낸 것(`_popup`)으로 곧장 띄우고, 서버에 다시 묻지 않는다.
