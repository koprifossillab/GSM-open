# 온 지구 — 구의 그리기가 멈췄을 때

2026-09-30 · `fix/earth-render-error` · wetherilli

사람이 온 지구 화면에서 Cesium 의 "RuntimeError: Fragment shader failed to compile. Compile log: null" 로 구가 멈춘 것을 보았다(달 세션이
전했다). 달 세션이 헤드리스(swiftshader)로 운영 v0.25.6 에서 레이어 열 개·250 Ma·20 ka·연대와 구/평면 오가기를 되풀이했지만
되살아나지 않았다.

## 1. 까닭 — 셰이더가 아니라 문맥

기록(log)이 `null` 인 셰이더 실패는 셰이더가 틀린 것이 아니라 **WebGL 문맥을 잃은 것**이 거의 늘이다 — 그래픽 메모리가 모자라거나
드라이버가 GPU 를 다시 시작하면 브라우저가 문맥을 거둬 가고, 그 뒤의 셰이더 엮기가 기록 없이 실패한다. 잃은 문맥은 Cesium 이
되살리지 못한다. 그래서 막을 수는 없고 **멈춘 뒤를 사람의 말로** 바꾼다.

- Cesium 의 영어 오류 창(`showRenderLoopErrors`)을 끄고, `scene.renderError` 와 캔버스의 `webglcontextlost` 를 받아 멈춘 자리에
  안내를 띄운다 — 까닭 한 줄과 나갈 길 셋
  - **새로고침**
  - **가볍게 다시 연다** — 지형 세우기와 지구 속(맨틀, 106)을 끄고. 둘이 GPU 를 가장 많이 먹는다(지형은 타일마다 높이 격자,
    맨틀은 한 시점에 삼각형 20 만 남짓과 땅 비치기)
  - **평면으로** — 평면은 OpenLayers 라 구와 따로 돈다. 보던 가운데를 그대로 평면으로 연다
- 헤드리스 크롬에서 `WEBGL_lose_context` 로 문맥을 잃게 해 안내가 뜨고, "평면으로" 가 평면으로 다시 여는 것을 보았다

## 2. 버린 것

- **문맥을 되살리기** — Cesium 은 잃은 문맥의 자원(타일·셰이더·지형)을 다시 짓지 못한다. `Viewer` 를 새로 짓는 것은 화면의 모든
  레이어·점묶음·그린 것을 다시 붙여야 해서, 새로고침과 다를 바 없다
- **`requestRenderMode`** — 바뀔 때만 그려 GPU 를 쉬게 하지만, 타일이 들어올 때마다 다시 그려 달라고 불러야 하는 자리가 곳곳이다.
  재현이 되면 그때 본다

## 3. 남긴 것

- 재현 조건(브라우저·GPU·켠 레이어)을 사람에게 묻는 중이다(달 세션). 특정 레이어 조합에서 되풀이되면 그것을 가볍게 한다
