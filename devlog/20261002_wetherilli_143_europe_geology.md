## 2. 사용자와 정한 것

- **영국·프랑스 탭 둘에 "유럽" 묶음.** 처음엔 "유럽" 탭 하나를 권했다(셋 다 3857 이라 묶을 까닭이 적다). 사용자가 동아시아·북극처럼
  나라 탭을 두고 묶음으로 모으는 쪽을 골랐다. `models.REGIONS` 에 `uk`·`france` 가 늘어 0020 이주가 생겼다(수성 0019 뒤)
- **EGDI 1:100만도 넣는다.** BGS 1:5만은 1:94 495 보다 가까울 때만 그려(3857 줌 13 부터) 영국 탭을 처음 열면 빈 화면이다. BRGM 도
  판마다 그리는 줌이 좁다. EGDI 가 그 사이를 메운다
- **레이어 아홉** — BGS 셋(기반암·표층 퇴적층·선 구조), BRGM 넷(1:100만·1:25만·1:5만 통합 스캔, 1:100만 단순 암상도), EGDI 둘(시대·암상)

## 3. 줌 — 상류가 그리는 곳에서만 묻는다

판마다 그리는 축척이 정해져 있어, 그 밖의 줌에서는 빈 그림을 받는다. 2026-10-02 에 파리·리즈에서 줌마다 한 장씩 받아 쟀다.

| 판 | 그리는 화면 줌 |
|---|---|
| BGS 1:5만 (셋 다) | 13– |
| BRGM 1:100만 스캔 | 6–11 |
| BRGM 1:25만 스캔 | 11–12 |
| BRGM 1:5만 통합 스캔 | 12– |
| BRGM 단순 암상도 | 6–14 |

GetCapabilities 의 `Min/MaxScaleDenominator` 만으로는 줌을 정하지 못했다 — MapServer(72 dpi)·ArcGIS(96 dpi)·OGC(0.28 mm)가 같은
축척을 다른 해상도로 읽는다. 그래서 잰 것을 문(`bgs.MIN_ZOOM`·`brgm.ZOOMS`)에 적고 카탈로그가 `minZoom`·`lastZoom` 으로 화면에
알린다. `minZoom` 은 일본(024) 때 생긴 것이고 `lastZoom`(이보다 가까우면 숨긴다)은 이번에 더했다 — GSJ 의 `maxZoom` 은 "그 위는
늘려 그린다" 는 뜻이라 같은 이름을 쓰지 않았다. 숨겨진 레이어는 패널에 "줌 13 부터 그린다" 가 뜬다(있던 기능).

## 4. EGDI 는 한 곳에 두고 빌린다

레이어명은 지역 하나에만 걸린다(`Layer.name` 이 유일). EGDI 는 영국에도 프랑스에도 깔려야 한다.

- **영국 지역에 두고 프랑스가 빌린다** — `REGIONS.france.borrow = { uk: ["egdi"] }`. 스발바르가 북극해의 EMODnet 을 빌린 틀(135)
  그대로다. 유럽 묶음에는 한 번만 든다
- 묶음 탭은 레이어(군) 앞에 지역을 적는데(`영국 · …`), 빌려 쓰는 상류에 "영국" 을 붙이면 틀린 말이 된다. 묶음의 다른 지역이 빌리는
  상류면 지역을 붙이지 않게 했다(`map.js` 의 `wherePrefix`)
- 지역을 하나 더 두어(DB 의 `europe`) 거기 EGDI 를 넣는 길도 있었다. 그러면 묶음 이름이 DB 에 들어가 "묶음은 DB 에 없다" 는 틀이 깨진다

## 5. 속성

- BGS — 열이 쉰 남짓. `FRIENDLY` 에 적은 것만 — 지층명·암석·갈래·지질시대·세·가장 오랜/젊은 시기·층군·생성 환경, 선은 선 구조·단층
  이름, 그리고 도폭과 BGS 어휘집 링크. `Not Applicable`·`No Parent` 는 빈 칸으로 친다. 지질시대·세는 ICS 한글판으로
- BRGM — 스캔은 그림이라 누를 것이 없다(`queryable: false`). 단순 암상도만 암상·갈래를 준다. 값은 프랑스어 그대로
- EGDI — GetFeatureInfo 가 시대 판은 PostgreSQL 오류를, 암상 판은 20 초 뒤 빈 답을 준다. 누르지 못하게 두고(`egdi.QUERYABLE`),
  누가 불러도 상류를 타지 않고 빈 답을 낸다

## 6. 버린 것·남은 것

- **영국 국가 좌표(27700)·프랑스 람베르트-93(2154)으로 받기** — 상류가 받긴 하지만 3857 탭에서 옮겨 그릴 까닭이 없다. 중위도라 3857 의
  축척 부풀림이 작다(북위 54° 에서 1.7 배)
- **EMODnet 을 유럽 탭에 빌리기** — 영국·프랑스 둘레 바다를 덮지만 EMODnet 레이어는 3413 으로 받게 되어 있고 3413 의 범위가 북위 50°
  언저리에서 끝난다. 하려면 3857 로 받는 판을 따로 둔다
- BRGM 1:100만 스캔에는 종이 지도의 여백(회색 테)이 그대로 있다 — 스캔이라 그렇다. 거슬리면 단순 암상도를 먼저 켠다
- EGDI 는 한 장에 9 초 남짓 — 첫 화면이 느리다. 캐시가 데워지면 낫다. `prewarm` 에 넣을지는 캐시 TODO 와 함께 본다
- 북아일랜드(GSNI)·아일랜드(GSI)·독일(BGR)·스페인(IGME)은 같은 묶음에 더할 수 있다
