# 구름 1 단계 — 모델 구름량을 바람과 같은 시각으로

2026-10-01 · `feature/cloud` · koprifossillab

[P03](20261001_koprifossillab_P03_cloud.md) 의 1 단계다. 온 지구의 "움직이는 지구"(koprifossillab 010)에 레이어 "구름".

## 1. 무엇을 했나

- **GFS** — 바람과 같은 grib filter 요청에 `TCDC`·`LCDC`·`MCDC`·`HCDC` 와 그 층(entire atmosphere·low/middle/high cloud
  layer)을 더했다. 한 장이 3 MB 에서 9.7 MB 로 는다 — 예보 장에는 순간값과 0–3 시간 평균이 함께 오고, grib filter 는 둘을 가르지
  못한다. 푸는 쪽에서 **순간값만**(`stepType=instant`) 쓰고, `TCDC` 의 기압면 장(250 mb 가 딸려 온다)은 층으로 거른다
- **ERA5** — `total/low/medium/high_cloud_cover`. 새로 굽는 날에는 바람과 함께, `build_era5_wind --clouds` 는 바람만 구운 날에
  구름만 덧굽는다(날에 덩이 넷·9 MB 남짓)
- **굽는 꼴** — 종류마다 **회색 PNG**(`cloud-<종류>.png`, 0–255 = 구름량 0–1, 경도 −180 부터). 목록 한 줄에 `clouds` 로 있는
  종류를 적는다. 구름이 없는 GFS 줄(0.35 까지 받은 장)은 받기가 빠진 장으로 보아 그 판을 다시 받는다
- **화면** — 카드에서 지금/지난(바람과 한 축), 종류(전체·하층·중층·상층). 두 시각의 구름량을 가중치로 섞어 **흰색·투명도 영상 한
  장**을 만들어 구(Cesium 영상 레이어)와 평면(OpenLayers `ImageStatic`)에 덮는다. 처음 켜면 75% 로 비친다

## 2. 계획에서 바꾼 것

P03 은 서버가 흰색·투명도로 구워 두고 화면은 두 장의 투명도만 바꾸자고 했다. 짜기 전에 셈해 보니 **투명도 레이어 두 장을 겹치면
가운데 시각에 구름이 옅어진다** — 구름량 0.9(투명도 0.9)인 자리가 w=0.5 에서 1−(1−0.45)² = 0.70 이 된다. 그래서 서버는 구름량을
회색으로 주고, 화면이 **구름량을 섞은 뒤** 투명도로 바꾼다(`CLOUD_ALPHA` 표). 100 만 칸을 다시 셈하는 것은 가중치를 1/16 로 끊어
바뀔 때만 한다 — 지금의 것은 한 시간에 다섯 번 남짓, 재생은 하루 넘김에 열여섯 번이다. 영상은 `toBlob` → 객체 주소로 넘기고,
Cesium 은 새 장이 선 뒤(`readyEvent`)에 옛 장을 걷어 깜박이지 않게 했다

## 3. 시각을 맞추는 일을 바람에서 뗐다

전에는 목록·가중치·재생이 바람 그리기 안에 있어 바람을 끄면 멈췄다. 이제 둘 가운데 하나라도 켜져 있으면 돈다(`fluxShown`). 재생은
다음 날의 바람과 구름이 **둘 다** 왔을 때(`nextReady`) 섞기를 채운다. 카드의 시각 고르개는 두 카드가 함께 따른다

## 4. 해 본 것 (2026-10-01)

- 실제 NOMADS — 구름 없이 받았던 06 판을 다시 받아 다섯 장에 구름 넷(장마다 0.35–0.5 MB). ERA5 하루와 `--clouds` 덧굽기
- 브라우저 — 구(구름만·바람과 함께), 평면(4326), 극 평면(3031, 상층 구름). 두 카드의 시각 줄이 같고 페이지 오류 없음.
  가까이(1:4백만) 당기면 0.25° 칸이 흐릿하게 보인다 — 모델의 해상도다
- 흰 구름 위에서는 밝은 바람 입자가 묻힌다 — 구름을 처음 켤 때 75% 로 둔 까닭이다
- 시험 — 구름 주소, 회색 굽기·경도 돌리기, 덧굽기, GFS 의 순간값만 고르기(ecCodes 로 만든 GRIB2), 구름 없는 장 다시 받기.
  운영 이미지(numpy 없음)에서 뷰어 시험 전부 통과

## 5. 버린 것

- **투명도 레이어 두 장 겹치기** — 위
- **구름을 하늘에 띄우기**(구 위 몇 km) — Cesium 은 영상을 땅에만 덮는다. 따로 껍질을 지으면 지형·바람과 겹침 차례가 꼬인다
- **GFS 의 평균값으로** — 바람이 순간값이라 짝이 맞지 않는다
