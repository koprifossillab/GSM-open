# 화면이 주소를 짓는 타일에도 판을 — 길게(immutable) 캐시한다

2026-10-04 · `feature/immutable-js-tiles` · wetherilli

151 에서 주소에 판(`?v=`)이 든 우리 타일만 1 년 `immutable` 로 내기로 했다. 그때 선 것은 카탈로그가 주소를 주는 GeoMAP·IBCSO TID·
음영판뿐이다. 나머지는 화면의 JS 가 주소를 짓는다. JS 가 판을 모르니 붙일 수 없었다. 그 "판을 화면에 알리는 길" 을 냈다.

## 1. 판은 페이지에 싣는다

카탈로그에 싣는 길과 페이지 값에 싣는 길이 있었다. 달·화성·수성·온 지구 화면은 카탈로그가 없고(레이어 목록이 JS 에 있다),
IBCSO 배경은 레이어가 아니라 배경이다. 그래서 화면마다 `<script id="tile-versions">` 하나에 갈래 → 판을 싣는다
(`views.tile_versions(page)`). JS 는 `vq(갈래)` 로 `?v=…` 를 붙인다.

| 화면 | 갈래 | 판을 이루는 것 |
|---|---|---|
| 달·화성 | `orig` (원도·옛 지질도만 — Trek 판은 빼고) | `RENDERER` + sqlite 의 크기·고친 때 |
| 수성 | `geology` | `RENDERER` + sqlite 의 크기·고친 때 |
| 온 지구 | `paleo`·`crust`·`ne`·`icemargins` | `RENDERER` + 저장소 자료 파일의 내용 해시 |
| 온 지구 | `coast` | `RENDERER` + 파일의 크기·고친 때 |
| 온 지구 | `fossils`·`volcanoes`·`quakes`·`neotoma` | `RENDERER` + 구운(받은) 날 + 파일의 크기·고친 때 |
| 지역 탭 | `bed`·`ice` (IBCSO 배경) | 잘라 둔 폴더의 고친 때 (`_dir_version`, 151 의 TID 와 같다) |

상류에서 받는 것(Trek 통합 지질도·Macrostrat·화성 크레이터 따위)은 싣지 않는다. 화성 크레이터는 우리가 굽지만 캐시에 담지 않고
그때그때 그리는 것이라 이번에 넣지 않았다.

## 2. 판은 서버 캐시 열쇠와 같은 것이어야 한다

주소의 판만 바꾸고 서버 캐시 열쇠를 그대로 두면 일이 꼬인다. 파일을 다시 구워 주소가 바뀌어도 서버는 옛 열쇠로 옛 그림을 꺼내 주고,
브라우저는 그것을 새 주소에 1 년 묶는다. 그래서 **열쇠에 든 `RENDERER` 자리를 판 전체로 바꿨다.**
달·화성·수성 원도와 판 회전·옛 해안선·지각·지명·빙상은 전에는 열쇠에 `RENDERER` 만 들었다 — 파일을 다시 구워도 서버가 옛 그림을 냈다.
이번에 그것도 함께 고쳐졌다. 대신 **이 판을 올리면 그 타일들의 서버 캐시를 한 번 버리고 다시 굽는다**(지우지는 않는다 — 옛 열쇠로 남는다).

화석·화산·지진·고생태는 열쇠에 구운 날이 이미 들었다. 그런데 날짜가 하루 단위라 같은 날 다시 구우면 판이 그대로다.
1 년 묶는 주소에는 모자라 파일의 크기·고친 때를 더했다. 이것도 열쇠가 바뀌어 한 번 다시 굽는다.

## 3. 저장소 파일은 내용으로 센다

판 회전(`paleomap2016.json`)·지각·지명·빙상은 저장소의 `data/` 에 들어 이미지에 실린다. 고친 때는 이미지를 구울 때마다 바뀔 수 있다.
그것을 판으로 쓰면 판을 올릴 때마다 주소와 서버 캐시가 다 바뀐다. 그래서 내용의 해시를 쓰고, 고친 때가 바뀔 때만 다시 센다
(`_content_stamp`). `/srv/GSM/db/` 의 sqlite 는 수백 MB 라 해시하지 않는다. 사람이 `build_*` 로 다시 구울 때만 바뀌므로
크기·고친 때로 넉넉하다(`_file_stamp`).

## 4. 확인

- 시험: 수성 지질도를 다시 구우면 판과 열쇠가 함께 바뀐다(옛 주소는 새 그림을 하루짜리로). 화산은 같은 날 다시 받아도 판이 바뀐다.
  저장소 파일은 고친 때만 바뀌면 판이 그대로다
- 실제 파일로 서버를 띄웠다. 수성·지진·판 회전·IBCSO 타일이 판을 붙이면 `max-age=31536000, immutable`, 안 붙이면 하루였다
- 브라우저: 수성(`units`·`lines`), 온 지구(지각·화석·화산), 달(원도)이 주소에 `?v=` 를 붙여 불렀다
