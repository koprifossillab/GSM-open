## 2. 넷으로 가른다 — 바뀌는 빠르기대로

| | 파일·자리 | 드는 것 | 크기 | 언제 | 보관 |
|---|---|---|---|---|---|
| ① | `GSM.<YYYYMMDD>.tar.gz` | `GSM.db`(sqlite 사본 — **컨테이너가 뜬다**, 아래) · 스위치(`dev_direct_wms`·`public`, 있으면) · `kopri/` · `kigam50k/` · `earth/pbdb_collections.csv`(있으면) · 파일 시절의 데이터소스 명세 `sources.json`·`sources_history/` 와 기록 `store.sqlite`(P03 부터 둘 다 `GSM.db` 에 든다 — 옛 판으로 되돌릴 때를 위해 남긴다) · `fetch_log_host/`(호스트에서 손으로 부른 일의 기록, 날마다 한 파일) · `docker-compose.yml` · `manifest-built.txt` | 4.7 MB | 매주 | 모두 |
| ② | `GSM-built.<YYYYMMDD>.tar` | `db/` 의 나머지 — IBCSO·한반도·달·화성·GeoMAP·geo3al·얀마옌 | 1.4 GB, 파일 4 만 6 천 | **목록이 바뀐 주만** | 30 일까지 전부, 그 뒤 달마다 하나 |
| ③ | NAS `GSM/tiles/` | `/data/GSM/tiles/` 의 거울 | 1.2 GB | 매주 | 거울 하나 |
| ④ | `/data/GSM/sources/` | NAS `GSM/sources/` 의 거울 | 3.9 GB | 매주 | 거울 하나 |

①② 는 로컬과 NAS 둘 다에 있다. ③ 은 로컬 → NAS, ④ 는 NAS → 로컬이다 — 어느 쪽을 잃어도 다른 쪽에 남는다.
③④ 는 지우지 않는다(`--delete` 없음).

같은 날 두 번째 백업은 덮지 않고 `.2`·`.3` 을 붙인다(①·② 모두, jikhanjung 025). ① 이 받기 **전에** 뜨는 것이 요점이다 — `fetch_kopri` 는 목록에서 사라진 자료를 파일에서도 뺀다.

**`GSM.db` 의 사본은 컨테이너가 뜬다**(jikhanjung 017) — 호스트는 `GSM.db` 를 열지 않는다(사람, 2026-10-07). `docker compose exec -T … manage.py backup_db`
가 컨테이너 안에서 온라인 백업 → `integrity_check` → **로그인 세션을 비우고 VACUUM**(NAS 는 누구나 읽는다 — 세션 키가 곧 쿠키 값, jikhanjung 025)한 사본을 표준 출력으로 내고, 스크립트는 받은 파일의 머리와 `integrity_check` 를 한 번 더 본다
(살아 있는 DB 가 아니라 받은 사본이다). 컨테이너가 서 있지 않으면 백업은 실패로 끝난다.

| ⑦ | `fetch_pbdb` | 매주 — 그달의 첫 월요일은 통째로, 그 밖은 바뀐 것만(`--changed`, jikhanjung 026). **`db/earth/` 가 섰을 때만** | 통째는 CSV 110–160 MB·몇 분, 바뀐 것은 한 주에 수십 KB + 다시 굽기 1–2 분 |

⑦ 은 그 판이 배포되면 스크립트를 고치지 않아도 붙는다. 사람이 부르는 것(`prewarm`·`fetch_grportal`·`build_*`·
`fetch_moon_places`·`fetch_trek_catalog`)은 cron 에 두지 않는다.

## 4. 백업하지 않는 것과 다시 얻는 법

| 것 | 다시 얻는 법 |
|---|---|
| 코드 · 웹 이미지 | GitHub `koprifossillab/GSM` 태그 · Docker Hub `koprifossillab/gsm:<태그>` |
| 레이어 카탈로그 | 저장소 씨앗 — 컨테이너가 뜰 때 `seed_catalog` 가 채운다 |
| `kigam_key`·`vworld_key` | **일부러 뺀다**(NAS 는 누구나 읽는다). data.kigam.re.kr·vworld.kr 의 마이페이지에서 다시 본다 |
| `secret_key`·`/srv/GSM/.env` | 뺀다. 비밀키는 없으면 entrypoint 가 만든다 |
| `geus_whoami`·`allowed_hosts` | 뺀다. 한 줄짜리라 손으로 다시 쓴다(HANDOFF "배포한 자리에서 알아둘 것") |
| `pbdb.sqlite` | ① 의 CSV 로 다시 굽는다(`fetch_pbdb --csv`) |
| `hourly_status.json`·`upstream_host/` | 뺀다. 호스트가 매시 남기는 것을 컨테이너가 매시 `GSM.db`(①)로 들인다 — 넣으면 ② 가 매주 새로 뜬다 (jikhanjung 018) |

## 5. 잘 되고 있나

```bash
curl -s http://127.0.0.1:8094/GSM/healthz/ # status·notes — 걸리는 것이 notes 에 뜬다
cat /data/GSM/logs/last_backup.json        # result·step·backup·built·nas·tiles·sources·fetch
tail -40 /data/GSM/logs/weekly_backup.log
ls -la /data/GSM/backups/ /nfs/temp-share/GSM/backup/
```

- `"result": "ok"` 에 `"step": "fetch"` — 다 했다. `note` 가 "NAS 쪽을 본다" 면 `nas`·`tiles`·`sources` 가운데 `fail` 이 있다
- `"built": "same"` — 구운 것이 지난번과 같아 ② 를 뜨지 않았다
- `"result": "fail"` — `step` 에서 멈췄다. `backup`·`built` 면 백업이 안 떴다. `fetch` 면 백업은 떴고 받기만 실패했다
  (지난 파일 그대로)

손으로(paleoadmin):

```bash
/srv/GSM/scripts/weekly_backup.sh --backup-only   # ①② 와 NAS 만 (20 초 남짓)
/srv/GSM/scripts/weekly_backup.sh --no-fetch      # ①–④
```

같은 날 다시 돌리면 그날의 ① 을 덮어쓴다.

## 6. 되살리기

```bash
B=/data/GSM/backups                                   # 또는 /nfs/temp-share/GSM/backup
W=$(ls $B/GSM.*.tar.gz | sort | tail -1); G=$(ls $B/GSM-built.*.tar | sort | tail -1)

# 1) 구운 것 — db/ 에 푼다. 없으면 NAS 원본(또는 /data/GSM/sources)으로 build_* 를 부른다
tar -xf "$G" -C /srv/GSM/db
# 2) 다시 못 얻는 것 — 컨테이너를 멈추고 GSM.db 를 바꾼다
docker compose -f /srv/GSM/docker-compose.yml stop web
tar -xzf "$W" -C /srv/GSM/db --exclude docker-compose.yml --exclude manifest-built.txt
docker compose -f /srv/GSM/docker-compose.yml up -d web
# 3) 캐시 — 없어도 뷰어는 돈다
rsync -rt /nfs/temp-share/GSM/tiles/ /data/GSM/tiles/
~/projects/GSM/deploy/host/smoke.sh
```

- ① 의 `manifest-built.txt` 는 그 주의 구운 것 목록이다. 풀어 둔 것과 맞는지는 `cd /srv/GSM/db && sha256sum -c
  manifest-built.txt --quiet`
- 서버를 통째로 잃었으면: `/srv/GSM/` 에 ① 의 `docker-compose.yml` 과 `.env`(`deploy/srv/env.template`), `db/` 에 설정
  파일 한 줄씩(§4) → 위 1)–3) → 이미지는 Docker Hub 에서 `pull`

## 7. 모자란 것

- **NAS 는 같은 건물·같은 망이다** — 건물 사고는 못 막는다
- **`/healthz/` 는 알리기만 한다** — 누가 늘 들여다보지 않으면 `degraded` 도 조용히 지나간다. `smoke.sh` 가 판을 올릴 때
  적어 줄 뿐이다
- **점묶음을 쓰기 시작하면 주 1 회로 모자란다** — 그때 `GSM.db` 사본을 날마다(DiaRUGA·ForGIA 의 시간별 틀) 더한다
- 되살리기는 임시 폴더에 풀어 `manifest-built.txt` 와 대조만 했다(2026-09-30, 46 561 파일 일치). 운영에 실제로
  되살려 보지는 않았다
