# 아시아·오세아니아·북대서양 섬의 지질도 API

2026-10-04 · 검토 (계획이 아니다) · [다른_대륙_지질도.md](다른_대륙_지질도.md) 의 뒤를 잇는다

아직 찔러 보지 않은 곳 — 인도·몽골·러시아·카자흐스탄, CCOP 밖의 동남아, 중동·튀르키예·이란, 뉴질랜드·파푸아뉴기니,
아이슬란드·페로 — 의 지질도 API 를 웹에서 찾아 **실제로 찔러 본** 기록이다. 형식은 `다른_대륙_지질도.md` 를 따랐다.
- 실측: 이 서버(paleolab)에서 `curl -A 'GSM/0.1'` 로 보냈다. 사내망 TLS 가로채기 때문에 필요할 때 `-k` 를 붙였다(조사에서만).
- 한 상류에 서너 번만 물었다. 응답 시간은 한 번씩 잰 어림이다.
- CORS 는 `Origin: https://koprifossillab.github.io` 를 실어 `Access-Control-Allow-Origin` 이 오는지 보았다.
- 서버에서 닿지 않는 곳은 바깥(WebFetch)에서 한 번 더 보았다 — 둘 다 막히면 "지역 차단" 으로 적었다.
- "붙이는 품" 은 상류 문 하나만 친 값이다. **지역 탭을 새로 세우는 품**(REGIONS·색·투영·씨앗 JSON·LAYER_EN·마이그레이션)이 따로 든다.

**조건이 적힌 곳이 드물다.** 아래에서 이용 조건을 글로 읽은 것은 뉴질랜드 GNS(CC BY 3.0 NZ)·아이슬란드 NÍ(CC BY 4.0)·
BGS 가 여는 인도 판(Free viewing)·BGR IGME5000(BGR AGB) 넷뿐이다. 나머지는 서비스의 copyright 칸이 비었거나 기관 이름뿐이라
**정적 판·밖에 열기 전에 사람이 읽는다.** 호주(GA)는 따로 붙고 있다(#194) — 여기서 재지 않았다.

## 남아시아·북아시아 — 인도·몽골·러시아·카자흐스탄

### 인도

#### GSI 1:200만 인도 지질도 — GSI 의 ArcGIS Online 피처 서비스 ★★★
- 주소: `https://services7.arcgis.com/MpVV35eHXsBYcufv/arcgis/rest/services/Geology_2M_WFL1/FeatureServer` — 지질 면 `7`(`GEOLOGY_2M`),
  `FAULT_2M`(4)·`THRUST_2M`(3)·`COMMODITY_2M`(2)·도시·강·주 경계. 소유자 `gisadmin.gsi`(GSI 관리 계정), 공개 항목
- [실측 2026-10-04] `?f=json` 200(2.8 s). `returnCountOnly` 면 4 555 개. 데칸(75°E 19°N) 점 질의 `f=geojson` 200(0.5 s) —
  `INDEX_: DECCAN TRAP`·`AGE: LATE CRETACEOUS - PALAEOCENE`·`SUPERGROUP`·`GROUP_`·`STRATIGRAPHY`. 레이어 JSON 에 `uniqueValue` 렌더러(523 칸)
- 축척: 1:200만 / CRS: 3857. 피처 서비스라 그림(export)이 없다
- 속성·범례: 풍부하다(영어). 범례는 `drawingInfo` 의 523 칸 색
- CORS: `*` / 키: 없다
- 조건: `licenseInfo` 비어 있음. GSI 의 이용 조건은 Bhukosh 가 열리지 않아 읽지 못했다
- 붙이는 품: 하루(면을 통째로 받아 우리가 칠한다 — `kind: points`·`render: image`, 2 000 개씩 세 번, 양자화). 아래 BGS 판과 짝지으면 반나절

#### BGS 가 여는 GSI 1:200만 (OneGeology) ★★★
