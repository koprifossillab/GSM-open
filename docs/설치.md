# root 가 필요한 설치

paleo-server 에 GSM(대돌여지도)을 세우는 절차. **sudo 를 쥔 사람이 한 번만
돌리면 된다** — `sclee` 는 sudo 그룹에 없어 이 부분을 못 한다
(`sudo:x:27:paleoadmin`).

굽기·시험·컨테이너 띄우기는 sudo 없이 되므로 여기 없다.

## 한 줄

```bash
sudo /home/sclee/projects/GSM/deploy/host/install-srv.sh
```

## 무엇을 하는가

| | |
|---|---|
| `/srv/GSM/{db,tiles}` | 만들고 `paleoadmin:paleoadmin` 으로 둔다. 컨테이너가 1000:1000 으로 돈다 |
| `/srv/GSM/docker-compose.yml` | 저장소의 `deploy/srv/docker-compose.yml` 을 복사 (이미 있으면 안 건드린다) |
| `/srv/GSM/.env` | 본(`deploy/srv/env.template`)을 복사. **인증키는 사람이 채운다** |
| `/etc/nginx/snippets/GSM-subpath.conf` | 새로 놓는다 |
| `/etc/nginx/sites-enabled/phyloserver` | `include snippets/GSM-subpath.conf;` 한 줄을 ForGIA 조각 뒤에 넣는다 |
| `/srv/paleolab/index.html` | Foram Viewer 카드 뒤에 GSM 카드를 끼운다 |
| nginx | `nginx -t` 후 `systemctl reload nginx` |

**여러 번 돌려도 된다.** 이미 되어 있는 것은 건너뛰고, 고치는 파일은 전부
`.bak-<날짜시각>` 사본을 남긴다.

## 왜 80 포트의 서브패스인가

DiaRUGA·ForGIA 와 같은 까닭이다 — **사내 VPN 이 80 만 통과시킨다.** 그래서 이
장비의 앱은 전부 `127.0.0.1` 에만 묶이고 nginx 가 `/DiaRUGA/`·`/ForGIA/` 로
가른다. GSM 도 `/GSM/` 으로 같은 줄에 선다. 별도 포트(8083·8094)로 열어 보려
했지만 ufw 가 막는다.

- 정식 주소 `http://paleo-server/GSM/`
- 짧은 주소 `http://paleo-server/geomap/` → 위로 301
- 뒤에서 도는 곳 `127.0.0.1:8094`

## 되돌리기

```bash
# nginx
sudo rm /etc/nginx/snippets/GSM-subpath.conf
sudo sed -i '/GSM-subpath.conf/d' /etc/nginx/sites-enabled/phyloserver
sudo nginx -t && sudo systemctl reload nginx

# paleolab 카드 — 사본을 되돌린다
sudo cp /srv/paleolab/index.html.bak-<날짜시각> /srv/paleolab/index.html

# 자리
cd /srv/GSM && docker compose down
sudo rm -rf /srv/GSM
```

## 설치 뒤 — sudo 없이 한다

```bash
# 1) 인증키를 채운다 (아직 심사 중이면 비워 두어도 뜬다)
vi /srv/GSM/.env            # GSM_KIGAM_KEY=

# 2) 띄운다
cd /srv/GSM && GSM_TAG=v0.1.0 docker compose up -d web

# 3) 살아 있는지 본다
/home/sclee/projects/GSM/deploy/host/smoke.sh
```

이미지는 이 장비에 이미 구워져 있다(`koprifossillab/gsm:v0.1.0`). Docker Hub 에
올리지 않았으므로 `pull` 하지 않는다.

**인증키가 없어도 뜬다** — 타일 자리에 "인증키가 없다" 안내가 뜰 뿐,
레이어 패널·좌표·점묶음 업로드는 그대로 쓸 수 있다. 키를 넣은 뒤에는
`docker compose up -d web` 한 번이면 반영된다.

## 무엇을 하는 것인가 — 한 문단

한국지질자원연구원 지오빅데이터 오픈플랫폼의 오픈API 로 지질주제도(5만·25만
·100만 지질도, 지화학도, 해저지질도, 좋은물지도 등 61 종)를 겹쳐 보고, 지도를
클릭해 그 지점의 지층명·지질시대·대표암석을 읽고, 내 좌표 자료(CSV·GeoJSON)를
얹어 보는 뷰어. Django 5.2 + OpenLayers 이고 DiaRUGA·ForGIA 와 같은 틀로 세웠다.
자료는 그쪽과 나누지 않는다.
