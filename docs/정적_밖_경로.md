# 서버 없이 밖에 — 정적 사이트(GitHub Pages)로 한국·극지 탭을 낼 수 있나

2026-10-02 · wetherilli · 검토 (계획이 아니다)

> **같은 날 VWorld 절(§10)을 더했다** — "밖에 판을 낼 때 VWorld API 는 어떻게 굴러가나" 를 따로 쟀다.

연구소 서버를 밖에 열지(터널) 않고, **씨앗만 실은 정적 판**을 GitHub Pages 에 올려 연구소 밖 사람이 보게 하자는
안을 따진다. 사용자 안은 "서버를 두지 말고, 시드 데이터만 준 다음 한국은 내 인증키 그대로 쓰고, 극지는 극지
지도에서 쓰는 API 를 브라우저가 곧장 부른다" 이고, 뒤에 **"키를 박지 말고 각자 자기 키를 그 브라우저에만 넣는다"**
(bring your own key)가 더해졌다. 대상은 한국 탭과 극지 탭(그린란드·스발바르·얀마옌·남극·북극해·북극 묶음)이다.
정해지면 그때 P 문서를 쓴다.

## 1. 한 줄

**극지는 거의 된다. 한국은 "그림은 되고 속성은 반쪽" 이다. "내 키를 그대로 박는 것" 은 하지 않는다 — 키는
각자 넣게 한다.**

- 극지 상류는 GEUS·그린란드 포털·NPI·PGC·EMODnet 모두 **CORS 를 열어 두었다**(실측). 타일·속성·범례를 브라우저가
  곧장 받을 수 있다. 우리 파일에서 굽는 것(GeoMAP·IBCSO·얀마옌)은 미리 구워 씨앗으로 싣는다 — GeoMAP 만 크기가 걸린다
- KIGAM 은 두 길 다 **CORS 를 열지 않았다**(실측). 타일은 `<img>` 라 CORS 가 없어도 받히고, 범례도 그림이라 받힌다.
  속성(`GetFeatureInfo`)만 막히는데, 키 없는 `/mgeo/geoserver/wms` 가 **JSONP(`text/javascript`)를 준다**(실측) —
  이것으로 속성을 읽을 수 있다. 다만 그 길은 문서에 없는 주소이고, JSONP 는 상대의 스크립트를 우리 화면에서 돌린다
- 키를 정적 판에 박으면 누구나 그 키를 뽑아 간다. **운영 서버와 같은 키라 남이 두드려 막히면 운영까지 멈춘다.**
  CLAUDE.md "인증키는 브라우저에 절대 내보내지 않는다" 와도 정면으로 부딪힌다. 그래서 **키를 각자 넣는 방식(§6)이
  옳은 꼴**이다 — 키 없는 사람에게는 지질도 타일 자리에 "인증키를 넣으면 보인다" 를 띄우고, 나머지는 돈다
- 연구실 내부용(`views.LAB_ONLY` — geo3al·phyloserver·peninsula·kopri)은 정적 판에 싣지 않는다(§8)

## 2. 무엇을 쟀나 (2026-10-02)

연구소 망의 이 서버에서 `curl -s -A 'GSM/0.1' -D - -H 'Origin: https://koprifossillab.github.io' '<주소>'` 로
상류마다 두세 번, 3 초 간격으로 불렀다. `Access-Control-Allow-Origin`(아래 "ACAO")이 오는지와 상태를 봤다.
인증서 오류는 없었다(이번에 부른 주소들은 망의 TLS 가로채기에 걸리지 않았다).

**구분** — 타일과 범례 그림은 `<img>`(OpenLayers 의 기본)로 받으면 **CORS 가 없어도 보인다.** 다만 그 그림이
캔버스를 더럽혀 "그림으로 내려받기"(`map.js` 의 `exportPng`)가 깨진다 — 그걸 지키려면 `crossOrigin` 과 ACAO 가 둘 다
있어야 한다. 속성·범례 JSON·점 묶음처럼 `fetch` 로 읽는 것은 **ACAO 가 있어야만** 읽힌다.

### 2.2 재지 못한 것

- **키를 붙인 `/openapi/wms`** — 키는 서버의 `GSM_KIGAM_KEY` 이고 이 검토는 쓰지 않았다. 그래서 키가 있을 때 ACAO 가
  오는지, **github.io 의 Referer 로 부르면 막히는지**는 모른다. 사람이 브라우저 콘솔에서 한 번 재면 된다(§9 첫 줄)
- 극지 배경(EOX·GIBS·Esri 남극·NPI 배경·GEBCO)은 **지금도 브라우저가 곧장 부르므로**(CLAUDE.md "지역") 다시 재지 않았다
- GEUS 의 정사각 403 이 `whoami` 때문인지 정사각 꼴 때문인지 가르지 못했다 — 남의 이메일을 넣어 볼 수는 없었다.
  GEUS 가 권하는 길(`singleTile`, 화면 한 장)로 가면 어느 쪽이든 피한다(§5)

## 3. 인증키 — 박을 때의 위험

1. **CLAUDE.md 와 부딪힌다.** "인증키는 브라우저에 절대 내보내지 않는다. 이것이 이 저장소에 서버가 있는 이유다."
   정적 판은 그 이유를 없애는 판이다. 키를 박으려면 이 규칙을 사람이 고쳐 적어야 한다
2. **운영과 같은 키다.** 정적 판의 소스·네트워크 탭에서 키가 그대로 보인다. 누가 그 키로 두드려 "지나치게 잦은
   호출"(이용제한)에 걸리면 KIGAM 은 키(또는 키+IP)를 막을 것이고, **연구소 운영 서버의 지질도도 같이 멈춘다.**
   devlog 010 이 두려워한 것이 바로 이것이다
3. **우리 캐시가 사라진다.** 지금은 타일을 `tilecache` 에 담아 상류를 덜 탄다(devlog 007). 정적 판은 보는 사람마다
   KIGAM 을 곧장 부른다 — 같은 자리를 백 사람이 보면 백 번 간다. 키 하나에 그 호출이 다 몰린다
4. **이용약관** — `data.kigam.re.kr/about/terms` 에 "회원은 서비스를 이용하여 얻은 정보를 가공, 판매하는 행위 등
   서비스에 게재된 자료를 상업적으로 사용할 수 없습니다" 가 있다. 비상업 공개 뷰어는 걸리지 않아 보이나, 내 키로
   남에게 내주는 꼴이 "회원의 이용" 인지는 문서가 말하지 않는다

**줄이는 길과 그 한계**

- **공개용 키를 따로 받는다** — 운영 키와 갈라 두면 막혀도 운영은 산다. 가장 싸고 확실하다
- **도메인에 묶기** — `/guide/openapi` 와 약관에는 도메인·Referer·IP 제한이 **적혀 있지 않다.** 신청 쪽
  (`/my-openapi/request/`)은 로그인 뒤라 못 봤다. 다만 KIGAM 의 OpenLayers 예제 소스
  (`/map/openapimanual/openlayersSample.html`)가 **브라우저 코드에 키를 넣고**, 그 키 옆에 `//domain : 만능키` 라는
  주석이 붙어 있다 — 키가 보통은 도메인에 묶이고 그 키만 예외라는 뜻으로 읽힌다(짐작이다). 즉 **KIGAM 스스로
  브라우저에 키를 넣는 쓰임을 예제로 보인다.** 키가 신청 때 적은 주소에 묶인다면, 운영 서버용 키는 github.io 에서
  막힐 수 있고 공개 판에는 github.io 를 적은 키가 따로 있어야 한다. 사람이 신청 화면에서 확인해야 한다
- **GeoServer 길(`/mgeo/geoserver/wms`)** 로 가면 키가 아예 안 나간다. 그러나 CLAUDE.md 가 정한 것 — "제자리는
  `/openapi/wms` + 인증키다. 식별되는 쪽으로 나가는 것이 옳고, 문서에 없는 주소는 예고 없이 닫혀도 할 말이 없다" —
  과 어긋난다. 우리 서버는 요청 대부분(타일)을 식별되는 길로 보내고 속성만 GeoServer 로 보낸다. 정적 판이 타일까지
  GeoServer 로 보내면, **누가 부르는지 모르는 대량 호출**이 문서에 없는 주소로 몰린다. 닫히면 정적 판의 한국 탭은
  통째로 빈다. 속성만 이 길로 가는 지금의 갈림(`kigam.DIRECT_REQUESTS`)을 정적 판도 지키는 것이 맞다

## 4. 서버가 지금 하는 일 — 정적 판에서는 어디로

| 서버의 일 | 지금 자리 | 정적 판 |
|---|---|---|
| 카탈로그 | `seed_catalog` → DB → `views._catalog`·`catalog_json` | 빌드 때 `catalog.json` 으로 떠서 싣는다. `LAB_ONLY` 를 빼고(`GSM_PUBLIC=1` 과 같은 거름) 한국·극지 지역만 |
| 상류 고르기 | `views._upstream_of` + `_Door` | 카탈로그 행의 `upstream` 을 보고 브라우저가 고른다. `map.js` 의 `LAYER_KINDS` 가 이미 상류마다 손을 둔다 — 그 손의 `url: BASE + "wms"` 를 상류 주소로 바꾼다 |
| 타일 중계 | `views.wms` — `wmsSource`·`npolarSource` 가 `BASE + "wms"` 를 부른다 | KIGAM·EMODnet 은 TileWMS 를 상류로. **NPI·PGC 는 ArcGIS `export`/`exportImage` 라 WMS 꼴이 아니다** — 서버가 옮겨 주던 것(`npolar.export_params`·`elevation.get_map` 의 `renderingRule`)을 `ol.source.TileArcGISRest` 로 바꾼다. GEUS 는 `ImageWMS`(§5) |

| 속성 손질 | `feature_info` 의 거름(`_is_noise`·같은 것 하나로·`_split_links`)과 `geus.friendly`·`npolar.friendly`·`emodnet.friendly`·`vworld.friendly`, 영어판 `i18n.props_en`·지질시대 옮기기 | 표(`FRIENDLY`·`PROP_EN`·`AGE_STAGES` 따위)를 빌드 때 JSON 으로 떠 싣고 손질을 JS 로 한 벌 옮긴다. **파이썬과 JS 두 벌이 생긴다** — 시험이 둘을 같은 입력으로 대조해야 한다 |
| 범례 | `views.legend` — 담아 두고 `img.src = BASE + "legend/?layer=…"` | KIGAM·EMODnet 은 `GetLegendGraphic` 을 `<img>` 로 곧장. NPI 는 `legend?f=json` 을 받아 그린다(서버가 하던 것). GEUS 는 302 로 HTML 범례 쪽이 온다 — 링크로 연다. GeoMAP 범례는 우리 파일에서 미리 굽는다 |
| 캐시 | `tilecache.py` (운영 1.4 GB) | 없다. 브라우저 캐시뿐. **상류 부하가 보는 사람 수에 비례한다** — CLAUDE.md "받아온 것의 순위"·"미리 데우기" 가 다 빠진다 |
| GeoMAP 그리기 | `geomap.py` 가 gpkg(468 MB)에서 3031 타일을 그 자리에서 | 미리 구워 싣는다. 크기는 §7 |

| 얀마옌 | `janmayen.body` — NPI 파일(1.4 MB) → 위경도 GeoJSON | 빌드 때 구워 싣는다. 가볍다 |

## 5. 레이어별 — 정적 판에서

## 6. 키를 각자 넣는 방식 (bring your own key)

공개 판에 키를 하나도 싣지 않고, **보는 사람이 KIGAM 에서 받은 자기 키를 화면에 넣어 그 브라우저(localStorage)에만
둔다.** GEUS 의 `whoami` 도 같다 — 각자 자기 이메일.

**키를 매번 넣지 않게 — 사용자가 정했다(2026-10-02)**

- 넣은 키는 그 브라우저의 `localStorage` 에 둔다. 다음에 열 때 다시 묻지 않는다. 우리 서버도 GitHub 도 키를 보지 않는다
- "임시로" — 마지막으로 쓴 날부터 **30 일**이 지나면 저절로 지우고 다시 묻는다. 공용 PC 에 오래 남지 않게
- 설정 창에 **"키 지우기"** 단추. 키 칸 옆에 **"이 PC 에 기억하지 않기"** — 고르면 `sessionStorage` 에 두어 탭을 닫으면 사라진다
- 저장소가 막힌 브라우저(사생활 모드 등)에서는 그 탭 동안만 쓴다 — 읽기·쓰기를 try 로 감싼다(GSM 의 다른 localStorage 쓰임과 같다)
- 열쇠 이름은 `gsm.key.kigam`·`gsm.key.geus` — 기술이 소문자를 강제하는 자리라 `gsm`(CLAUDE.md "이름")

**좋은 것**

- §3 의 위험 1·2·3 이 거의 사라진다. 운영 키는 밖에 나가지 않고, 막혀도 그 사람 키만 막힌다. 호출이 키마다 갈려
  KIGAM 이 원래 바라는 "누가 부르는지 아는" 꼴이 된다. CLAUDE.md 의 규칙은 "**우리** 키를 내보내지 않는다" 로 읽으면
  그대로 지켜진다 — 사람의 키는 그 사람의 브라우저를 떠나 KIGAM 에만 간다
- GEUS 도 이메일을 저장소·공개 판에 적지 않아도 된다

**확인할 것과 지금 아는 것**

1. **키가 신청 때 적은 주소·IP·도메인에 묶이나** — 안내(`/guide/openapi`)·약관에는 없다. 신청 화면은 로그인 뒤라
   못 봤다. 예제 소스의 `//domain : 만능키` 주석이 "보통 키는 도메인에 묶인다" 를 짐작하게 한다. 묶인다면 **사람마다
   신청할 때 `koprifossillab.github.io` 를 적어야** 하고, 그걸 안내문에 써 둬야 한다. Referer 로 묶는다면 github.io 에서
   부르는 `<img>` 는 Referer 를 싣으므로 된다. IP 로 묶는다면 BYOK 는 사람마다 제 IP 를 적어야 해 사실상 어렵다
2. **`/openapi/wms` GetMap 을 `<img>` 로 받히나** — 키 없이 부르면 500 에 **HTML**(오류 쪽)이 온다(실측). 그림이 아니라
   `<img>` 의 `onerror` 가 난다. 키가 맞으면 PNG 가 오므로 `<img>` 로 받힌다(WMS 의 당연한 꼴이고, KIGAM 예제가 바로
   그렇게 쓴다). 그래서 **키 검사는 타일 한 장을 `Image` 로 불러 `onload`/`onerror` 로 가른다** — CORS 가 없어도 된다.
   틀린 키·키 없음·막힘을 서로 가르지는 못한다(본문을 못 읽는다)
3. **속성은 키 없는 GeoServer** — 서버가 지금 그렇게 한다(devlog 006). 그 길은 ACAO 가 없어 `fetch` 는 막히고
   **JSONP 는 된다**(실측). JSONP 는 상대가 준 스크립트를 우리 화면에서 돌리는 것이라, KIGAM 쪽이 털리면 우리 화면도
   털린다 — 개인 레이어의 키가 든 IndexedDB·localStorage 까지 닿는다. 받는 콜백을 하나로 두고, 정적 판에는 다른
   비밀(사람이 넣은 키 말고는)이 없다는 것을 받아들여야 한다. JSONP 를 피하려면 속성을 빼고 "그림만" 으로 낸다
4. **연결 레이어 틀을 다시 쓰는 법** — `personal.js` 의 연결 레이어(wetherilli P09·122)는 "주소·키는 그 브라우저에만,
   곧장 부르고 막히면 서버(`linked/fetch/`)" 다. 정적 판에서 쓸 수 있는 것과 없는 것:
   - **쓸 수 있다**: 키를 그 브라우저에만 두는 약속과 관리 화면(`/manage/`)의 입력·지우기 꼴, 키를 싣는 꼴
     (`withQuery` — `?key=`), `credentials: "omit"`. KIGAM 키 칸을 "상류 키" 로 하나 더 두면 된다
   - **그대로는 못 쓴다**: 연결 레이어는 우리 양식(`docs/개인레이어_양식.md`)의 JSON·CSV 를 `fetch` 로 읽는 틀이고,
     CORS 가 막히면 서버 문으로 돈다. KIGAM 은 WMS 타일이고 ACAO 가 없으며 정적 판에는 서버 문이 없다. 그래서 KIGAM
     키는 **연결 레이어가 아니라 `wmsSource` 가 `params.key` 로 읽는 설정 값**이다(지금 서버가 넘기는 `vworldKey` 와
     같은 자리). 저장은 localStorage 로 충분하다(글자 하나)
   - GEUS `whoami` 도 같은 설정 값 하나. 비워 두면 GEUS 를 `ImageWMS` 로만 부르거나 그린란드 지질도 자리에 안내를 띄운다
5. **안내** — 키가 없을 때 지금 서버의 "인증키가 없다" 안내 타일(CLAUDE.md "인증키")과 같은 뜻을 정적 판에서는
   레이어 패널의 한 줄로 띄운다("KIGAM 에서 인증키를 받아 넣으면 보인다" + 신청 주소). 키를 넣지 않아도 극지 탭·
   배경·개인 레이어·좌표 표시는 돈다

**남는 위험** — 사람마다 키를 신청해야 하는 문턱이 높다(회원가입·심사 — 우리 키도 심사에 며칠 걸렸다,
2026-09-23~27). 한국 탭을 보려는 대부분은 키 없이 들어와 빈 지질도를 볼 것이다. 이 문턱을 받아들일지가 갈림길이다.

## 7. GeoMAP 을 구우면 얼마나 되나 (어림, 재지 않았다)

gpkg 는 468 MB. GitHub Pages 는 사이트 1 GB·파일 하나 100 MB·월 100 GB 전송이 권장 한도다.
3031 격자에서 남극 대륙(약 1 400 만 km²)은 줌 10(한 장 13 km 남짓)에 레이어마다 8 만 장 안팎, 줌 9 에 2 만 장 안팎이다.
한 장 5–15 KB 로 치면 **여섯 레이어를 줌 10 까지 구우면 수 GB 라 못 싣는다.** 간추린 지질도 하나를 줌 9 까지, 나머지는
줌 7–8 까지로 줄이면 수백 MB 로 들어온다. 다른 길은 GeoMAP 을 벡터 타일(PMTiles 한 덩이)로 바꿔 브라우저가 그리는
것 — 속성도 같이 실려 클릭이 된다. 다만 `geomap.py` 의 색(`geomap_styles.json`)을 JS 로 옮겨야 한다.
어느 쪽이든 **줌을 깊이 들어가면 거칠어진다**는 것을 받아들여야 한다.

## 8. 연구실 내부용은 빠진다

`views.LAB_ONLY = ("geo3al", "phyloserver", "peninsula", "kopri")`. 정적 판은 **밖에 여는 판**이라 `GSM_PUBLIC=1` 과
같다 — 이 넷을 카탈로그에서 빼고 그 데이터·타일·씨앗도 저장소(공개 GitHub 저장소가 된다)에 싣지 않는다.

- geo3al(중국) — 대상 지역 밖이지만, USGS 이용 조건이 "내부 용도만, 제3자 재배포 금지"
- phyloserver·peninsula(한국) — 같은 서버의 연구실 자료·출처를 모르는 스캔판
- kopri(극지 44 종) — KPDC 공개 정책을 사람이 읽기 전까지. 극지 탭에서 빠지는 것이 가장 많다
  (남극 19·북극해 10·그린란드 8·스발바르 7)

## 9. 할 일 순서 (정한다면)

1. **사람이 잰다** — 자기 키로 github.io 에서(아무 정적 쪽이나 콘솔) `new Image().src = "https://data.kigam.re.kr/openapi/wms?…&key=<키>"`
   를 불러 `onload` 가 나는지. 나면 BYOK 가 선다. 안 나면 KIGAM 에 도메인 등록을 묻는다(042-868-3111)

3. 공개 판에 키를 박을지 BYOK 로 갈지 **사람이 정한다**. 박는다면 공개용 키를 따로 받고 CLAUDE.md "인증키" 절을 고쳐 적는다
4. 극지만 먼저 — 키가 필요 없는 그린란드(GEUS `ImageWMS`·포털)·스발바르(NPI)·PGC·EMODnet·얀마옌(구움)·IBCSO(구움)로
   정적 판을 세운다. GeoMAP 은 줌을 줄여 굽는다
5. 빌드 단계 — `catalog.json`(LAB_ONLY 뺌), 속성 손질 표의 JSON, 구운 타일. `map.js` 의 `BASE + …` 를 정적 판에서는
   상류 주소로 돌리는 갈림 하나(서버 판과 한 소스를 나눠 쓰게)
6. 한국 — 키 칸(localStorage)·키 검사(`Image` 한 장)·속성 JSONP 를 붙인다. VWorld 는 공개 판용 키를 따로 받아 싣고, 주소 CSV 만
   각자 키로(§10)
7. 밖에 열기 전 — EOX 비상업·Esri 조건·KIGAM 약관(상업 금지)·AGPL 13 조(소스로 가는 길)를 다시 본다

## 10. VWorld — 밖에 낼 때 (2026-10-02 더함)

### 10.1 한 줄

**VWorld 는 KIGAM 과 반대다 — 키가 원래 브라우저에 실리는 것으로 설계됐고, 지금 우리 키는 도메인을 검사받지도 않는다.**
그래서 정적 판에는 **"공개 판용 키 하나"** 를 따로 받아 싣는 것이 맞다(배경·검색·좌표→주소·WMS 그림). 다만 두 가지가 걸린다.

- **하루 한도를 그 키 하나가 진다.** 공개 판을 보는 모든 사람의 호출이 한 키로 모인다. 넘으면 그날은 공개 판의 VWorld 가
  통째로 멈춘다(`OVER_REQUEST_LIMIT`). 운영 서버의 키와 반드시 갈라 둔다
- **지오코더(주소→좌표, 좌표→주소)는 "저장할 수 없다"** 는 조항이 있다. 주소 CSV(#130)처럼 찾은 좌표를 점으로 남기는 쓰임은
  정적 판에서도, **지금 운영에서도** 이 조항과 부딪힌다(§10.4) — 사람이 약관을 읽고 정할 일이다

### 10.2 키는 무엇에 묶이나

**공식 안내** (vworld.kr 개발자 쪽, 2026-10-02 에 읽음)

- 키는 회원가입 뒤 [오픈API > 인증키 > 인증키 발급]에서 받고, 받을 때 **서비스 URL** 을 적는다
- WMS/WFS API 2.0 레퍼런스: "**https나 Flex 등 웹뷰어가 아닌 브라우저에서의 API사용은 요청URL에 도메인정보를 추가하여
  서비스를 이용합니다**" — `domain=` 에 "API KEY를 발급받을때 입력했던 URL" 을 넣는다
- Geocoder API 2.0 레퍼런스의 오류문: "**인증키 정보가 올바르지 않습니다. (ex. 인증키 발급 시 입력한 도메인이 다를경우)**"
- 남의 기록 — 개발키가 발급 때 등록한 도메인으로만 인증돼, 옛 도메인으로 부르니 `INCORRECT_KEY` 였다는 것(부동산 중개
  `ned` 계열 창구), 키를 여럿 받아 키마다 서비스 URL 을 달리 적을 수 있다는 것, localhost 를 서비스 URL 로 적으면 `domain=localhost`
  로 부른다는 것. 키 하나에 서비스 URL 이 몇 개까지인지는 공개된 글에서 찾지 못했다

**우리 키로 잰 것** (이 서버에서, 창구마다 한 번·3 초 간격, `Origin`·`Referer` 를 `https://koprifossillab.github.io` 로)

| 창구 | `domain` 없음 | `domain=github.io` | `domain=localhost` | ACAO | JSONP |
|---|---|---|---|---|---|
| 배경 WMTS (`req/wmts`) | 200 PNG | — (붙이지 않는 창구) | — | `*` | — |
| 검색 (`req/search`) | OK | OK | OK | 없음 | **된다** (`application/javascript`) |
| 주소→좌표 (`req/address` `getcoord`) | OK | OK | — | 없음 | 된다(004) |
| 좌표→주소 (`req/address` `getAddress`) | — | OK | — | 없음 | **된다** |
| WMS `GetMap` (`req/wms`) | 200 PNG(020) | 200 PNG | — | 없음 | — |

**지금 우리 키에는 도메인 검사가 걸리지 않는다.** 004 가 `domain` 으로 붙였던 `http://paleolab/GSM/`(발급 때 적은 서비스 URL 로
보인다)과 다른 github.io·localhost·없음 모두 통과했다. 004·033 이 WMTS 에서 본 것(Referer 를 빼도 엉뚱해도 온다)이 검색·지오코더·WMS 에서도 같다. 그러나 **이것을 믿고
설계하지 않는다** — 안내는 검사한다고 적고, 남의 개발키는 실제로 막혔다. 창구나 키 종류에 따라 다를 수 있고 언제든 켜질 수 있다.
공개 판용 키는 서비스 URL 에 `https://koprifossillab.github.io` 를 적어 받는다(서비스 URL 은 자유 입력이라 github.io 도 들어갈
것으로 보이나 신청 화면은 로그인 뒤라 못 봤다).

**검사가 없다는 것의 다른 얼굴** — 공개 판에 실린 키는 누구나 뽑아 **아무 도메인에서나** 쓸 수 있다. 그 사람의 호출도 우리 키의
하루 한도를 먹는다. 운영 키와 갈라 두는 까닭이 이것이다(KIGAM §3 의 2 와 같다).

### 10.3 키의 종류·기한·한도

- **개발키** — 처음 받는 키. **3 개월 유효, 최대 3 번 연장**(남의 글들, 공식 쪽에서 원문을 다시 확인할 것)
- **운영키** — 따로 신청, 심사 최대 10 일 남짓, **1 년마다 갱신**(갱신 때마다 다시 심사)
- **하루 한도** — 지오코더는 공식 안내에 "**일일 지오코딩 요청건수는 최대 40,000건**"(옛 글에는 3 만). 검색·WMS·WFS 도 하루
  한도가 있고 넘으면 `OVER_REQUEST_LIMIT` 인데, 창구별 수치는 공개 문서에서 찾지 못했다. 배경 WMTS 의 한도는 적힌 곳이 없다
- **우리 키** — `/srv/GSM/db/vworld_key` 는 2026-09-23 에 받았다(003). 개발키인지 운영키인지 기록에 없다. **개발키라면 12 월
  하순에 끝난다** — 운영 화면의 VWorld 배경·주소 찾기·VWorld 레이어가 그날 함께 멈춘다. 마이페이지에서 종류와 만료일을 본다
  (공개 판과 상관없이 지금 할 일)

### 10.4 약관 — 저장·재배포·상업

- **지오코더: "API 요청은 실시간으로 사용하셔야 하며 별도의 저장장치나 데이터베이스에 저장할 수 없습니다."** (Geocoder API 2.0
  레퍼런스). 주소→좌표(`getcoord`)와 좌표→주소(`getAddress`)가 이 API 다. 우리가 지금 이 조항과 부딪힐 수 있는 자리:
  - 점묶음의 **VWorld 둘레**(074, `vworld.point_facts`) — 좌표→주소·가까운 단층 따위를 `Point.place` 에 **DB 로 저장**한다
  - **주소만 적힌 CSV**(#130, wetherilli 152) — 찾은 좌표를 점묶음의 점으로 저장하고, 같은 주소를 캐시에 담는다
  - 서버의 검색·좌표→주소 캐시(`tilecache` 의 `.json`)
  정적 판에서 같은 일을 하면 저장 자리가 사람의 브라우저(IndexedDB)로 바뀔 뿐 "저장" 은 같다. **이 조항의 범위(사용자가 자기
  자료에 찾은 좌표를 붙여 두는 것까지인지)는 약관 원문과 운영기관 답을 보고 사람이 정한다**
- WMS·WFS·검색 레퍼런스에는 저장 조항이 보이지 않는다. 우리는 VWorld WMS 타일을 `tilecache` 에 담는다(020) — 이용약관 원문에서
  다시 본다
- **재배포·상업** — vworld.kr 이용약관 원문은 이번에 읽지 못했다(누리집이 스크립트로 그려 긁히지 않았다). 공개 판은 비상업이지만,
  WFS 로 받은 단층·등치선을 떠서 정적 판에 싣는 것은 재배포라 원문을 먼저 본다

### 10.5 다섯 자리 — 정적 판에서

| 자리 | 지금 | 정적 판에서 되나 | 키 |
|---|---|---|---|
| **배경 WMTS** | 브라우저가 곧장, 끊기면 문(033) | **된다** — ACAO `*`, 도메인 검사 없음. "그림으로 내려받기" 도 된다 | **공개 판용 키 하나.** 배경은 누구나 봐야 해서 BYOK 면 키 없는 사람의 한국 탭이 빈 바탕이 된다 |
| **WMS 레이어 그림** (행정경계·보호구역 …) | 문(`vworld.get_map`), 캐시 | **그림만** — `<img>` 로 받히나 ACAO 가 없어 그림 내려받기가 깨진다 | 공개 판용 키 |
| **WMS 속성·WFS 벡터** (단층·등치선) | 문(`get_feature_info`·`get_features`) | **안 된다** — ACAO 없음, WFS 는 JSONP 도 없다. 떠서 싣거나(재배포 — §10.4) 뺀다 | — |
| **주소·장소 검색** | 문(`vworld.search`), 캐시 | **된다** — JSONP | 공개 판용 키. 하루 한도를 나눠 쓴다 |
| **좌표→주소** (누른 자리·점묶음 둘레) | 문(`vworld.reverse`·`point_facts`) | 된다 — JSONP. 저장은 §10.4 | 공개 판용 키(보기만). 점에 붙여 두는 것은 §10.4 를 정한 뒤 |
| **주소 CSV → 좌표** (#130) | 화면이 50 줄씩 문에 보낸다 | 된다 — JSONP 로 한 줄씩. **그러나** 한 사람이 2 000 줄을 올리면 공개 키의 하루 4 만 건을 혼자 먹고, 결과를 저장한다 | **각자 키(BYOK)** — 쓰는 사람의 한도·책임으로. 키가 없으면 이 기능만 숨긴다 |

**KIGAM 과 갈리는 까닭** — KIGAM 은 키를 각자 넣는 것이 옳았다(§6): 운영 키를 지키고, 호출을 식별되게 하려고. VWorld 는

- 키가 원래 브라우저에 실리는 것으로 만들어졌다(배경 WMTS 를 브라우저가 부르는 전제, 003). 운영 화면도 지금 이미 키를 내보낸다
- 키를 받는 문턱이 낮다(가입하면 개발키부터 받는다). 그래도 보는 사람마다 키를 받게 하면 배경조차 안 뜬다 — 지도의 바탕이라 BYOK 의
  손해가 KIGAM 보다 크다
- 그래서 **보는 것(배경·검색·좌표→주소·WMS 그림)은 공개 판 키**, **대량으로 부르고 저장하는 것(주소 CSV)은 각자 키**로 가른다

### 10.6 사람이 할 일

1. **지금 키의 종류와 만료일**을 vworld.kr 마이페이지에서 본다 — 개발키면 운영키로 바꾸거나 연장한다(운영 서버 일이다)
2. 공개 판을 낸다면 **공개 판용 키를 따로** 받는다 — 서비스 URL `https://koprifossillab.github.io`. 개발키로 시작하면 석 달 뒤
   끝나므로 운영키로 신청한다
3. **이용약관 원문**에서 저장(지오코더 조항의 범위)·재배포·상업 조항을 읽고, 점묶음 둘레(074)·주소 CSV(#130)를 그대로 둘지 정한다.
   애매하면 운영기관(공간정보산업진흥원 브이월드 고객센터)에 묻는다
4. 공개 판 키의 하루 사용량을 마이페이지에서 지켜본다 — 넘기 시작하면 검색을 디바운스·캐시(브라우저)하거나 좌표→주소를 누를 때만
   부르게 줄인다
