# 다른 대륙의 지질도 API — 북미·남미·아프리카

2026-10-04 · 검토 (계획이 아니다) · `docs/새_상류_후보.md` 의 뒤를 잇는다

미국·캐나다·멕시코·남아메리카·아프리카의 지질도 API 를 웹에서 찾아 **실제로 찔러 본** 기록이다. 형식은 `새_상류_후보.md` 를 따랐다.
- 실측: 이 서버(paleolab)에서 `curl -A 'GSM/0.1'` 로 보냈다. 사내망 TLS 가로채기 때문에 필요할 때 `-k` 를 붙였다.
- 한 상류에 서너 번만 물었다. 응답 시간은 한 번씩 잰 어림이다.
- CORS 는 `Origin: https://koprifossillab.github.io` 를 실어 `Access-Control-Allow-Origin` 이 오는지 보았다.
- "붙이는 품" 은 상류 문 하나만 친 값이다(`igme.py`·`bgs.py`·`brgm.py`·`gsj.py` 를 본뜬다고 할 때).
  대륙마다 **지역 탭을 새로 세우는 품**(REGIONS·색·투영·씨앗 JSON·LAYER_EN)이 따로 든다.

`새_상류_후보.md` 와 다른 점 하나 — 거기에 적힌 **"캐나다 GSC ArcGIS 499" 는 옛 주소의 일이다.** 지금은 `maps-cartes.services.geo.ca` 에 열려 있다(아래 북미).

## 북미 — 미국·캐나다·멕시코·북미 전체

[실측 2026-10-04] 은 이 서버에서 `curl -A 'GSM/0.1' -H 'Origin: https://koprifossillab.github.io'` 로 던져 본 것이다.
GetMap 은 3857 256×256 한 장을 받아 눈으로 보았다. 붙이는 품은 GSM 의 문(`igme.py`·`bgs.py` 같은 ArcGIS 문, `gsj.py` 의 범위 범례)을
본뜬다고 할 때다. 중간 파일은 `scratchpad/na/`.

**Macrostrat 이 이미 덮는 것** — 온 지구 화면의 Macrostrat 을 점으로 물어 보니 켄터키는 large(KGS 1:2.4만), 미국 본토는 medium(SGMC),
온타리오·유콘·멕시코도 medium(각 기관 지도)이 들어 있다. **퀘벡(발도르)은 medium 이 비었다.** 그러니 북미에서 새 문을 낼 값은
"지역 탭에서 그 나라 투영·그 기관의 색과 속성으로 본다" 쪽에 있고, 자료 자체가 새로운 곳은 퀘벡·캘리포니아 색도 정도다.

### 미국

#### USGS SGMC — 주 지질도 합본 (mrdata) ★★★
- 주소: WMS `https://mrdata.usgs.gov/services/sgmc2` (레이어 `sgmc2`·`sgmc2contact`·`sgmc2structure`), 속성은 WFS
  `https://mrdata.usgs.gov/services/wfs/sgmc2` (`Lithology`·`Contacts`·`Structure`). 단위 설명 쪽 `https://mrdata.usgs.gov/geology/state/sgmc2-unit.php?unit=<unit_link>`
- [실측 2026-10-04] Capabilities 200(1.1 s). GetMap 200 `image/png` 11 KB, 덴버 둘레가 실제 지질 색으로 그려졌다(0.7 s).
  **WMS 레이어가 MapCache 앞단(cascaded)이라 GetFeatureInfo 는 막혀 있다**("unqueryable layer"). 대신 **WFS 1.0 bbox 질의가 된다** —
  `typeName=Lithology&bbox=lon,lat,lon,lat` 에 GML 로 `state·orig_label·unit_link·generalize(대분류 암상)·src_url·url` 이 온다(0.85 s).
  WFS 1.1 은 축 순서(위도 먼저)를 안 맞추면 빈 결과다. GeoJSON 출력은 없다(GML 만). GetLegendGraphic 501
- 축척: 주마다 1:5만~1:100만(대개 1:50만)을 합친 것. 미국 본토 48 주
- CRS: 3857·4326·900913
- 속성·범례: 속성은 WFS(위처럼 작은 bbox). 범례는 없다 — 단위가 주마다 수천이라 범례 대신 속성 팝업에 단위 페이지 링크
- CORS: `Access-Control-Allow-Origin: *` (WMS·WFS 모두)
- 키: 없다
- 조건: USGS 자료 — 공공 도메인, 출처 표기(Horton 외 2017, USGS DS 1052). AccessConstraints none
- 같은 서버의 짝: **알래스카** `services/sim3340`(SIM 3340, 1:158만 — 레이어 `units`·`faults`, **queryable**, GetFeatureInfo GML 에
  `state_unit·age_range·label` 이 온다. CRS 3338·3857·4326), **하와이** `services/hi`, 푸에르토리코 `services/pr`, King & Beikman 1:250만 `services/kb`
- 붙이는 품: 하루 (타일은 WMS 그대로, 속성만 WFS bbox → GML 읽기). 알래스카를 같이 넣으면 +반나절
- 비고: 미국 탭을 만든다면 기본 레이어감. Macrostrat medium 과 같은 자료(SGMC)지만 색이 USGS 원래 것이고 주 경계에서 이어진다

- **모로코** — 공식은 PDF 도폭 목록(`cartesgeoscientifiques.mem.gov.ma`)뿐, WMS 없음. ArcGIS Online 의 "geologie maroc" 는 개인 웹맵
- **나이지리아 NGSA** — 지도는 PDF·판매, 웹 서비스 없음
- **보츠와나·에티오피아·이집트(EGSMA) 정부 지도 서비스** — 찾지 못했다. 이들 나라는 BGS AGA(위 2, 보츠와나·에티오피아)로만 덮인다
- **Africa GeoPortal(Esri)** — 지질 자료는 위 3(b) 같은 사용자 업로드 사본이고 따로 지질 서비스가 없다
- **EGDI 1:100만** — 아프리카를 덮지 않는다(유럽·터키까지)

### 이 갈래의 추천 순서
1. **CGMW–BRGM 아프리카 1:1000만** — 대륙 전체 한 장, 3857·CORS `*`·키 없음, 연대가 ICS. 반나절. 아프리카 탭의 바탕
2. **BGS AGA 나라별 1:500만** — 38 나라, CC BY-SA(가장 깨끗한 조건), 이미 쓰는 BGS 호스트. 반나절. 1 위 위에 한 단계 자세히
3. **나미비아 GSN 1:100만 + RMCA 콩고·르완다·부룬디 1:200만·1:25만** — 둘 다 3857·CORS `*`·속성 좋음, 반나절씩. RMCA 는 조건을 물은 뒤
4. **탄자니아 GMIS 1:150만**(CORS 없음, 서버 문으로) 또는 **남아공 CGS 1:100만(DPME REST)** — 남아공은 ArcGIS REST 문이 새로 필요해 하루

## 먼저 붙일 순서 (세 대륙을 통틀어)

GSM 에 아직 북미·남미·아프리카 탭이 없다. 그래서 **대륙 바탕 한 장으로 탭을 먼저 세우고**, 자세한 나라 판을 그 위에 얹는 순서로 골랐다.

1. **SGC 남미 1:500만 + 콜롬비아 1:50만**(반나절)
   - 한 서버, 문 하나로 남미 탭의 바탕과 한 나라가 함께 선다.
   - 3857 이 그려지고, 속성은 geo+json 이며, CORS 가 되고, 키가 없다.
   - 남미 판은 CGMW 조건이라 밖에 열기 전에 읽는다. 콜롬비아 판은 CC BY 4.0 이다.
2. **CGMW–BRGM 아프리카 1:1000만**(`mapsref.brgm.fr`, 반나절)
   - 아프리카 탭의 바탕이다. 3857 을 받고, CORS 는 `*`, 연대는 ICS 표기다.
   - BRGM 계열이라 `brgm.py` 의 틀을 빌린다. 같은 서버에 세계 1:5000만과 유라시아 판도 있다.
   - 속성은 GML 로 물어야 온다. 범례는 정적 PNG 다.
3. **NRCan Wheeler 캐나다 1:500만 + 온타리오 OGS 1:25만**(반나절씩)
   - 캐나다 탭의 바탕과 자세한 판이다. 둘 다 ArcGIS 이고 CORS 가 열려 있으며 조건은 OGL 이다.
   - Wheeler 는 영어·프랑스어 속성을 함께 준다.
4. **브라질 SGB GeoServer**(하루)
   - 1:100만 전국판에 2025 년 1:250만 판이 더 있다. 속성이 가장 풍부하고 CORS 는 `*` 다.
   - GetFeatureInfo 에는 `propertyName` 을 꼭 붙인다. 안 붙이면 한 번에 2.2 MB 가 온다.
   - 범례는 범위에 맞춰 떠야 한다. 화석·연대 점 레이어도 있다.
5. **USGS SGMC**(+알래스카 SIM 3340, 하루)
   - 미국 탭의 바탕이다. 공공 도메인이고 CORS 는 `*` 다.
   - GetFeatureInfo 가 막혀 속성은 WFS bbox 로 읽는다.
   - Macrostrat 의 medium 이 이미 SGMC 라, 자료가 새롭기보다는 탭에 세우는 값이다.
6. **멕시코 SGM 1:25만·1:5만**(하루)
   - CC BY 4.0 이고 속성이 넉넉하다. WMS 가 400 이라 REST export 와 identify 를 쓴다.
   - 범례가 수백~수천 칸이라 일본처럼 보는 범위의 범례를 떠야 한다.
7. **BGS 아프리카 지하수 지도책 나라별 1:500만**(반나절)
   - 지금 `bgs.py` 가 쓰는 호스트이고, 조건이 CC BY-SA 로 가장 깨끗하다.
   - 속성은 암상 갈래 하나뿐이다. 2 번 위에 한 단계 자세히 얹는 자리다.
8. **퀘벡 SIGÉOM**(반나절)
   - Macrostrat 에 빈 자리라 자료가 새롭고, CC BY 4.0 이다.
   - Origin 헤더가 붙으면 403 이라 서버 문으로만 붙는다.
   - **페루 INGEMMET 1:5만**도 같은 무게다 — 남미에서 가장 자세하지만 메타데이터의 CC BY-NC-SA 가 걸린다.

**버린 것 한 줄씩**

- GMNA·certmapper(아프리카 포함): 403 이다.
- ScienceBase: 503 이다.
- CGMW 자체: 지도를 팔 뿐 API 가 없다.
- SIGAfrique: 호스트가 없다(NXDOMAIN).
- OneGeology 포털: 여전히 닫혀 있다.

- 볼리비아: 8080 포트가 거부된다. 다른 망에서 한 번 더 볼 만하다.
