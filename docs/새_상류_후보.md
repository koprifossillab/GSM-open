# 새 상류 후보 — 지질도·점 자료 API 를 더 붙일까

2026-10-02 · wetherilli · 검토 (계획이 아니다)

LunaGeo(lunageo.com)를 보다가 시작했다. 그쪽은 오픈소스 GIS 를 **쓰는** 용역 회사라 열린 API·코드가 없었다
(GitHub `lunageo` 의 공개 저장소는 2023 년의 `rbac` 하나). 그래서 웹에서 쓸 만한 지도 API 를 더 찾았다.
**아래 "응답" 은 2026-10-02 에 `curl -A 'GSM/0.1'` 로 GetCapabilities 나 한 번의 질의를 던져 본 것뿐이다.**
이용 조건은 아직 읽지 않았다 — 붙이기로 하면 그것부터 읽고, 연구실 내부용이면 `views.LAB_ONLY` 에 넣는다.

## 3. 막혔거나 지금은 안 되는 것

- **중국지질조사국 GeoCloud** — 국외에서 연결부터 되지 않고, 지도 서비스는 신청해서 승인을 받아야 쓴다(2026-10-02).
  밖에 열 때 중국 탭은 CCOP 200만(108)으로 선다 — [중국_GeoCloud.md](중국_GeoCloud.md). 1/250 만은 TODOs 의
  `10.23650/data.H.2017.NGA121474` 와 같은 줄기다 (025)
- **러시아 VSEGEI** — `http://wms.vsegei.ru/VSEGEI_Bedrock_geology/wms` 가 403. 우리 쪽에서 막힌 것으로 보인다
- **OneGeology 포털** — 닫혀 있다. GSJ 가 새로 맡아 2026 년 중에 다시 연다고 한다. 열리면 각국 지질도 WMS 를 한
  목록에서 찾을 수 있다 — 가장 큰 수확이 될 곳
- **캐나다 GSC 지질도** — ArcGIS 499 — 옛 주소의 일이다. 2026-10-04 에 `maps-cartes.services.geo.ca` 에 열려 있다([다른_대륙_지질도.md](다른_대륙_지질도.md))
- USGS 광물자원 WMS(`mrdata.usgs.gov`) — 경로를 잘못 짚었다(MapServer 안내문). 다시 볼 것

레이어 틀이 PBDB 로 서 있다).
