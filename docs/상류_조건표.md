# 상류 조건표

2026-10-05 · wetherilli 281. 상류(카탈로그 레이어의 `upstream`)가 여든다섯이 되어, 사람이 **밖에 열 때 무엇을 내릴지**와 **정적 판에 무엇을 실을지**를
한눈에 정하도록 모았다. 조건은 문(`web/viewer/<문>.py`)의 머리글과 근거 devlog 가 적은 것을 옮겼다 — 새로 묻지 않았다. 조건을 아직 읽지 않은 곳은
**(사람) 읽을 것** 이다. 결정은 이슈 #153 에서 한다.

## 칸의 뜻

| 칸 | 뜻 |
|---|---|
| 조건 | 라이선스와 그것이 적힌 곳(Capabilities 의 AccessConstraints·메타데이터·누리집). "적힌 것 없음" 은 찾아봤는데 없었다는 뜻 |
| 비상업 | **NC** = 비상업 조건이 걸렸다. **판매** = 기관이 자료를 판다(보기만 열림). **내부** = 재배포 금지 |
| CORS | `*` · 되비춤(Origin 을 되돌려 준다) · 없음 · — (재지 않았다). 정적 판은 CORS 가 있어야 브라우저가 곧장 부른다 |
| 서버 캐시 | 담음(기본) · **담지 않음**(`views.NO_STORE`) · 곧장(브라우저가 상류를 곧장 불러 서버를 타지 않는다) · 파일(우리 디스크의 파일) |
| 밖에 열 때 | **LAB_ONLY** = `GSM_PUBLIC=1` 이면 목록에서 빠진다(`views.LAB_ONLY`) |
| 정적 판 | **기본** = `static_site.UPSTREAMS` · **구운 것** = `--baked` 가 있을 때 · **고를 때** = `OPTIONAL`(`--with …`) · — = 싣지 않는다 |

## 먼저 볼 것 — 사람이 정할 일

1. **밖에 열기 전에 내릴 후보** — 조건이 막는 곳: `geo3al`(내부, LAB_ONLY), `cgmw`·`sgc` 의 남미 1:500만(CGMW 판매), `cgs`·`gsn`(판매 — 캐시에
   담지 않지만 보이기는 한다), `geus`·`geusarc`(개인 용도), 비상업 넷(`sgb`·`ingemmet`·`iige`·`kigam50k`), `phyloserver`·`peninsula`(LAB_ONLY)
2. **CLAUDE.md 와 코드가 다른 곳** — CLAUDE.md 는 "극지연구소(`kopri`)도 KPDC 공개 정책을 사람이 읽기 전까지 LAB_ONLY" 라 적는데,
   `views.LAB_ONLY` 는 `("geo3al", "phyloserver", "peninsula")` 뿐이다. 그런데 `kopri` 는 정적 판 기본(`UPSTREAMS`)에 들어 있다. 어느 쪽이 맞는지 정한다
3. **조건을 읽지 않은 곳** — 아래 표의 "(사람) 읽을 것" 열여덟
