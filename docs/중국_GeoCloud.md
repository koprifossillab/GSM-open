# 중국지질조사국 GeoCloud — 중국 탭의 geo3al 을 바꿀 수 있나

2026-10-02 · wetherilli · 검토 (계획이 아니다)

중국 탭의 지질도(USGS geo3al, 025)는 "내부 용도만, 가공물 포함 제3자 재배포 금지" 라 밖에 열 때 내려야 한다. 그 자리를
중국지질조사국(CGS)의 GeoCloud(地质云, `geocloud.cgs.gov.cn`)로 채울 수 있는지 보았다. `docs/새_상류_후보.md` §3 의 막힌 줄,
TODOs 의 1:250만(`10.23650/data.H.2017.NGA121474`) 줄과 같은 줄기다.

## 1. 한 줄

**지금은 붙일 수 없다.** GeoCloud 는 국외에서 연결부터 되지 않는다. 우리 서버(한국)에서도, 미국 쪽 가져오기에서도 마찬가지다.
열린다 해도 지도 서비스는 **신청하고 승인을 받아야** 쓴다. 중국 탭을 밖에 열 길은 GeoCloud 가 아니라 **이미 있는 CCOP 200만**
(108, 비상업 자유)이다.

## 2. 닿는가 — 2026-10-02 에 재 본 것

| 주소 | IP | 우리 서버(한국) | 비고 |
|---|---|---|---|
| `geocloud.cgs.gov.cn` (포털·`/arcgis/rest/services`) | 219.142.81.151 | **TCP 연결 안 됨** (80·443 모두) | 미국 쪽 가져오기도 `ECONNREFUSED` |
| `geocloudsso.cgs.gov.cn` (로그인) | 219.142.81.150 | 25 초 무응답 | |
| `www.ngac.org.cn` (국가지질자료관) | 219.142.81.124 | 25 초 무응답 | |
| `dcc.cgs.gov.cn`·`dcc.ngac.org.cn` (지질 자료 출판, 1:250만의 DOI 쪽) | CDN | 연결은 되나 응답 없음 | 미국 쪽 가져오기는 502 |
| `geochina.cgs.gov.cn` (학술지 『中国地质』) | 219.142.81.70 | 200, 1.4 초 | 같은 대역인데 열린다 |
| `www.cgs.gov.cn` (기관 누리집) | CDN | 200, 0.6 초 | |

같은 대역(219.142.81.x)에서도 학술지는 열리고 지질 자료 서비스만 닫혀 있다. **서비스마다 국외 접속을 막아 둔 것으로 읽힌다.**
중국 안에서도 "학교 망·VPN 으로는 안 열리고 휴대폰 망으로 열린다" 는 글이 있다 — 접속을 고르는 망이다.

## 3. 열려 있다 해도

- **지도 서비스는 신청제다.** GeoCloud 의 "服务接口(서비스 접속)" 에서 신청 양식을 내고 승인을 받아야 서비스 주소를 준다(중국 쪽
  안내 글들). 공개된 WMS·ArcGIS REST 주소는 찾지 못했다 — 2026-09-30 의 첫 조사(`새_상류_후보.md` §3)와 같다. KIGAM 처럼 열쇠를
  받는 길이 있다 해도 계정은 중국 실명 인증을 요구하는 것이 보통이다(확인하지 못했다)
- **1:250만(`NGA121474`)은 내려받는 자료다.** 2001 년에 끝낸 벡터 데이터베이스(0.7 GB)로, 지질 자료 출판 시스템(dcc)이 DOI 로
  낸다. 받을 수 있으면 geo3al 처럼 우리 디스크의 파일을 읽어 그리면 된다(문이 아니다). 그러나 dcc 가 국외에서 응답하지 않아
  **이용 조건을 읽지 못했다.** TODOs 대로 사람이 받을 수 있는지·조건을 확인하는 길뿐이다
- **지도 반출의 법.** 중국은 국경·해안선이 그려진 지도를 내보낼 때 심사(审图号)를 요구한다. 국외 서비스가 그 지도를 다시 보이는
  것이 문제가 되는지는 따지지 않았다 — 붙일 수 있게 되면 그때 본다

## 4. 그러면 중국 탭은

| 길 | 축척 | 조건 | 지금 |
|---|---|---|---|
| USGS geo3al | 1:500만 | 내부 용도만, 재배포 금지 | 있음. `GSM_PUBLIC=1` 이면 내려간다(029) |
| **CCOP 동·동남아시아** (GSJ 새 호스트 WMS) | 1:200만 | 개인·교육·연구·비상업 자유 | **있음** (108). 밖에 열 때 이것이 남는다 |
| Macrostrat (온 지구 화면) | 나라마다 — 중국은 거친 판 | CC BY 4.0 | 온 지구 화면에만 |
| GeoCloud 1:20만·25만·50만 | 1:20만~ | 신청제, 국외 차단 | 닿지 않는다 |
| CGS 1:250만 (`NGA121474`) | 1:250만 | 읽지 못했다 | 사람이 받을 수 있는지 확인 중 |

**밖에 열 때 중국 탭은 CCOP 하나로 선다.** geo3al 보다 축척이 크고(200만) 조건이 맞는다. CCOP 의 지질시대는 이미 ICS 한글판으로
옮긴다. 따로 할 일은 없다 — `LAB_ONLY` 가 geo3al 을 내리면 중국 탭의 "기본 지질도" 칸에서 CCOP 이 첫째가 되는지만 보면 된다.

## 5. 다시 볼 때

- 중국 안의 망(협력 기관·출장)에서 GeoCloud 에 들어가 "服务接口" 신청이 국외 기관에 열려 있는지, 실명 인증이 필요한지 본다
- dcc 의 1:250만 상세 페이지의 공유 조건(共享方式)을 읽는다 — 자유 내려받기면 geo3al 틀(셰이프파일 → 우리가 그린다)로 하루면 선다
- OneGeology 포털이 다시 열리면(2026 년 중, `새_상류_후보.md` §3) CGS 가 거기 WMS 를 냈는지 본다 — 예전 OneGeology 에는 중국 1:250만
  WMS 가 있었다(확인하지 못했다)
