# 외부 자료원 — 받아 두는 것과 브라우저가 곧장 부르는 것

2026-10-06 · koprifossillab · 목록 (계획이 아니다)

바깥에서 자료를 가져오는 길을 **받아 두느냐, 그때그때 중계하느냐, 브라우저가 곧장 부르느냐** 로 갈라 모았다.
브라우저 쪽 주소는 `web/viewer/static/viewer/*.js`·`data/*_layers.json` 을 긁어 확인했고, 나머지 설명은 CLAUDE.md 에서
옮겼다. 문 일흔여섯을 하나하나 열어 보지는 않았다. 상류마다의 이용 조건은 [상류_조건표.md](상류_조건표.md) 가 맡는다.

## 1. 서버가 통째로 받아 모아 두는 것 (`fetch_*`)

화면이 부를 때 상류를 타지 않는다 — 모아 둔 파일(`<DB 옆>`)만 읽는다.

## 2. 사람이 원본 파일을 받아 굽는 것 (`build_*` 등)

원본은 NAS `N:\GSM\sources\`, 구운 것은 `<DB 옆>`. 저장소에 두지 않는다. 무엇이 있고 언제 구웠는지는 `manage.py data_status`.

- **달·화성·수성** — USGS 달 원도 6 장, 남극–에이트켄 분지 지질도, 화성 옛 지질도·지역도, Robbins 크레이터, 수성 1:500만 지질도,
  주룽 로버 경로
- **지역 탭** — 남극 GeoMAP·IBCSO v2·ADMAP-2, 얀마옌 NPI 지질도, 중국 geo3al(연구실 내부용), 한반도 지질도 음영판·민판,
  카리브 USGS SIM 3534, 남호주 방사능 격자, 일본 시군구 코드표(`japan-muni.json`)
- **온 지구** — PALEOMAP 판 회전, PaleoCoastlines, CRUST 2.0, Seton 해양 지각 연대·GlobSed, GLiM, IHFC 지열류,
  Hasterok 판 경계·지질구, World Stress Map, USGS MRDS 광상, GEM 활성단층(CC BY-SA), 충돌구·LIP, RGI 빙하,
  Natural Earth, NADI-1 빙상 가장자리, Müller 2022 맨틀 슬랩

## 3. 서버가 그때그때 중계하며 캐시에 보태는 것

상류마다 문(`viewer/*.py`)이 하나다. `tilecache.py` 가 타일·범례·속성을 담고 3 년이 지나면 다시 묻는다.

- **지질도 상류 여든 남짓** — KIGAM·GSJ·GEUS·NGU·BGS·BRGM·USGS mrdata·Macrostrat·NASA Trek 지질도·표고 … (`Layer.upstream` 의 목록 전부)
- **배경**(`basemaps.py`) — NASA GIBS Blue Marble, GEBCO, NPI 스발바르 지형도·위성
- **받되 담지 않는 것** — 남아공 CGS·나미비아 GSN(`views.NO_STORE`, 자료를 판다), phyloserver(하루만 믿고 한반도 지질도 타일은
  담지 않는다), VWorld(VPN 이 끊을 때만 문을 거치고 담지 않는다)

## 4. 브라우저가 외부 주소를 곧장 부르는 것

- **지역 탭 배경**

  | 배경 | 주소 | 비고 |
  |---|---|---|
  | VWorld WMTS | `api.vworld.kr` | 막히면 `vworld/…` 문으로 |
  | EOX Sentinel-2·Terrain | `tiles.maps.eox.at` | 비상업(CC BY-NC-SA) |
  | Esri 남극 위성 | `services.arcgisonline.com` | Esri 이용 조건 |
  | PGC ArcticDEM·REMA | `di-pgc.img.arcgis.com` | |
  | 국토지리원 타일 | `cyberjapandata.gsi.go.jp` | |
  | 대만 NLSC WMTS | `wmts.nlsc.gov.tw` | |
  | AWS 지형 법선 | `s3.amazonaws.com` | |

- **카탈로그 레이어가 화면에 주소를 그대로 주는 것** — 지리원 활단층도·화산토지조건도(`gsitile`),
  앨버타 AGS 타일(`tiles.arcgis.com`), BAS Bedmap3(ArcGIS Online)
- **찾기·주소** — 국토지리원 주소 검색(`msearch.gsi.go.jp`)·역지오코더(`mreversegeocoder.gsi.go.jp`)
- **구 화면** — NASA Trek 영상 타일(`trek.nasa.gov/tiles/`, 달·화성·수성), USGS Astrogeology WMS
  (`planetarymaps.usgs.gov`, 루나 오비터·클레멘타인·마리너 10), AWS Terrarium 지형(온 지구·3D)
- **정적 판에서만** — KIGAM `/openapi/wms`·VWorld(보는 사람의 키로), GEBCO·GIBS·NPI(연구소 판에서는 3 의 문을 거친다),
  `static-kinds.js` 의 극지 상류와 `--with` 로 고른 상류
- **링크로만 넘기는 것** — EarthThruTime3D, 출처·키 신청 링크. 자료를 받지 않는다

## 5. 사용자가 주소를 정하는 것

- **연결 레이어** — 브라우저가 곧장 받고, 못 받으면 `linked.py` 가 대신 부른다. 캐시에 담지 않고 주소는 그 브라우저에만 둔다
